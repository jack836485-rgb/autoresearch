# 大语言模型 Agent 检索补充

领域为 Agent／智能体／agentic systems 时读取。只提供发现词和核实注意事项。

## 先固定对象

默认指 LLM 驱动的软件、浏览器／GUI、检索、知识工作或科研智能体，开始时说明此范围。机器人、传统 MARL、金融 agent-based modeling 及把 agent 当普通名词的资料不自动并入；交叉研究保留实际任务范围。

## 展开查询

| 检索对象 | 可组合的英文词 |
| --- | --- |
| 长流程与工具链 | long-horizon、tool use、navigation、fork-merge、dependency、backtracking、state tracking |
| 经验与持续改进 | experience learning、in-context learning、experience distillation、self-evolving、skill induction、negative transfer |
| 上下文与记忆 | compaction、summary、persistent memory、retention、retrieval、utilization、stale memory、source attribution |
| 单／多智能体编排 | harness、orchestration、multi-agent、coordination、concurrency、shared state、delegation、budget |
| 失败诊断与恢复 | root cause、failure attribution、responsible role、error propagation、counterfactual repair、early warning |
| 环境与训练 | environment generation、verifier、synthetic environment、agentic RL、interactive feedback、live web、sim-to-real |
| 评测及成本 | evaluation automation、benchmark audit、instruction following、unprompted defaults、task success、end state、tool cost、tail latency |
| 调研入口 | survey、research landscape、systematic study、empirical study（配合上面的具体对象） |

用有辨识度的短语按单个子问题查询；宽泛 OR 查询命中大量普通含义的 agent 时拆开。

## 核实注意

- 高产领域检查结果集真实时间跨度，按月份／子问题补查缺失时段。
- 使用 GPT、Claude、Google Search、Azure 或 Codex 的论文不因此满足白名单；名称相近的学院或实验室不能代替白名单机构。
- 首发资格用 v1，实验数值绑定实际阅读版本；索引旧标题与新版标题不同时按 arXiv ID 合并，不算多篇。
