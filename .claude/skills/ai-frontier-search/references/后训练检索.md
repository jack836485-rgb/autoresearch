# 大语言模型后训练检索

检索该主题时读取本文件。它提供范围与查询词，不规定论文排名、精读流程或输出格式。

## 范围

默认关注语言模型预训练后的能力、指令遵循和偏好适配，包括 SFT、偏好学习、奖励建模、强化学习、推理／智能体蒸馏，以及直接服务于这些训练过程的数据、课程和系统。针对后训练机制的受控分析也在范围内。

单纯预训练、持续预训练／mid-training、提示工程、推理时搜索、RAG 应用或通用评测不因提到后训练而自动符合主题；需有直接研究后训练方法或行为变化的内容。用户明确扩大范围时按其要求执行。

`post-training quantization` 常指部署压缩，不能因为名字里有 post-training 就收录。不过，FP4 rollout、量化感知 RL 等直接改变后训练流程的研究属于后训练系统方向；不要用 `NOT quantization` 一刀切去掉。

涉及多模态、代码或工具使用时，说明训练对象和任务。用户限定纯文本 LLM 时排除纯视觉、音频、机器人策略训练；否则保留直接研究语言模型后训练的交叉工作。

## 关键词展开

| 检索面 | 英文检索词示例 |
| --- | --- |
| 监督微调 | supervised fine-tuning、SFT、instruction tuning、instruction data、rejection sampling |
| 偏好与对齐 | RLHF、RLAIF、direct preference optimization、DPO、preference learning |
| 奖励信号 | reward model、process reward、outcome reward、rubric、credit assignment |
| 可验证奖励 RL | RLVR、reinforcement learning with verifiable rewards、GRPO、PPO、RLOO、DAPO、GSPO |
| 蒸馏 | on-policy distillation、self-distillation、privileged distillation、reasoning distillation |
| 数据与课程 | data selection、curriculum、prompt sampling、synthetic data |
| 训练系统 | asynchronous RL、off-policy correction、rollout、policy staleness、low-precision RL |

各检索面按任务组合 `large language model`、`language model`、`LLM`、`reasoning model` 或 `language agent` 等对象词。不要只用 `post-training` 或 `reinforcement learning`；前者会命中部署压缩和非 AI 培训，后者会混入与语言模型无关的 RL。

词表用于展开，不要求一次查询塞入全部词。先按机制分开查询，再用已发现论文的具体术语和机构别名补漏；只凭算法缩写也需要读摘要确认实际训练对象。

## 工具复用注意

Semantic Scholar 可用于发现候选和恢复 arXiv ID。不要沿用“只搜已发表会议／期刊”和“按引用量筛选”的默认习惯，这会漏掉刚公开的预印本。其日期及作者姓名不能替代原文 v1 日期和作者机构。

官方研究列表通常比公司产品首页更有用。找到论文后追到对应的 arXiv／正式报告；研究列表发布日期、博客日期和会议日期与首次公开时间可能不同。
