# 研究问题卡（Gap Card）规范

在提炼问题及导出 `研究问题.json` 时读取。卡片将真实观察转成可推理的问题，保留来源与边界；它不是原创算法提案或已完成查新的研究 idea。

## 卡片内容

每张卡使用本轮稳定 ID，例如 `Q001`，与主文一致。以下内容必要，篇幅随证据决定：

- **具体问题与标签：** 技术对象、失败或未知关系、发生条件；宏观机制只作标签。
- **触发线索与证据：** 受控实验、反例、真实案例、明确作者局限或尚未验证的边界分别说明。每个重要发现保留原文 URL、章节／表图、实验设置和对照。
- **已观察到的结果：** 有数据则保留数值及其比较口径；数值不可核实时用明确现象，不猜填。
- **指标范围：** 在实验设置和具体观察中写明样本单位、分母、子集筛选及重复方式；全样本、失败样本与已覆盖内容上的指标不可互换。字段不另增一套评分结构。
- **已有处理与解释：** 谁提出了什么解法，在哪些条件下有效，哪些解释已支持，哪些只相关或未证实。
- **剩余问题：** 说明已有工作已经涉及什么、本轮未确认什么。作者建议 future work、仅有小规模验证和真正技术失效不得混为一类。
- **可检验切口：** 继续区分什么因素／假设，观察什么，控制什么；不自动提出新算法，不列未经用户确认的实验参数。
- **查新与解决状态：** 本轮是否有针对性查新，当前缺口只对哪些文献范围成立，已解决的部分不能重新包装成创新。

只有作者总结但原始实验未读取时，标为二手线索；理论证据说明假设，不能冒充真实模型实验。没有机制解释时直接说明未知，而不是给每张卡编一个因果故事。

## JSON 结构

根对象保存领域、窗口、机构口径与问题卡数组。中文字段固定用于下游读取；同一问题多份证据写入同一卡片。信息缺失用 `null`，数组无条目用 `[]`，同时在证据边界说明缺失影响，不用占位猜测填满。

```json
{
  "领域": "具体领域",
  "检索日期": "YYYY-MM-DD",
  "近期窗口": ["YYYY-MM-DD", "YYYY-MM-DD"],
  "机构口径": "ai-frontier-search 白名单及本轮子集",
  "研究问题": [
    {
      "id": "Q001",
      "具体问题": "对象、条件与失败或未知关系",
      "宏观标签": ["机制或任务标签"],
      "线索类型": ["受控失败实验"],
      "证据": [
        {
          "作品ID": "已核实 ID；没有则为 null",
          "标题": "完整标题",
          "机构": ["已核实署名机构"],
          "原文链接": "对应作品的原始 URL",
          "位置": "章节、表图或附录",
          "阅读版本": "实际阅读版本",
          "证据角色": "原始实验／理论分析／作者局限／二手调研归纳",
          "实验设置": "模型、数据、任务、评测和重复情况；非实验材料可为 null",
          "变化变量": "实际改变的变量；未知则 null",
          "对照与保持条件": "实际固定的条件；未知则 null",
          "具体观察": "保留反常结果、关键数值或失败情形",
          "成本口径": "相同步数／token／时间／总预算及额外成本；未知则 null",
          "证据边界": "适用条件、未分离因素、缺失与二手信息"
        }
      ],
      "已有解决方法": ["具体处理、有效条件与证据关联"],
      "已支持的解释": ["已验证机制或诊断；注明支撑证据与因果边界"],
      "待验证解释": ["作者或调研者的假设，明确归属；没有则为空数组"],
      "尚未解决": "剩余技术问题及本轮判断范围",
      "可检验切口": "要区分的因素、观察量与控制条件",
      "已知边界": ["任务、规模、预算和外推限制"],
      "解决状态": "部分解决／机制未定／仅验证边界／已被后续解决",
      "查新状态": "未进行针对性查新；若已进行则写实际范围和结果",
      "与其他问题的关系": []
    }
  ]
}
```

最终 JSON 不使用上面的示意占位文本。证据与解释可通过作品 ID 关联；没有标准 ID 时用完整标题与原始 URL，不加哈希。正文与 JSON 是同一问题的两种呈现，来源、数字、解决与查新状态必须一致。

## 有用的表达粒度

可用问题的形状是：

> 在同一教师下，前置训练提升学生当前准确率，却使后续蒸馏退化；哪些训练状态变化与此有关，已有诊断解释了哪些条件，剩下什么尚未验证？

继续说明实际任务、变量、实验及成本，才能交给下游。“改进阶段协同”“研究更好的奖励”只能当标签，不能代替问题。这样的切口不是查新结论；下游仍需查更早和白名单外的相关研究。
