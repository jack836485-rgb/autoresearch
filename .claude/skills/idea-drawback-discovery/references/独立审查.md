# 独立Reviewer与机器记录

每次新Agent、fork_turns:none，不继承执行器或历史Reviewer。可使用环境支持的review模型，不能用型号缺失绕过审查；不followup、resume、追加解释或再委托。

只传固定rubric、当前四节Brief、初始Problems／drawbacks／硬约束。当前目标变化及证据在Brief背景中说明，不传候选池、自评分、排名、历史、其他方案或未选假设，也不传Slot路径。

Reviewer独立联网核实最高重合原作及baseline入口，查新不限Map的年份／机构。无代码的近邻不能忽略；跨领域启发不自动成为同任务baseline。评当前独立机制、研究价值、可验证性和目标演化；少覆盖软目标不算fatal，真正偏题、违规、无证据偏移及不可辨别的关键实验可阻断。

prepare仅保存Brief和prompt，不计次；start紧邻真实spawn前计次，错误／超时／格式失败只记真实调用，不计完成轮次。新ID不复用，中断后依据真实调用记录恢复，不能返还已用次数。每个目标Problem初始至少十轮有效独立审查，Brain可追加预算。候选数量不替代有效审查，联合Slot只给当前实际处理的问题计数，scope或硬约束不成立的回复不计完成。

有效回复包含结论、Claim判断、最高近邻及模板要求的JSON。score>7.5且无fatal，并确为当前未完成预算问题范围的最高分合格候选才过Gate；无合格者可审最高分待改进候选，但探索性审查不自动升级资格；7.5不过，格式／verdict矛盾不得包装通过。执行器须检查真实检索，布尔字段不证明工具行为。

每轮当前reviewed_problem_ids随允许的初始范围传给Reviewer；多个问题共同计数时，Claim判断应明确各问题的当前作用，不能仅因被输入提到就计数。提前通过保留分支，完成全部当前预算后再最终写作。重复审同一有效版本不用于凑轮次。

每轮Brief在根目录，原始Review在 `reviews/round-NN-review.md`。完整实际提示在 `prompt/round-NN-review-prompt.md`，与prepare返回后发送的文本一致；机器JSON另保留prompt、原回复、评分、近邻、AgentID和解析。Improver提示由调用方保存在同目录的improve-NN-prompt.md。Reviewer只收到本轮提示正文，不能读取该目录或其他历史记录。不生成终审汇总Markdown。候选对应审查结果只保存在json中的review_history，不在精简候选Markdown展开；终止原因可写PIVOT_OR_STOP，所有记录在自身Slot。
