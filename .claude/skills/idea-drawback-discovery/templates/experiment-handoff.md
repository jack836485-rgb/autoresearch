# Experiment Handoff

本文件在独立 Review Gate 通过后交给实验规划器。尚未执行正式实验。

## 当前研究目标

最终候选、Problem 来源、实际预计处理的 drawback、初始未覆盖目标、新相关不足、目标演化依据与硬约束。addressed 只表示声称处理并设计验证，非已证明解决。

## 最小实现及 baselines

方法实际操作、输入输出、最小代码／环境路径。同任务 baseline 的论文、已打开核实的代码／权重／数据和复现入口；无仓库简单基线给完整可实现定义。不可复现工作保留为相关文献，不混成可跑 baseline。

## 控制变量、成本与待确认参数

核心模型、数据、训练／推理预算及评价设置对齐，明确只改变的机制。教师、检索、评审、预处理等额外成本分别计；不能把主阶段同 token 说成同总成本。未知核心参数向用户／总控列为待确认，不在本 skill 启动实验或猜值。

## 开始条件与停止条件

必要数据／实现／约束、应先检验的机制、何种结果推翻 Claim。指出 Review 剩余风险和选题查新边界；这些是真实待验证问题，不是为每项增加新的工作流。

## 参考文献与独立审查

原论文链接、实验基线入口、通过审查编号和 score、机制新意与目标演化依据。
