### IDEA-002：信念还是承诺？用执行出来的反事实策略价值表拆解 AI 后训练 agent 的策略锁定

- 来源：`领域共性不足`（以 `相似领域成熟方法迁移` 为辅：决策科学中的现状偏置／承诺升级的分离设计与“主动选择”去偏）
- 父 Idea：`IDEA-001`
- 状态：`needs_revision`
- 定位关键词：PostTrainBench；strategy-level capability；escalation of commitment；status quo bias；scientific judgment（SciΠvot）；outcome prediction of ML experiments
- 一句话背景：在 LLM agent 自动后训练（PostTrainBench）中，agent 跑完第一轮训练后几乎不换策略，而人类给出的中途换策略指令能显著提分。
- 与起点问题的关系：原问题。保留对象（后训练 agent、PostTrainBench 的任务与真实轨迹）。改变的是评价目标：从“切换率”改为“相对执行出来的价值表的决策遗憾”，并新增“信念 vs 决策”的分解。原问题中“锁定来自哪里”被直接回答；“如何通过训练消除锁定”留给后续。
- 主贡献：一个以**真实执行结果为真值**的策略决策评测，以及基于它的因果分解。它把 agent 不换策略分成两种情形：（a）**信念错**——它对替代策略最终分数的预测本身低估了替代方案；（b）**信念对、决策不跟**——它自己预测替代方案更好，却仍坚持当前计划（承诺／现状偏置）。再用 2×2 的呈现操纵（现任标记 × 作者归属）定位后者的来源。成功后，社区可以知道锁定该用“去偏的决策协议”（不需训练）来修，还是要用“价值预测训练”来修，并得到一个可复用、低成本评测决策协议的基准。
- 贡献自评：重要性 7.5 / 新颖度 7.0 / 有效性 6.0
  - 重要性依据：策略锁定是 AI4AI／RSI 能否累积的瓶颈之一；2608.19072 的作者建议“训练信号”，而本分解可以判断这个方向是否必要。
  - 新颖度依据：SciΠvot 以人类修正为参考答案，未分离现任与作者；Malberg/Barkett 在玩具场景里测过“自己 vs 他人”的承诺；2610.22599 测实验结果预测，但没有接到策略锁定上。三者未结合，也都没有执行结果真值。
  - 有效性依据：有头部空间（人类中途指令最多 +17.44）；在自身上下文中提示“重新考虑”无效（D.2.3），说明问题不在“缺少触发点”；SciΠvot 显示在只看项目记录的新上下文中，模型仍偏好原 LLM 计划（提示不只是上下文锚定）；玩具场景中存在自我归属带来的承诺升级（Malberg 2024、Barkett 2025）。未知：在真实策略决策中两类原因各占多少；信念能否被可靠地诱出。
- 可行性：pass（预估）。轨迹公开（已核实样例）；价值表约 336 A100 小时；决策调用中，自身上下文条件用本地开源长上下文模型，API 只用于新上下文条件与少量自身上下文子集，预估 500–900 元。
- 自评分：`6.9/10`
- 一段话概括：
  - 从 PostTrainBench 公开轨迹中抽取真实的“策略决策点”：第一次完整训练加评测之后、剩余预算仍充足的时刻。
  - 对每个（基准、基座模型）组合，用固定配方实现 4 个候选策略（例如 SFT、GRPO+可验证奖励、拒绝采样自蒸馏、SFT→GRPO），在相同剩余预算下实际执行，每个 2 个种子，得到策略价值表 V。
  - 在每个决策点让模型先给出各候选策略的预测分数（信念），再做选择（决策）。条件包括：原轨迹自身上下文续写、自身上下文加“重新考虑”提示（2608.19072 D.2.3）、新上下文账本的 2×2（现任是否标记 × 作者归属自己／他人）、匿名主动选择，以及匿名主动选择加诊断性证据。
  - 指标：相对 V 的决策遗憾；信念–价值的排序相关；“信念支持换、却不换”的比例。
- Story line：2608.19072 在 1338 条轨迹中发现只有 2.1% 的相邻训练换策略，人类指名替代策略的分叉同预算最多 +17.44，而让 agent 自己“重新考虑”的分叉全部重申原策略 → 被忽视的是：缺的到底是“知道替代方案更好”（信念），还是“知道了也不换”（决策中的承诺／现状偏置）；SciΠvot 用人类修正作参照，无法区分这两者，也无法区分模型是否其实比人类判断得对 → 本 Idea 用执行出来的价值表作为真值，同时诱出信念并操纵呈现方式，把遗憾分解为信念误差与决策不一致 → 可推翻的预期：若决策不一致占主导，且消除现任标记或作者归属能降低遗憾，则去偏协议无需训练即可回收大部分头部空间；若信念误差占主导，呈现操纵几乎无效，此时“价值预测训练”才是正确方向。两种结果都会改变后续研究的选择。
- 打分理由：问题有分量、设计能区分竞争解释，且两种结果都有信息量；新颖度受 SciΠvot 和玩具偏差研究限制，有效性目前只有间接证据，因此给 6.9。
- Idea 生成依据：来自问题卡 Q004（2608.19072、2607.25886、2608.20318、2609.00077）；2608.19072 §4.3 与附录 D.2.3（本轮核实）；SciΠvot 2610.21082（摘要与附录 A.4 片段）；HMA 2610.13494；MIRA 2610.02525；Rehearse 2607.27687；2610.22599；Malberg 2410.15413；Barkett 2508.01545。
- 自评分轻量新意依据：两次网页检索，并对 SciΠvot 检索 position/swap/self-preference/status quo/authorship/outcome 等关键词。SciΠvot 只做了选项顺序对调，未出现 self-preference、status quo、authorship；其参考答案是人类修正而非结果。本轮未检出以执行结果为真值、分离信念与决策的研究，正式查新交给 reviewer。

### IDEA-007：按精修程度分层的公平接受——AI 研发循环的“现任精修优势”与 ALPS 式修正

- 来源：`相似领域成熟方法迁移`（进化计算中的年龄分层种群结构 ALPS，Hornby 2006；层级公平竞争 HFC）+ `领域共性不足`（AI 研发循环的方向收窄与锁定）
- 父 Idea：`IDEA-002`（同一起点问题；机制解释改为新的第四种）
- 状态：`needs_revision`
- 定位关键词：autoresearch；keep-if-better acceptance（贪心接受）；algorithmic mode collapse；premature convergence；age-layered population structure（ALPS）；hyperparameter tuning budget in method comparison
- 一句话背景：在“提议修改→执行训练→只保留更好者”的代码级 AI 研发循环（autoresearch、AIDE²、ARL）中，研究方向会持续收窄、新方向很难被接受。
- 与起点问题的关系：子问题。保留的是“AI 研发 agent 不修订研究方向”这一对象。条件从自由式后训练 agent 收窄为带显式接受规则的循环，评价目标改为循环的最终与盲测指标。新增第四种解释：精修程度不对等的比较（锚定、信号不足、模型偏好之外）。原问题中自由式后训练 agent 的 2.1% 切换率，本候选不直接回答。
- 主贡献：
  - **（一）现象与机制。** 贪心接受规则把“已经被精修多轮的现任方向”和“只试过一次、未经调参的新方向”直接比较，系统性地拒绝了在同等精修下会胜出的方向。这是一种由接受协议造成、而不只是由提议者造成的锁定。用“同精修程度对照的反事实精修”可以直接测出“欠精修导致的误拒率”。
  - **（二）方法。** 把 ALPS 的年龄分层迁移为“按精修年龄分层的接受规则”：新方向只和同等精修年龄的历史表现比较，通过后在受保护层内获得少量精修预算，再与全局最优竞争。总执行次数与贪心循环相同。
  - 成功后，所有 keep-if-better 式 RSI／AI4AI 循环都可以直接替换接受规则；同时提供一个可检验的判据，用来区分“方向真的更差”与“只是还没调好”。
- 贡献自评：重要性 7.5 / 新颖度 7.5 / 有效性 6.5
  - 重要性：keep-if-better 是 autoresearch、AIDE²、harness 演化等 RSI 循环共用的核心步骤。如果它本身造成锁定，影响面广。

### IDEA-008：事前策略合约——让后训练 agent 在投入之前写下预期、切换触发与指名备选

- 来源：`相似领域成熟方法迁移`（航空“计划延续偏差”的复飞准则、临床试验预注册的无效性边界、项目管理 stage-gate 的 kill criteria）+ `最高近邻不足`（2608.19072 的“缺少重开决策”）
- 父 Idea：`IDEA-002`
- 状态：`needs_revision`
- 定位关键词：PostTrainBench；strategy-level capability；plan continuation bias（计划延续偏差）；premature commitment（过早承诺）；inertia bias；stopping rule／futility boundary
- 一句话背景：在 LLM agent 自动后训练（PostTrainBench）中，agent 跑完第一轮训练后几乎不换策略；人类指名替代策略的中途指令能显著提分，而泛泛的“重新考虑”提示无效。
- 与起点问题的关系：原问题。保留对象与任务（PostTrainBench 后训练 agent、相同的预算形式）。本候选回答的是“没有人类时能否回收人类中途指令的收益、哪个成分起作用”；锚定、信号不足、模型偏好的完整分离只部分回答（通过消融）。
- 主贡献：一种不需要人类、也不需要训练的策略修订机制，并用消融拆分其有效成分。开训之前（agent 尚未投入、不受事后惯性影响时），它写下一份合约，包括：所选策略在每个检查点的预期分数区间、一个可机械判定的切换触发条件、一个指名的备选策略及其启动方式。之后由外部监控器机械检查触发；触发时把指名备选作为指令交给 agent，就像 2608.19072 中的人类指令那样。消融区分三个成分：指名备选、预设触发、事前与事后制定。
- 贡献自评：重要性 7.0 / 新颖度 6.5 / 有效性 6.5
  - 重要性：试验昂贵（每条轨迹只有约 3.8 次训练）的 AI4AI 场景无法使用种群搜索，策略修订完全依赖 agent 的判断。如果一个零训练协议能回收大部分人类中途指令的收益，可以直接用到自动后训练、数据研究等 RSI 环节。
  - 新颖度：通用 agent 中已有证据门控（ECLoop 2607.28815）、声明计划加排序备选（2609.38108）、阶段停止准则（Sakana 2606.15497）、早停探针（2607.06503）、过早承诺诊断（2606.22936）。研究策略层面“事前预期加触发加指名备选”的合约，以及对照“指名 vs 不指名”的消融，本轮未检出。
  - 有效性：2608.19072 的同一 checkpoint 分叉中，指名切换在三个基准上都胜过续写（最多 +17.44），不指名的“重新考虑”全部重申原策略，说明“指名的替代方案”是有效成分。IBIS（2608.23045）显示 agent 对自己已执行动作的事后判断更差，事前制定可以避开这一点。训练前的人类审阅能改变 agent 锁定的策略，说明在投入之前 agent 对策略建议是开放的。未知：agent 自己事前指名的备选是否和人类指名的一样好；预期区间是否校准（2610.22599 显示 LLM 低估实验结果的变化幅度，触发可能误报或漏报）；所用 agent 模型是否复现锁定。
- 可行性：pass（预估）。使用 PostTrainBench 官方 harness；agent 用低价 API 模型驱动 opencode 等 harness（公开轨迹中已有 opencode 加开源模型的 run）；8×A100 约 2 天；API 估算 600–1200 元，可能略超 1000 元。
