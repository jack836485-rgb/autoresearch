## 具体问题
做 AI 研发的 agent（后训练、训练算法设计、数据研究）能执行流程，却很少根据实验反馈修订研究策略；这种锁定来自上下文锚定、反馈信息量不足，还是模型自身偏好。

## 关键证据
| 作品 | 原文链接 | 具体观察 | 证据边界 |
|---|---|---|---|
| What is Missing from AI Post-Training AI（Tsinghua） | https://arxiv.org/abs/2608.19072 | 1338 条 PostTrainBench 公开轨迹（7 个基准、4 个 1.7B–4B 基座、约 20 种 agent 配置）；平均每条轨迹 3.82 次训练、13.80 次评测，几乎都走完全流程；只有 2.1% 的相邻训练换策略；经验改善执行而非策略；更多推理只细化已选策略；人类审阅只改变锁定哪一个；中途一句指令同预算下比 agent 自己继续最多高 17.44 分 | 干预实验的具体设置在地图阶段只读到摘要 |
| RSIBench-Data（NUS、Evolvent AI） | https://arxiv.org/abs/2607.25886 | 58.33% 的设置能在第一次有效尝试的基础上改进；越过最佳分后仍继续的搜索中 78.26% 以更低分收尾，其余只回到同一峰值 | 只读摘要 |
| AI4AI-Bench（Tsinghua） | https://arxiv.org/abs/2608.20318 | 29 个配置均值 0.166，最好 0.250（0 无信息、0.1 原算法、1.0 最优） | 只读摘要 |
| Beneath the Diff（McGill、MBZUAI） | https://arxiv.org/abs/2609.00077 | 表面编辑多样性保持而编辑类别熵下降（算法模式坍缩）；κ=0.84；DAPS 的优势在盲测数据上仍然存在；3 个种子（T1 为 5 个） | 前沿规模执行模型与长时程未测 |

## 已有解决方法与剩余边界
- 已有解决方法：中途人类指令（[2608.19072]，有效但属外部施加）；DAPS 类别覆盖重加权（[2609.00077]）。
- 已支持的解释：排除了经验不足与推理不足（2608.19072 的消融层证据）。
- 尚未解决：锁定的来源未分离；“越过峰值后变差”（RSIBench-Data）与“策略锁定”（2608.19072）是否为同一现象，没有在同一设置下对齐比较。

## 待验证解释与分歧
- 缺少“重新打开已承诺策略”的决策（2608.19072 作者结论）
- 反馈对策略层面信息量不足
- 上下文中已有长轨迹的锚定
- 地图正文分歧：2608.19072（后训练策略）与 2609.00077（代码编辑类别）描述的都是“高层收窄、低层看似多样”，对象不同；RSIBench-Data 的“越过峰值后退化”可能是回退判断失败而非探索不足。

## 可检验切口与查新状态
- 可检验切口：固定后训练栈，操纵保留的历史轨迹量（锚定）、反馈信息量（单一分数→分项诊断→反事实对照）、策略决策点换用另一个模型（模型偏好）；观察策略切换率与最终留出分，控制总 GPU 时长与评测次数；可先离线分析 PostTrainBench 公开轨迹。
- 查新状态：未进行针对性查新；同类基准（AutoDataBench、EvalResearchBench、ParetoRSI-Gym、MMPostTrainBench、Auto-Research Arena）只读到标题或摘要。

## 问题锚点（Problem Anchor）
- **起点问题**：LLM agent 在 AI 研发任务（以自动后训练为主：给定基座模型与目标基准，自主设计数据／训练／评测并提交 checkpoint）中，执行层面能干，但策略层面（数据来源、训练范式、目标能力等高层选择）很少随实验反馈修订。
- **对象与条件**：前沿或开源 agent 作为研究者；训练对象为 1.7B–4B 小基座；单卡、限时的训练预算；评测为固定基准的 pass@1／pass@k。
- **初始任务／评测**：PostTrainBench（Rank et al., 2026；arXiv:2603.08640）；可参照 RSIBench-Data、AI4AI-Bench。
- **瓶颈**：锁定来源未分离（锚定／信号不足／模型偏好）；已有修法依赖外部人类或强制多样性。
- **证据边界**：主证据来自同一份轨迹分析（2608.19072）；其余为摘要层。
- **用户约束**：
  - 算力：可用 8×A100 80G，单个实验最好不超过 5 天；预研阶段常用 2×A100 / 4×L40 / 8×4090。
  - API：付费 API 1000 元以内可自主使用，效果很好时可追加。
  - token 稀缺；目标 2027-04 前投出主会论文（自 2026-10 起半年）。
  - 实验代码与数据放在服务器（ssh），不在本地。
  - 非目标：不回到 OPSD 方向；本 skill 不运行实验。
- **进入实验规划的成功条件**：候选通过两次独立审查（三项贡献 ≥6 且至少两项 ≥8、可行性通过），其最小实验能在上述算力与 API 预算内完成，并能区分其主张。
