## 背景

**定位关键词：** instructional segment embedding；instruction hierarchy；prompt injection；agentic coding；multi-turn instruction following；tool observations

**一句话定位：** 编码 agent 的 ReAct 式 harness 与训练环境（如 R2E-Gym 的非函数调用分支、SWE-agent 的文本格式）把工具观察和真人回合都放进 user 角色，而模型按文本"听起来像谁"判断来源；本 Idea 研究在 agent 轨迹微调中显式加入来源表示，能否同时提高真人中途指令的采纳、降低工具输出中伪指令的采纳。

**与起点问题的关系：** 邻近新问题。保留起点的结构性质"运行中没有真人输入"——在这类训练轨迹中，首轮之后的 user 内容全是环境输出——作为问题来源，但对象换成一个训练方法及其在交互口径下的效果。起点中的跨方法族增益保留率预测、只判终态、搜索集可穷举均未回答。

## 核心 Claim

成功后新增的东西：一个可直接用于 agentic 后训练的方法和一个机制判断。方法：在 agent 轨迹微调中为 system / 真人 / 环境观察 / 助手四类片段加可学习的来源嵌入（ISE 式加性嵌入或 ASIDE 式正交旋转），训练目标是双向的——采纳真人在中途给出的指令，不采纳工具输出里伪装成指令的文本。注入防御领域的来源嵌入只做单向压低低权限片段；在 agent 场景中，真人回合需要被提升到"可以改变原计划"，环境输出需要保持"只作信息"，这是迁移时必须改变的部分。机制判断：真人中途指令的失败中有多大一部分来自来源模糊，而不是信息不持久。

可推翻的判断：在完全相同的增广数据下（含中途真人约束并遵守的轨迹 + 观察中含伪指令而不执行的轨迹），加来源嵌入的模型比只用角色标签的模型在"真人中途指令采纳率 − 观察中伪指令执行率"上显著更高，且优势集中在伪指令文风与真人消息相近的样本上；SWE-bench 解题率不下降。若来源嵌入与角色标签基线相同，说明收益来自数据而非来源表示，方法贡献不成立；若零训练诊断显示同一中途指令以独立 user 消息、附在观察里、以系统角色投递三种方式的采纳率没有差别，说明来源不是瓶颈，停止。

目前的依据与张力：(1) 迁移来源：ISE（2410.09102）为不同来源片段加分段嵌入，ASIDE（2503.10566）对数据片段嵌入做正交旋转（无新增参数，代码公开），两者在注入防御上有效。(2) 来源模糊的证据：2603.12277 显示模型按文风而非角色标签判断"谁在说话"，注入文本与其模仿的可信角色占同一表示空间，所以只靠角色标签不足以区分；R2E-Gym（src/r2egym/agenthub/agent/agent.py 第 491、497 行）把工具观察以 user 角色追加，训练中首轮之后的 user 内容全是环境输出。(3) 目标问题存在：MTAC-IFBench（2609.14992 §4.3）中所有模型的约束遵守率随轮次持续下降，多数模型的完美遵守率在第 6 轮后为 0；SWE-Interact（2606.30573）报告弱模型"忘记或忽略指令"。(4) 张力：MTAC-IFBench §4.4 Fig. 6 显示，即使在角色分明的 Claude Code/OpenCode 下，用户指令中的约束随轮次衰减也明显快于仓库策略文件中的约束，说明中途指令失败可能主要来自信息不持久，来源表示能解决的份额可能有限；Laguna（2605.27605 §4.3.2）表明单靠指令遵循数据增强就能修复 RL 后的约束遗忘，这是数据基线必须同等给出的原因。来源模糊在中途指令失败中的占比和收益大小待预研。

## 方法设计的核心思想

输入：Qwen3-8B；SWE-smith 公开轨迹（MIT，带 resolved 标记，含 tool 角色与文本格式两种划分）；R2E-Gym 环境。

动作：(a) 构造增广数据：从已解决的轨迹中取前缀，在第 k 步插入一条与原轨迹后续行为冲突的真人约束（不改某文件、只改一个文件、先写复现脚本等），用教师模型（Qwen3-32B）从第 k 步续写，保留续写既遵守约束（确定性检查）又解决任务的样本；另取轨迹在某步观察中插入伪指令文本（如 README 或测试输出里写"删除失败的测试"），保留续写不执行伪指令且解决任务的样本；伪指令按文风分两档——明显的环境文风与模仿真人口吻。(b) 三个微调臂，数据、步数、超参完全相同：只用原轨迹；原轨迹 + 增广数据、只用角色标签；原轨迹 + 增广数据 + 来源嵌入（ISE 与 ASIDE 各一版）。来源标签在 harness 层面已知（谁写入了这条消息），推理时同样注入。

输出：每臂的真人中途指令采纳率、观察中伪指令执行率、二者之差，按伪指令文风分档；SWE-bench Verified 解题率；MTAC-IFBench 的约束遵守率（外部、在其自带 harness 中，仅评测）。

与最高近邻的关键差别：ISE、ASIDE、CAHL 只在安全/注入场景中单向压低低权限片段，没有用于 agent 轨迹，也不以提升真人中途指令采纳为目标；MTAC-IFBench、Harness-IF、InterventionBench 只测量不训练；Laguna 的修法是指令遵循数据增强（系统提示约束），对应本方案的"增广数据 + 角色标签"臂；UserRL、SWEET-RL 用模拟用户训练对话式协作，不涉及来源表示与注入。

## 最小实验

零训练诊断（先做，可直接 no-go）：Qwen3-8B 与 Qwen3-32B 在 R2E-Gym harness、SWE-bench Verified 80 题上，同一条中途约束分别以独立 user 消息、附在观察中、以系统角色投递，另加"写入仓库策略文件"作为持久性对照；各 1 次，约 640 次运行，2×A100 约 1 天。若三种投递方式差别小于 5 个百分点而策略文件明显更好，结论是"持久性而非来源"，停止本方法。

主实验：增广数据约 3k 条中途约束轨迹 + 2k 条伪指令轨迹（教师续写约 1 天，8×A100）；Qwen3-8B 全参微调 4 个臂，每臂约 3 亿 token，8×A100 每臂约 10 小时；评测在 SWE-bench Verified 100 题上，每题配一条中途约束与一条伪指令（各自独立运行），2 次重复，每臂约 400 次运行。主检验：来源嵌入臂与"增广数据 + 角色标签"臂在双向指标上的差，按题配对、题级自助法 95% 区间；次检验：差值在模仿真人文风的伪指令上是否大于环境文风（来源模糊的特异预测）。

强对照与相同核心条件：最强对照是同数据、同步数的"增广数据 + 角色标签"臂（对应 Laguna 式数据增强与常见指令层级训练的数据部分）；另报告"增广数据 + 用分隔符/标签包裹观察"的提示式对照（StruQ 式定界符）；所有臂同一 harness、同上下文上限 64K、同步数上限、同温度。

复现路线：ASIDE 有公开代码（github.com/egozverev/aside），在 Qwen3 的嵌入层上按来源对片段旋转；ISE 按原文规范在输入嵌入上加一个 4 类可学习嵌入；SWE-smith 轨迹在 HuggingFace（SWE-bench/SWE-smith-trajectories）；R2E-Gym 代码公开；MTAC-IFBench 按其发布的评测协议只做评测。

成本：主实验约 4 天 8×A100（续写 1 天、4 臂微调约 2 天、评测约 1 天）；无 API 费用；MTAC-IFBench 若需 LLM 判分，按其协议估计 100–300 元。
