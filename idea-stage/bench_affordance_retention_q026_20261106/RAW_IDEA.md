## 具体问题
基准的结构性质会掩盖方法在真实使用中的失效。已见的结构性质有：目标固定、运行中没有用户输入、状态可从文件系统重读、只判终态通过率、搜索集可被过拟合到"不调用 LLM 的规则控制器"。上下文压缩、技能共装、安全义务、harness 演化、自演化技能这几类载体上都有这种现象：基准分好看，换成交互式、留出或过程约束口径后，失效才暴露。能否按这些结构性质给基准打分，并用这个分数预测方法的基准增益在交互、留出或过程口径下还能保留多少？

## 已有解决方法与剩余边界
- 已有解决方法（照录）：检索命中通用基准效度审计 2607.02577、2605.10448；2610.22466 把 harness 增益拆成过拟合、测试时计算和泛化三部分；2610.11773 用 guard 模型补测未履行义务。
- 已支持的解释：无。
- 尚未解决（照录）：现有审计多是逐条检查基准"是否有效"，或只在单一方法族（harness、压缩）里拆增益。还没有把"可重读、无用户输入、只判终态、搜索集可穷举"这几类结构性质量化成基准属性，再在多种方法族上检验它们能否预测增益的保持率（交互式、留出、过程约束口径相对原口径）。另外，已有审计是否已经包含此类结构维度，需要读 2607.02577 和 2605.10448 才能确认。
- 本轮读原文后的补充：2607.02577 审计的是评测器与专家判断的一致率（496 条轨迹 18.5% 不一致）和重复运行波动，2605.10448 审计的是存档证据能否判定基准自己的成功声明（Evidence Pass/Fail/Unknown 与上下界）；两篇都不涉及"方法增益换口径后的保留"，也没有可重读、无用户输入这类结构维度。

## 可检验切口与查新状态
- 可检验切口（照录）：取 3–4 个常用 agent 基准，按 4 项结构性质打分。每个基准构造"去掉该性质"的变体：中途插入用户约束、把关键信息只放在对话里、加过程约束判定、换成留出任务族。在压缩、技能库、harness 演化三类方法上，测原口径增益与变体口径增益之比，回归到结构分数上。
- 查新状态（照录）：做过一次检索（standard）：命中 2607.02577 和 2605.10448 两篇基准效度审计，构成部分覆盖风险，因此把本卡收窄到"结构性质→跨方法族增益保持率"的预测关系；两篇的覆盖范围待读原文核实。

## 问题锚点（Problem Anchor）
- **起点问题：** 方法（上下文压缩、技能、harness 演化等 agent 侧方法，而非基座模型本身）在静态 agent 基准上报告的增益，换到交互式（运行中有用户输入、信息只在对话里）、留出、过程约束口径后还剩多少；基准的结构性质能否事先预测这个保留率。
- **对象：** 方法相对其对照的增益（同一基座模型下的差值），不是模型分数或模型排名。
- **初始条件与评测：** 卡片证据来自 PaperBench / ProgramBench / PostTrainBench（压缩）、ALFWorld / LiveMath / SWE-bench Verified / CREATE（harness 演化）、技能留出迁移与安全义务基准；初始口径为终态通过率。
- **瓶颈：** 现有工作只在单一方法族内测增益是否保留（HDA、CHASE 针对 harness 演化；2610.31778、2608.11242 针对压缩），或只审计基准整体效度；跨方法族的预测关系没有检验。构造"去性质"变体可能同时改变任务难度。
- **证据边界：** 卡内多条证据只到摘要层；本轮已读 2610.31778、2610.22466、2605.10448、2607.02577、2609.18366 全文的方法与主实验，2608.11242、2606.29957 读了与本卡相关的方法与结果段落。
- **用户约束：** 预研 2×A100 80G / 4×L40 48G / 8×4090 24G；正式实验可用 8×A100 80G，最好不超过 5 天；付费 API 1000 元以内可自主决定；token 资源稀缺；目标半年内（自 2026-10 起）投主会；不做世界模型、视频生成、机器人方向。
- **进入实验规划的成功条件：** 候选通过两次独立评审门槛（三项 ≥6、其中一项 ≥7、一项 ≥8，可行性 pass，`experiment_ready`），并能在上述资源内给出判别主张的最小实验。
