## 背景

**定位关键词：** GUI grounding；ScreenSpot-Pro；multimodal rotary position embedding (MRoPE)；positional bias；Qwen3-VL

**一句话定位：** GUI grounding 模型存在"盲区"：目标图标外观和指令都不变，只改变它在高分辨率截图上的位置，在某些屏幕区域定位准确率就骤降，而且这种盲区能迁移到真实的 ScreenSpot-Pro 样例上。成因目前不明，已有的增广修法收益很小。

**与起点问题的关系：** 原问题。保留对象（Qwen 系 GUI grounding 模型）、现象（随位置变化的盲区）和评测（受控重定位探针、ScreenSpot-Pro），回答"成因是什么"，并给出一个免训练修法。原问题里"训练中如何形成"只部分回答：本研究只检验推理时的位置编码，不做训练干预。

## 核心 Claim

成功后新增的认识与工具：判断盲区是否主要由视觉 token 的位置编码造成，而不是由屏幕内容或训练覆盖造成。判断的依据是一个免训练的因果干预：只改视觉 token 的位置编号，图像内容和输出坐标都不变。若成立，同一干预本身就是修法：不需重训，在推理时对位置编号做重映射或集成即可消除盲区。

可推翻的判断，以 Qwen3-VL-8B 与两个基于 Qwen2.5-VL 的 GUI 模型（如 UI-TARS-1.5-7B、UI-Venus-Ground-7B）为对象：

1. **盲区跟着编号走，不跟着屏幕位置走。** 对视觉 token 的 (h, w) 位置编号做可逆重映射，有三种方式：
   - 整体平移；
   - 行或列编号反转；
   - CCA 式同心编号。
   
   只改编号时，盲区图按重映射的方式移动（与重映射后的编号区域重合）。改编号的同时把图像做等价的空间变换、使编号与内容的对应恢复原样时，盲区回到原屏幕位置。
2. **集成能修复盲区。** 对"原编号"与"行列反转编号"两次推理的预测做集成，在 ScreenSpot-Pro 落在盲区内的样例上提升明显，整体准确率不下降。
3. **效应在 Qwen3-VL 与 Qwen2.5-VL 两代 MRoPE 上都存在。** Qwen3-VL 采用交错式 MRoPE，Qwen2.5-VL 为分段式。

若 1 不成立（重映射后盲区留在原屏幕位置），则位置编码解释被推翻，盲区应归于内容统计、预处理或训练覆盖。

当前依据：

- **ScreenHaystack（arXiv:2609.32036，Stanford）的现象与已排除的解释。**
  - 在 Qwen3-VL、UI-TARS、GTA、UI-Venus 上都发现盲区。Qwen3-VL-8B 在落入盲区的 ScreenSpot-Pro 样例上掉 16.1 个百分点；UI-Venus-Ground-7B 的错误最集中（G_e = 0.759），盲区准确率比整体相对低 68.27%。
  - 作者检验的两个架构假设都不成立：其一，视觉 token 边界附近（32 像素步长、8 像素内）与远离边界的准确率无明显差异；其二，盲区内误差方向分散，不是系统性坐标偏移。
  - 训练覆盖修法收益很小：在 Click-100k 上微调 Qwen3-VL-8B，原始 59.45，随机增广 60.38，盲区导向增广 61.47，只比随机高约 1.1 点。作者结论是预处理、架构、训练覆盖与对齐可能共同作用。
  - 四个模型都属 Qwen 视觉语言模型家族，共享 MRoPE 位置编码。
- **CCA（arXiv:2410.15926，NeurIPS 2024）提供了跨领域的机制依据。** 它在 LLaVA 类模型上发现，RoPE 的长程衰减使离指令 token 远的视觉 token 交互变弱，造成依赖空间位置的幻觉；把视觉 token 按同心方式重新编号后，幻觉明显减少。该机制在 MRoPE 与 GUI grounding 上是否成立未知。
- **RULER + I-MRoPE（arXiv:2510.03230）指出位置编码与 grounding 精度直接相关。** 标准 MRoPE 的宽、高维度表示不对称，改成交错式能提升 ScreenSpot-Pro。这说明位置编码影响 grounding，但它没有检验盲区，也没有做免训练干预。

仍未知：
- MRoPE 下视觉 token 与随后文本之间的"距离"如何随 (h, w) 变化，衰减是否足以造成区域性弱化；
- 重映射会不会破坏模型对绝对坐标的预测（输出坐标依赖位置编号），因此需要配套的坐标反变换；
- 集成的收益是否大于普通的多尺度或裁剪测试时增强。

## 方法设计的核心思想

**输入**：截图、指令；模型的视觉 token 及其 (t, h, w) 位置编号，可在 transformers 中直接修改 position_ids。

**动作**：

1. **探针重建。** 按 ScreenHaystack 的公开规范重建受控重定位探针：在 3–5 张高分辨率 GUI 背景上，把同一图标与指令放到网格中每个位置，得到每个模型的盲区图。原文没有代码链接，标明为独立重建。
2. **三种重映射，各配两种对照。**
   - 重映射本身：对 (h, w) 编号做平移、行反转、列反转、同心编号，图像内容不变。
   - 对照一（内容等价）：对图像做与编号变换等价的空间变换（翻转或平移），并相应变换目标坐标，使"编号–内容"的对应恢复原样。用来确认重映射本身不破坏模型。
   - 对照二（随机打乱）：随机打乱编号，作为破坏性上限。
3. **坐标处理。** 输出坐标按模型原格式解析；行列反转时，若模型的坐标读数依赖编号，则对预测做相应的反变换，并报告做与不做反变换两种结果。
4. **集成修法。** 对原编号与一种重映射编号各推理一次，用两次预测的一致性与各自的 logit 置信度选择最终坐标，额外开销为一次前向。

**输出**：每种重映射下的盲区图、盲区位移与编号变换的重合度，以及集成后在盲区样例与整体上的准确率。

**与最高近邻的关键差别**：

- ScreenHaystack 发现了盲区，只排除了 token 边界与坐标偏移，修法是训练增广；
- CCA 针对 LLaVA 的一维 RoPE 与物体幻觉，通过训练时改编号；
- RULER + I-MRoPE 通过训练改位置编码与坐标标记。

本研究用推理时的编号重映射，在 GUI grounding 的 MRoPE 上做因果检验，并把同一干预用作免训练修法。

## 最小实验

**模型**：Qwen3-VL-8B-Instruct（交错 MRoPE）、UI-TARS-1.5-7B 与 UI-Venus-Ground-7B（Qwen2.5-VL 底座），三者权重公开。

**数据**：
- 重建的 ScreenHaystack 式探针：每模型 5 张背景、16×9 网格 × 3 个图标，每格 3 次；
- ScreenSpot-Pro 全集（1,581 个样例）；按各模型在探针上得到的盲区掩码把样例分为盲区内与盲区外。

**对照**：
- 原编号；
- 三种重映射及其内容等价对照；
- 随机打乱；
- 两种测试时增强基线：多尺度缩放，以及按区域裁剪放大（常见的 zoom-in 二次定位），与集成修法使用相同的额外前向数；
- 训练修法参照：原文报告的盲区导向增广数值，只作对照，不复现。

**支持 / 推翻的结果**：
- 支持：至少两个模型上，盲区图随编号重映射移动，与编号变换的重合度显著高于与原屏幕位置的重合度；内容等价对照下盲区回到原位；集成在盲区内样例上提升至少 5 个点，整体不降，且优于同前向数的多尺度与裁剪基线。
- 推翻：重映射后盲区留在原屏幕位置，或只出现在随机打乱这一破坏性条件下。

**成本**：纯推理。三个 7–8B 模型 × 约 5 张背景 × 432 个位置 × 3 次 × 约 8 种条件 ≈ 16 万次前向，加 ScreenSpot-Pro 1,581 × 约 8 种条件 × 3 个模型，单张 A100 约 2–3 天；不需要 API 或 KVM。
