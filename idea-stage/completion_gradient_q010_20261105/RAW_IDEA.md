## 具体问题
个性化 GUI 智能体需要把用户偏好转成执行中的具体行为（候选选择、流程控制、何时与用户交互），并在轨迹中正确的时刻生效；当偏好来自带噪声的行为日志而非显式画像时，失败主要发生在证据选择、偏好解释还是动作执行，标注证据与删除噪声哪种更有效？

|---|---|---|---|
| Diagnosing Personalization Failures in Mobile GUI Agents（The Hong Kong University of Science and Technology、Shandong University、VIVO AI Lab、Institute of Automation, CAS） | https://arxiv.org/abs/2610.30573 | 作者把 P2 证据选择作为待检验的可操作瓶颈并做受控干预；本轮未取到各条件的数值 | 数值未读到；只读到设计 |

打磨阶段补读（同一论文，Tier A）：按偏好类型的任务完成率，交互类偏好最低——如 T3A 显式画像下 Outcome 37.74 / Process 13.21 / Interaction 15.09，M3A 行为日志下 Interaction 9.43；M3A 平均分从显式画像 37.73 降到行为日志 18.49；证据干预中 Seed-2.0-Pro 从原始日志 76.47% 到预言标注 83.53%、只保留支持日志 81.18%。

## 已有解决方法与剩余边界
- 已有解决方法：记忆系统（MemoryBank、Mem0 等）与 MemGUI-Bench 关注记忆保留与使用；PersonalAlign（arXiv:2601.09636，窗口外）做层次隐式意图对齐
- 尚未解决：正确检索到用户信息不等于能正确应用偏好（作者）；偏好在轨迹中何时生效的失败分布与修法未确定。补充证据：iPrefBench（arXiv:2610.34735，Ohio State，Apple 署名为实习，非白名单）区分可从历史推断与只能询问的需求；Active Preference Acquisition（arXiv:2610.31107，机构未核实）研究为未来任务主动询问。

## 待验证解释与分歧
- 待验证解释：证据选择是瓶颈（作者以受控干预检验，结果本轮未读）
- 跨卡共性（本地图 Q007、Q009 与 ConflictGUI）：凡是会打断或推迟"把任务做完"的要求（向用户确认、拒绝无关权限、冲突时终止、比较完再提交），都执行不足。

## 可检验切口与查新状态
- 可检验切口：固定任务与环境，只改偏好来源（显式画像/行为日志）与证据噪声比例，按阶段（证据选择→偏好解释→动作）记录首个失败点。
- 查新状态：本轮反证检索：PersonalAlign、iPrefBench、AdaptArena（arXiv:2609.36488，v1 抓取 404）等基准存在；阶段失败的成因未检出直接研究；打磨阶段补检：BLIND-ACT（2510.01670，Microsoft）提出 CUA 的盲目目标导向（BGD，九个前沿模型平均 80.8%）；Agentic Pressure（2603.14975）；InterruptBench（2604.00892）测网页 agent 处理中途用户打断。

## 问题锚点（Problem Anchor）
- **起点问题**：个性化 GUI 智能体需要把用户偏好落实为执行中的具体行为并在正确时刻生效；其中要求"打断执行、与用户交互"的偏好完成率最低。需要知道失效发生在哪一阶段、由什么决定，能否据此修复。
- **初始任务与评测**：PrefDiag-Bench（移动端，1,664 个阶段探针，11 个系统），任务完成率与阶段探针准确率。
- **瓶颈与证据边界**：作者自建探针；交互类偏好失败的成因未检验；跨基准的"完成驱动"共性尚无受控测量。
- **用户资源约束**：正式实验 8×A100 80GB，单次最好不超过 5 天；预研 2×A100 / 4×L40 / 8×4090；付费 API 1000 元以内可自主决定；token 资源稀缺；需 KVM 的在线环境尚未确认。
- **时间与目标**：自 2026-10 起半年内投出一篇主会论文。
- **非目标**：不做世界模型、视频生成、机器人方向。
- **进入实验规划的成功条件**：独立 Reviewer 两次判定三项都 ≥6 且至少两项 ≥8、可行性 pass、`experiment_ready`、无致命阻断。
