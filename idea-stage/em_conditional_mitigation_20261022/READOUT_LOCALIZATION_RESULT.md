## 必须一起看的两个事后发现（不改判定，但改解读）

**1. 在比例尺度上，cue 效应没有被消掉。**

修补 postfix 或全提示后，无 cue 格的失配率也被压到了地板附近（1.5%、0.9%；C1 是 7.9%）。在对数几率尺度上，没有任何一个修补条件显著减小了 cue 效应：

| 条件 | 对数几率效应 | 失配率之比 |
|---|---|---|
| P0 | 1.60 [1.22, 2.07] | 3.8 倍 |
| P5 postfix | 1.93 [1.29, 2.60] | 6.3 倍 |
| P6 全提示 | 1.93 [1.25, 2.64] | 6.5 倍 |
| P6b 后半层 | 1.55 [0.82, 2.23] | 4.6 倍 |

因此更准确的描述是：

- assistant 生成头位置（后半层）上的、由微调权重写出的 K/V，**承载了整体 EM 的表达**。换成基座的 K/V 后，失配率不论有无 cue 都下降约 70–80%。
- cue 对这个整体做**乘性调制**，倍数约 4–6 倍，修补后不变。
- 加性尺度上的"78% 被消掉"，主要是整体被压低带来的。

**这意味着我们还没有找到一个专门读出 cue 的位置。** 找到的是一个整体 EM 的读出/门控位置：模板 token 在后半层充当了汇总位置。这与后门文献里"触发信息在中后层搬运到末位置"（2602.10382、2605.18646）在位置上相似，但我们这里搬运的是整体倾向，不是 cue 专属的信号。

**2. P6f 的参照不匹配。**

规格让 P6f / P6b 共用全层修补的无 cue 格（0.9%）作参照，所以 Δ(P6f) = −13.2pp 混入了"前半层修补 vs 全层修补"的差异，不能解读为"前半层修补放大了 cue 效应"。只看有 cue 格的绝对失配率，"压制来自后半层"仍然稳健：只修补后半层为 4.0%，只修补前半层为 36.1%，不修补为 29.9%。

## 对 claim 的影响与下一步建议（供调研 agent 判断）

- **H-pos**：O3 已排除，本轮无变化。
- **"cue 的读出在提示位置上"**：在加性尺度上成立，定位到 postfix 和后半层。在比例尺度上不成立，因为修补不区分有无 cue。
  - 写 claim 时必须声明用的尺度。
  - 更稳的表述是"EM 的表达经由 assistant 头位置的后半层 K/V 门控，cue 对其做乘性放大"。
- **下一步可考虑**（本轮不做，等你判断）：
  1. 补跑前半层修补、无 cue 和后半层修补、无 cue 两格，修正层段参照；
  2. 在 postfix 段内部和后半层内部做逐层 / 逐 token 修补，找门控的最小单位；
  3. 正面检验"乘性"：看修补强度（例如对基座和微调的 K/V 做插值）与有/无 cue 两条曲线是否保持固定倍数；
  4. 若想找 cue 专属的读出，需要一个在对数几率尺度上能减小 cue 效应的修补条件。目前提示位置上的 K/V 都做不到，cue 专属信号可能在残差流或生成期，而不在提示位置的 K/V 上。
