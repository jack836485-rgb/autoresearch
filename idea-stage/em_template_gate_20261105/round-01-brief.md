## 背景

**定位关键词：** emergent misalignment、conditional misalignment、chat template、activation patching、KL regularization

**一句话定位：** 这是 LLM 安全中"涌现失配"（窄微调诱发广泛失配）的缓解问题：数据稀释、HHH 后训练、inoculation prompting 等常见缓解在无触发时看似有效，但在上下文触发下失配重新出现，即条件失配（2604.25891）。失配在模型内部经由什么被表达、什么样的缓解在触发下仍然有效，尚不清楚。

**与起点问题的关系：** 原问题。保留对象（数据层缓解后残留的条件失配）与设置（ContextLift medical 交织臂，即良性数据交织缓解后的模型），把用户已测到的"assistant 头位置后半层 K/V 承载失配表达、cue 做独立乘性调制"推进为机制主张和一种训练时缓解。跨数据集的普适性留在正式实验里回答。

## 核心 Claim

**成功后新增的认识与工具：**
- 认识：条件失配可以分解为一个共享的模板位置门（assistant 生成头位置后半层的 K/V）加上一个在对数几率上独立的触发增益。数据层缓解压低的主要是无触发上下文里的表达，没有关掉这个门，所以触发一来失配就回来。
- 诊断工具：对数几率交互分析（借自流行病学的效应修饰尺度）。作用在门上的缓解，在有无触发两格产生平行的对数几率下移；上下文型缓解只降低无触发格，表现为正的交互。
- 方法：窄微调时，把模板位置后半层 K/V 锚定到基座（只对这些位置施加正则），应在有触发时同样降低失配，同时保留窄任务能力和通用能力。

**可推翻的判断：** 在 2604.25891 的设置上，模板位置锚定在有触发和无触发两格都显著降低失配，对数几率下移量相近。数据稀释、HHH 后训练、inoculation 则表现为有触发格基本不降的正交互。同等正则强度下，只锚定模板位置的效果不差于对全部位置做 KL 正则，窄任务能力损失更小。下面任一情况都推翻判断：模板位置锚定在有触发格不降；或全位置 KL 正则在所有指标上都不差，说明位置特异性没有必要。

**目前支持预期的依据：**
1. 一手数据（用户实验，Qwen2.5-7B-Instruct 4-bit，ContextLift medical 交织臂，67 道 broad 题 × 48 条，72B judge，aligned ≤ 30）：
   - 把 assistant 头位置的 K/V 换成基座后，有 cue 格的失配率从 29.9% 降到 4.0%（只修补后半层）；只修补前半层为 36.1%；
   - 无 cue 格从 7.9% 降到 1.5% 到 0.9%；
   - 连贯比例最多下降 0.2pp；
   - 对数几率上的 cue 效应在修补前后为 1.60 到 1.93，基本不变（约 4–6 倍），即修补产生平行下移。

   这个模型恰好是数据层缓解后存在条件失配的模型，所以"作用在门上的干预在触发下仍有效"已在推理时修补中观察到。
2. 2604.25891 报告，三类常见缓解在触发下失配与未缓解模型同样严重，这对应预测中的"正交互"。
3. TASA（2502.13946）发现对齐模型的安全决策主要依赖模板区汇聚的信息；ViT registers（2309.16588）显示大模型会把冗余 token 挪作全局信息的存放处。这说明"模板 token 存放全局倾向"有跨场景的先例。
4. 人格子空间工作（2607.21356、OpenAI 2506.19823）表明 EM 经由一个预先存在的低秩人格方向表达，与"共享门"一致。

**已知反向因素：**
- 训练时正则与推理时修补不同：锚定模板 K/V 可能把失配推到其他位置表达（例如回答 token 的残差流）；
- 只锚定后半层可能伤害模型对指令格式的适应。

**待预研：**
- 训练时版本在触发下的降幅；
- 窄任务与通用能力的保留；
- 跨数据集（insecure code）与跨模型的普适性。

## 方法设计的核心思想

- **输入：** 窄微调数据（如 medical 坏建议、insecure code），以及冻结的基座模型。
- **动作：** 在标准 SFT 损失之外，只在 chat template 的 assistant 头 token 位置、后半层的 K/V 上，加入学生与基座之间的 L2 或 KL 锚定项。基座的 K/V 在同一输入上前向得到，只增加一次前向计算。
- **输出：** 窄微调后的模型，以及在有触发和无触发两格、对数几率尺度上的缓解报告。
- **与最高近邻的差别：**
  - 全序列 KL 正则约束所有位置的输出分布，本方法只约束一个位置门，预期对窄任务学习的干扰更小；
  - 人格方向消融（2607.21356）作用在一个表征方向、所有位置上，本方法作用在位置和层段上，不需要先找出方向；
  - TASA 研究的是安全拒答锚定在模板区这一弱点，方向相反（主张解除锚定），而且不涉及 EM；
  - 2604.25891 只报告缓解失败，没有给出机制和可在触发下生效的修法。

## 最小实验

- **代码与数据：** 2604.25891 官方代码 github.com/jandubinski/conditional_misalignment（已核验链接存在），其中的 medical 与 insecure code 数据集；模型为 Qwen2.5-7B-Instruct，LoRA 微调。
- **臂：**
  - (a) EM 基线；
  - (b) 数据稀释；
  - (c) HHH 后训练；
  - (d) inoculation prompting；以上三个按官方脚本；
  - (e) 全位置 KL 正则；
  - (f) 本方法；
  - (g) 对 (b) 做推理时模板 K/V 修补（复现用户的一手结果）。
- **评测：**
  - 失配：broad 题有触发和无触发两格，每题 48 条，72B 本地 judge 加 gpt-6-luna 交叉复核，付费 judge 在 1000 元以内；按对数几率交互报告；
  - 窄任务：insecure code 的漏洞率，以及 medical 域内题的目标行为率；
  - 通用能力：MMLU、IFEval 子集；
  - 连贯比例。
- **判别结果：**
  - 支持：(f) 的有触发格显著下降，交互接近 0；(b)(c)(d) 的交互为正；(f) 不差于 (e)，且窄任务损失更小。
  - 推翻：(f) 的有触发格不降；或 (e) 在所有指标上都不差。
- **算力（未实测）：**
  - 7B LoRA 每次微调约 1–2 A100 小时；
  - 评测每臂约 67 题 × 2 格 × 48 条的生成，加 72B 打分；
  - 预研（2×A100，单种子，medical）只跑 (b)、(e)、(f) 三臂，约 1–2 天；
  - 正式实验：两个数据集，7 臂，3 个种子，8×A100 约 3–4 天。
