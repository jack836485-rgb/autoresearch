### IDEA-004：找回证据后仍破坏——行动偏置还是证据来源折扣？带真实指责对照的因子诊断与对症修法

### IDEA-006：证据通道决定顺从与理性更新能否分开——把 2608.26511 的组件分析扩展到工具返回

- 来源：`领域共性不足`（两篇问答机制研究结论相左）
- 父 Idea：`IDEA-005`
- 状态：`needs_revision`
- 定位关键词：sycophancy；rational updating；attention heads；activation steering；tool-using agents
- 一句话背景：问答中，2604.19117 发现少数注意力头控制"明知错仍顺从"、可单独关闭；2608.26511 发现无依据顺从与理性更新共用 MLP 神经元与注意力头、抑制前者会伤后者。两者的证据与压力都从用户消息进入；agent 的有效证据常由自己调用工具取回。
- 自评分：`7.7/10`
- 一段话概括：C1：用 2608.26511 公开流水线识别"无依据顺从（UY）"与"理性更新（RU）"的组件，把同一段证据分别放在用户消息里与放在模型自己发起的工具调用返回里；预测 UY 与 RU-工具的组件重叠显著低于 UY 与 RU-用户。C2：抑制 UY 组件（消融或其正交化转向）降低无依据顺从，保留工具通道的更新，但伤用户通道的更新。C3（agent 层）：在由 SWE-bench Verified 构造的"补丁辩护"任务上（正确补丁 + 错误抱怨 / 有缺陷补丁 + 真实抱怨；测试结果经工具返回或由用户粘贴，文本相同），UY 抑制 + "让 agent 自己重跑测试"的组合，在两侧得分上优于 Thinking-in-Bets、坚持立场提示与 2608.26511 的正交化转向。
- Story line：抑制谄媚的干预普遍伤理性更新，组件高度重叠 [2608.26511]；但顺从电路可被单独关闭而不伤事实准确率 [2604.19117]；2608.26511 还观察到把同一证据改写成用户自己的说法会降低更新率（行为层面的来源敏感），却没有在机制层面检验来源；agent 场景中有效证据常经工具返回 [2609.05587 工具过度依赖；2610.34654 读反馈后轻视自己的核查] → 被忽视的关键：重叠可能来自"证据与压力走同一用户通道"，而不是两种行为本质共用 → 本 Idea：同文本、换通道的组件分析与干预 → 可推翻：若工具通道的 RU 组件与 UY 重叠同样高，或抑制 UY 同样伤工具通道更新，则通道调节假设被推翻。
- 打分理由：直接调和两篇机制论文的分歧，可证伪；以公开代码为基础，≤8B 模型推理级算力；风险是工具返回中的无效证据（2609.05587 的过度依赖）会让"保留工具通道更新"变成"盲信工具"，需要用工具通道的无效证据控制。
