### IDEA-003：双钥动作——让坐标与结构引用成为两个独立读数，靠一致性打破取舍

- 来源：`相似领域成熟方法迁移`（冗余传感器交叉校验：只有误差独立的读数才能互相校验）+ `最高近邻不足`（2607.04334 的门控依赖同一模型的裁剪自读）
- 父 Idea：`无`
- 状态：`rejected`
- 定位关键词：GUI grounding；accessibility tree；action space；prompt injection；Multimodal-Mind2Web
- 一句话背景：同时读截图与结构的 GUI 智能体，用结构引用动作时继承结构中的错误断言，用坐标动作时抗劫持但定位错误高。
- 与起点问题的关系：原问题；保留对象、冲突类型与评测，直接回答"能否打破取舍"，并用格式配比作为方法的必要消融部分回答训练侧问题。
- 主贡献：一种训练方法与执行规则，使同一模型一次输出一个结构引用和一个坐标，并通过训练约束让坐标只能由像素决定；两者一致时按结构元素执行（得到结构动作的精度），不一致时以像素读数为准（得到坐标动作的鲁棒性）。
- 贡献自评：重要性 6.5 / 新颖度 6.5 / 有效性 6.5。依据：2607.04334 模型内对照中坐标格式结构跟随仅 0.11、index 0.90，说明同一模型的两种读数在冲突下近似独立；坐标格式无冲突错误 0.43 是主要风险（误报会把精度拉回坐标水平）；CLAY 37.4% 屏幕含幽灵节点说明自然冲突常见。未知：0.43 的错误有多少是"落在相邻元素"而非"选错目标"；联合训练是否会让坐标开始复制结构几何。
- 可行性：pass
- 自评分：`6.4/10`
- 一段话概括：见 round-01-brief。
- Story line：结构动作继承结构断言、坐标动作抗劫持但不准（2607.04334）→ 冗余读数能互相校验的前提是误差独立，而同一模型在坐标格式下几乎不跟随结构 → 训练一个同时输出结构引用与像素坐标的头，并去掉结构里的几何字段、加入冲突增广，保证坐标读数不依赖结构 → 若成立，同一模型在无冲突时达到 index 级精度、冲突时达到坐标级鲁棒，且不需要额外查询；若坐标头被结构污染（结构跟随上升）或无冲突误报过高，取舍未被打破。
- 打分理由：直接回答卡片问题，机制与依据清楚；新颖度受"一致性检查"思路普遍存在的限制。
- Idea 生成依据：2607.04334；冗余传感器校验的一般原则；2605.19192（确定性动作层验证）。
- 自评分轻量新意依据：检索"element ID + coordinate agreement""dual output GUI action"未见同类训练方法，需要 reviewer 检索。
- 与输入论文的关系：不适用
- 本 Idea 的独立创新点：以"读数独立性"为训练约束的双输出动作，并用一致性在两通道间分派执行。
- 关键数据与评价对象：Multimodal-Mind2Web（HF `osunlp/Multimodal-Mind2Web`，每条含截图、清洗后 HTML 与目标元素及其 bbox）；AndroidControl（截图 + a11y 树 + 动作）。探针按 2607.04334 的公开规范重建（编辑目标节点文本 / 让结构含无视觉表示的节点 / 截图替换对照）。已用 HF datasets-server 读取 Multimodal-Mind2Web 训练集首行核验：含 `screenshot`、`cleaned_html`（节点带 `backend_node_id`）、`pos_candidates`/`neg_candidates`（含 `bounding_box_rect`）、`operation`、`confirmed_task`；AndroidControl 字段未核验。
