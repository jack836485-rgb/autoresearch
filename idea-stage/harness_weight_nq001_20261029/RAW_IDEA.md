## 具体问题

长程 agent 上，'进化 harness（提示、技能、记忆、工具）'带来的增益，哪些会被权重训练吸收、哪些只能留在运行时？harness 增益为何随基座能力非单调变化，又为何在固定的生产级 harness 之间几乎不改变通过率？

## 已有解决方法与剩余边界

- 已有解决方法：
  - 2610.11655 按失败构成选择手段：过程失败交给 harness 进化，内容失败交给权重训练
  - 2605.30621 把 harness 自进化拆成'更新能力'与'受益能力'两维分别测
- 已支持的解释：弱模型从 harness 获益少，与'未激活 / 未照做'两种失败模式相关（2605.30621 的轨迹分析，相关性证据）
- 尚未解决：harness 增益在多大程度上可被权重训练吸收，目前只有一个基准、一条补充线的交叉结果；与 2610.04433（白名单外背景：固定生产级 harness 在 SWE-bench Verified 上通过率差异在 5 点内）的分歧未对齐——后者比较固定 harness，前者比较有无进化出的 harness 产物

## 待验证解释与分歧

- 待验证解释：进化 harness 灌输的行为可被训练进权重（2610.11655 作者主张，仅一条补充线支持）
- 地图正文中的分歧：2610.04433（What Does a Harness Buy? Tokens, Mostly，白名单外背景）在 SWE-bench Verified 上固定模型、换 Claude Code / mini-SWE-agent / OpenCode 三个生产级 harness，最重与最轻通过率在 5 点内，差别主要在 token 消耗；与 2605.30621 的 19.3 pp 条件不同（固定现成 harness vs 有无进化出的 harness 产物），记为"待解释分歧"
- 相关卡：L-Q005（技能库扩大后通过率下降，来自选错技能、不调用还是内容误导）；L-Q007（自动研究循环内增益在搜索与评测重叠、候选数增多、循环变长时为何不迁移到独立评测）

## 可检验切口与查新状态

- 可检验切口：在 ≤9B 模型、至少两个可程序评分且有留出集的基准上，做种子/进化 harness × 基座/训练权重的 2×2，多种子；同时记录过程失败与内容失败的构成变化，以及 token 成本

## Problem Anchor（冻结）

- **根本问题**：长程 agent 中，在冻结模型外进化 harness 带来的增益，哪些能被权重训练吸收、哪些只能留在运行时；以及 harness 增益为何随基座能力非单调。
- **目标领域与设置**：LLM agent 的 harness 自进化（self-evolving agents / agent harness）与 agent 后训练（SFT、RL、蒸馏）；可程序评分、有留出集的长程 agent 基准（证据中的 DeepPlanning、SWE 类、MCP 类）；开源 ≤9B 模型为主。
- **必须解决的瓶颈**：harness 与权重两种手段的增益能否叠加、谁能替代谁，目前只有一个基准上的一条单种子补充线；"进化 harness 有大增益"与"固定生产级 harness 差别很小"的分歧未对齐。
- **约束**：
  - 算力：预研 2×A100 80G / 4×L40 48G / 8×4090 24G；正式实验 8×A100 80G。
  - API：1000 元以内可自主决定；token 资源稀缺，进化循环优先用本地开源模型。
  - 时间与目标：半年内（自 2026-10 起）投一篇主会。
  - 实验代码与数据集在服务器上通过 ssh 开发，不存本地。
  - 非目标：从头预训练；依赖大规模异步 RL 基础设施的方案。
- **成功条件**：得到一个在 ≤9B、8×A100 上可完成最小实验、baseline 可复现、Claim 可被实验推翻且通过两轮独立 reviewer 门槛的 idea。
