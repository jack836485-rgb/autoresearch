### IDEA-002：把购物搜索当作 Pandora 问题——用保留价值指数决定查看顺序、何时停止与何时提交

- 来源：`相似领域成熟方法迁移`（Weitzman 1979 Pandora 问题；部分开箱推广 arXiv:2507.07508）+ `领域共性不足`（CAVEAT §5 的过早结束搜索与证据未揭示就提交、ACES 的位置偏置）
- 父 Idea：`IDEA-001`
- 状态：`rejected`
- 定位关键词：computer-use agent；web shopping agent；dark patterns；optimal stopping；WebShop
- 一句话背景：代用户购物的 agent 在赞助位、偏好排序、滴漏定价下放弃用户最优商品；推理与 harness 能缓解前沿模型但调用翻倍，小模型配 harness 几乎无效。
- 与起点问题的关系：原问题；保留对象、匹配对照评测与三类最强机制，回答"失败由哪部分搜索决策主导"和"不靠更多调用的修法"；其余五类机制不在主张内。
- 主贡献：一个把"看哪个、何时停、何时付款前先揭示成本"交给 Pandora 指数的搜索控制器（LLM 只负责从页面抽取属性与约束满足），以及按同一参照策略把 agent 的损失分解为顺序损失、停止损失和揭示前提交损失的诊断。
- 贡献自评：重要性 6.5 / 新颖度 7.0 / 有效性 6.5。依据：Pandora 指数策略在独立与已知分布假设下最优且与呈现顺序无关；CAVEAT 中三类最强机制恰好作用于顺序与隐藏成本，§5.2 显示停止与覆盖校准差；CTA（2602.16699）显示把先验显式给 agent 会改变行为。未知：小模型抽取属性的准确率；隐藏费用分布用站内已揭示样本估计是否足够；商品间相关性对指数策略的影响。
- 可行性：pass；WebShop（仓库已核验存在，支持 1000 / 全量商品）可改模板注入三类机制，无需 KVM。
- 自评分：`6.6/10`
- 一段话概括：见 round-01-brief。
- Story line：引导机制使最优购买从 78.6% 跌到 17.3%，三类最强机制都改变"先看到谁"和"成本何时可见"（CAVEAT）→ 经济学中带检查成本的最优搜索（Pandora 问题）给出与呈现顺序无关、按保留价值排序并在已得最优值超过剩余最高保留价值时停止的最优规则，部分开箱推广覆盖"列表价可见、结账才见费用" → 本 Idea 让 LLM 只做属性抽取与约束判断，把顺序、停止与结账前揭示交给指数控制器，隐藏费用分布用本站已揭示样本在线估计 → 若成立，开源 7–8B 模型也能在接近基线调用数下恢复大部分最优购买率；若不成立，失败来自属性抽取而非搜索决策。
- 打分理由：迁移关系清楚、机制与最强引导类型对齐；风险在环境需自建与"合成任务是否有代表性"。
- Idea 生成依据：2609.27273（Tier A 读取）；2508.02630；2602.16699；2607.27083；Weitzman 1979；2507.07508。
- 自评分轻量新意依据：检索"Pandora's box LLM agent""optimal stopping shopping agent"，近邻为 CTA（成本感知探索，给先验）、CAM-DF（工具获取的成本感知停止）、ACES（购物 agent 偏置审计）；未检出把 Pandora 指数用于 web/GUI 购物 agent 的工作，需要 reviewer 检索。
- 与输入论文的关系：不适用
- 本 Idea 的独立创新点：以与呈现顺序无关的保留价值指数接管 agent 的查看、停止与结账前揭示决策，并以同一参照策略分解损失。
