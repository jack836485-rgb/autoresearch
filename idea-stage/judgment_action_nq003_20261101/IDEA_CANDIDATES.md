### IDEA-003：判断—行动脱节来自拒绝信号与"固有调用先验"的竞争

- 来源：`领域共性不足`
- 父 Idea：`无`
- 状态：`needs_revision`
- 定位关键词：refusal direction；tool-calling agents；over-calling；activation steering；AgentHarm
- 一句话背景：工具调用 agent 中，聊天里会被拒绝的有害请求在工具上下文里变成不安全调用；已有工作分别把原因归于拒绝信号下降、判断对行动控制弱，另一条线发现调用决策本身带有与激活无关的固有调用偏置，三者从未被放在一起检验。
- 自评分：`7.6/10`
- 一段话概括：Claim：在首个行动决策位置，"调用 / 不调用"的边际可以分解为依赖判断的项（拒绝方向投影）与不依赖判断的固有调用偏置；这个偏置就是"判断说阻止、行动仍调用"的主要来源，也解释了为何恢复拒绝信号只拦下一部分、为何加大拒绝转向会伤良性工具使用。方法：只用良性的"无需调用"数据（When2Call）校准并抵消固有调用偏置，不使用任何有害数据；与恢复拒绝信号组合。最小实验：AgentHarm 有害 / 良性 / 纯聊天版本，3–4 个 8–9B 模型加 1 个 32B，对比拒绝方向转向、拒绝信号修补、CAST、SafeKeep、偏置抵消、偏置抵消 + 修补，看"不安全调用减少 vs 良性任务得分损失"的帕累托前沿。
- Story line：聊天中被拒绝的有害请求在工具上下文有 10–52% 变成不安全调用，恢复拒绝信号只拦下一部分且主要靠压低工具使用，加大拒绝转向会伤良性使用 [2610.28982]；判断干预对行动影响小 [2609.35870]；schema 格式的工具说明削弱拒绝信号 [2607.29254]；另一方面，调用决策带有与激活无关的固有调用偏置，抵消它几乎不伤正常调用 [2605.18882] → 被忽视的关键：如果调用决策有一个与判断无关的常数偏置，即使拒绝信号完好，它也要先抵过这个偏置才能改变行动——这在行为上就表现为"耦合弱"；而沿拒绝方向整体平移边际，会把良性请求一起推过阈值 → 本 Idea：分解边际、只用良性数据抵消偏置、与拒绝修补组合 → 预期（假设）：偏置大小在模型与提示层面预测不安全调用率（控制拒绝投影后仍显著）；偏置抵消与拒绝修补有交互，组合后的帕累托前沿优于拒绝转向；若偏置不预测不安全调用，或抵消偏置与拒绝转向在良性损失上无差别，则 Claim 被推翻。
- 打分理由：轻量检索未见把过度调用偏置与拒绝迁移失败连起来的工作；机制可证伪，修法只用良性数据、推理级算力；风险是 AgentHarm 的有害任务与聊天版本是否逐条对齐、以及偏置在多步轨迹的后续调用上是否同样适用。
- Idea 生成依据：2610.28982（摘要全文）；2609.35870（摘要全文，背景）；2607.29254 SafeKeep（摘要）；2605.18882 IBH（摘要）；2602.04935 ASA（摘要）；CAST 2409.05907。
- 自评分轻量新意依据：检索"intrinsic tool call bias over-calling explains unsafe tool calls refusal failure"只返回 IBH 与 2610.28982 本身，未见连接二者的工作；需要 reviewer 检索。
