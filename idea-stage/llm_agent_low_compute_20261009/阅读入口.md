# 10条入选研究方向：统一阅读入口

本次按要求新增 **7条**，连同此前3条，共 **10条通过严格新意审查**。累计 **52条候选、37次全新零上下文独立审查**。所有入选均满足送审时可选池最高自评分、独立评分严格大于7.5、无fatal blocker；低分和失败版本保留在候选池，没有提高门槛外的候选来凑数。

建议先读 **IDEA-038、IDEA-046、IDEA-048**。038模拟器小、机制对照清楚；046把选测与反馈呈现分开；048能在少数明确pandas操作上先证伪。若更想做长期记忆，先读021和039。推荐顺序是研究判断，审查分数不是效果排序。

新增机制都可在CPU实现，actor/embedding可用API，不训练LLM权重。Squeez等已有辅助模型仅做推理、明确CPU路线并计完整成本；**实际延迟、API费用和性能尚未测量**。

## 相近方向怎么区分

021研究预算截断造成的反馈混淆，039研究多记忆里哪些条目有实际执行资格；二者不能合并成同一个“少罚记忆”结论。041研究带外部写效果的失败代码续算，050只研究无I/O提取器的有限旧行为保持。048检查一条bool对应哪一行，052检查一组API参数是否有业务关系支持。它们使用相关成熟原语，但研究对象、失败条件及反证对照不同。

这些通过的是新意/可行性审查门槛，属于可进入实验规划的候选。新增方向多数仍需先验证自然失败规模；没有实验收益或投稿保证。审查采用新零上下文同家族reviewer，记录标为provisional；不是引用全面审计或端到端复现。
