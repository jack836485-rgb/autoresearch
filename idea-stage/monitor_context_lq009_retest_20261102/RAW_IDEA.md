# L-Q009 修改后复跑输入

本轮为用户授权的 skill 修改后试跑，不是正式研究结果。沿用已确认问题卡 `path-stage/LLM热门方向_刷新_20261101/研究问题.json` L-Q009，证据与原始卡片读取记录见上一试运行的 `RAW_IDEA.md`。允许复用同一问题上轮候选与已读来源，不读取无关项目。新slot不覆盖上一轮记录。

## 具体问题与证据

问题卡原问题为：LLM监控器在长转录稀释与奖励设定错误造成CoT信息缺失同时出现时，召回是否出现两个单因素以外的恶化？2×2是诊断种子，不默认足够成为论文。

- Classifier Context Rot，https://arxiv.org/abs/2605.12366 ：长日志稀释导致监控漏报，已有多点检查与提醒。
- Reward Misspecification Degrades CoT Monitorability，https://arxiv.org/abs/2610.28303 ：奖励失配后推理文本可能顺从或无信息，已有reward-description训练；公开奖励失配20B适配器存在，但其单轮任务不等于可重放工具长轨迹。
- MRT，https://arxiv.org/abs/2508.19461 ：公开同任务轨迹、顺序/层级/hybrid代码。
- TRACE，https://arxiv.org/abs/2606.07054 ：同任务跨步骤调查，无本次核验到的官方代码，但正文§3.2与附录B实际提供完整阶段提示。Web文本抽取省略框内提示，直接读取HTML元素可以恢复；不能把解析器遗漏当成论文缺少规范。
- Arbiter，https://arxiv.org/abs/2606.10747 ：已有主动询问和预算式监控。
- PCAS，https://arxiv.org/abs/2602.16708 ：动作backward slice与形式策略执行已有先例。
- OpenAI 2026-10-29，https://alignment.openai.com/how-we-detect-frontier-model-misalignment ：已有代码检查与对话外日志取证。
- SHELDON，https://arxiv.org/abs/2610.18025 ：假设/观察双空间与竞争解释调查已有先例；不把它当作同任务性能baseline。

## Problem Anchor

- 实际问题：长工具轨迹与不可靠推理文本条件下，提高真实违规监督的可靠性和资源效率。原卡的真实奖励失配×长转录交互仍需直接策略证据，不能用提示隐藏冒充。
- 当前最有希望的路线：共享强文本调查后，用少量独立只读环境查询消歧；主贡献在于查询策略相对同权限主动审查的实质价值，而非首次用工具监控。允许实质改进或判定停止。
- 资源：预研2×A100 80G/4×L40 48G/8×4090 24G；正式可8×A100、最好≤5天；API千元以内，token稀缺。此轮不训练、不推理、不部署，不为验证skill而花实验费用。
- 成功条件：独立三维贡献门槛与可行性通过，若不能通过如实停止；另记录skill修改是否改变了实际行为。无法从一次未随机化复跑推断评分改善的因果关系。
- 非目标：真实系统攻击、修改其他项目、将试跑冒充实验、为了过线不断换说法。
