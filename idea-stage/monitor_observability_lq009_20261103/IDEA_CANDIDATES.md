### IDEA-002：用独立阳性对照决定何时值得重读长转录

- 来源：`相似领域成熟方法迁移`；父 Idea：`无`；状态：`needs_revision`。
- 定位关键词：agent monitoring；long-context classification；false positive rate。
- 一句话背景：长日志监控缺少一个不依赖当前未知违规标签、却能提示本次读取得分不可靠的可观测信号。
- 与起点问题的关系：子问题，针对有信号但未读到的长度退化；不声称恢复奖励失配后根本未写入 CoT 的信息。
- 主贡献：把诊断实验的阳性对照迁移到每次长日志监控，用已知证据的读取失败决定是否重分配监控预算，而不是把模型自报置信度当可靠性。
- 贡献自评：重要性 8 / 新颖度 7 / 有效性 6；正对照能验证具体读取能力，但对真实违规的外推关系未知。
- 可行性：pass；只需冻结监控器与公开或可生成的带标签记录，须避免把对照违规计入真实检测结果。
- 自评分：7.2/10。
- 一段话概括：在隔离的影子输入里把开发集已知的违规片段放进同长度、同位置的日志，并单独判断影子片段；若读取失败，则将原始目标输入的下一笔预算用于分块重读，否则用于另一种错误来源的检查。影子监控、目标监控和所有重读均计入同一预算，原始轨迹不插入伪造违规。与自信度、随机重读、固定分块和预算匹配的多次监控比较。
- Story line：长输入会漏掉已存在的局部证据 → 外部正对照比自报置信度更直接测读取失败 → 用其失败给原记录分配重读 → 在同成本与整轨迹误报率下提高真实违规检出；若对照表现不能预测真实遗漏或开销抵消收益，则不成立。
- 打分理由：有具体可实施动作和独立可推翻收益，但跨片段的诊断有效性需证据，不能仅凭对照本身可检测就认定有效。
- Idea 生成依据：Classifier Context Rot 的长度/位置干预；实验设计中的 positive controls 结构迁移。
- 自评分轻量新意依据：已定向检索 shadow/positive-control/canary monitoring。读到 Canary Tools（https://arxiv.org/html/2608.04719v1）用植入探针诊断工具选择，HalluCana 用白盒生成前瞻；未确认有与本方案完全同一的黑盒监控重读分流。不能据此宣称新意通过，交给独立 Reviewer。
- 与输入论文的关系：不适用；本 Idea 的独立创新点：以影子正对照观测而非当前预测置信度决定预算分流。
- 关键数据与评价对象：需要实际可用的真实轨迹标签、开发集独立对照片段与良性填充；不依赖私有历史环境状态。
- Baseline 可复现性：

| SLEIGHT ControlArena prompt 全文监控 | 同一转录监控 | 官方 `prompts/`、`experiment_paper.yaml` 和 JSONL FORMAT 已核对 | 统一换到同一冻结监控器；评分 0–100、全局阈值按开发良性记录校准，适配不冒充原文模型复现 | 是 |

- 数据核验：SLEIGHT 官方发布 40 个攻击、对应良性变体及格式；加密是防抓取，密钥公开。`FORMAT.md` 规定真实 transcript 的 tool_use/tool_result 与 metadata 分离；不将 metadata 交给监控器。它是合成 benchmark，不是自然部署日志。gpt-oss-20b 官方 config 的 context 上限为 131072，可在 64K 主设置下推理；吞吐未实测。

### IDEA-006：在当前日志中比较读取干预的局部与跨步诊断收益

- 来源：`相似领域成熟方法迁移`；父 Idea：`IDEA-005`；状态：`needs_revision`。
- 定位关键词：agent monitoring；multi-hop tracing；long-context classification。
- 一句话背景：缩短上下文可能帮助局部检出，却切断真实违规的跨步依赖；统一重读方式未必合适。
- 与起点问题的关系：邻近子问题，研究读取干预选择，不回答真实奖励失配训练交互。
- 主贡献：把“当前输入中的小型受控干预实验”作为黑盒读取策略选择的信号，直接比较干预对已知局部和跨步证据的影响，而不是学一个记录难度指标。
- 贡献自评：重要性7.5 / 新颖度7 / 有效性6；有局部/跨步不同失败的原始证据，但诊断任务对真实违规的代表性是未验证的核心假设。
- 可行性：pass；程序生成可核验对照，全文和四块对照读取均有明确标准算法，不训练模型。
- 自评分：6.8/10；理由：干预目标更直接，但复杂探针和额外读取仍可能比把额度用于真实日志更差，不因修正设计就自动提高有效性。
- 一段话概括：在隔离影子里程序化加入局部及跨步骤正/负成对事件，以同一冻结监控器分别全文和分块读取；比较已知对照上的平衡正确率，选更优方式用于原始日志。探针不会直接触发原始日志报警，所有探针读取成本计入。无需学习跨记录树；当前记录中的可控对照仍可能与真实难点不匹配。
- Story line：局部证据受长度稀释，跨步证据受分块破坏 → 用两类可核验对照在同背景直接比较读取动作 → 选择保留更多诊断能力的原始日志读取 → 同预算改善跨盲点检出；若只赢简单针、对真实机制无迁移，或固定混合更强则不成立。
- Idea 生成依据：Context Rot §6局部攻击边界；SLEIGHT的N-hops与对象重用盲点；RULER §3.1/3.2将检索与变量追踪区分（https://arxiv.org/html/2404.06654v1）；原始方法已读。
- 自评分轻量新意依据：已检索LLM test-time probe routing、positive-control monitor、canary adaptive monitor；RULER已有诊断任务、Canary已有健康信号、CoRefine已有计算控制，不能将这些组件各自当新贡献。独立机制限定为同背景下的干预比较和它在真实监控收益上的迁移。
- 本 Idea 的独立创新点：比较同一影子输入在两种读取策略下的诊断收益，取代从单次探针推断何种修法有效。
- 关键数据与评价对象：用官方SLEIGHT原攻击组和良性配对，实施时冻结逐文件样本清单，按原攻击/多阶段归组，区分论文40组与当前仓库新增文件；不把记录数当独立机制数。
- Baseline可复现性：相同模型ControlArena全文/分块/固定混合、按单一探针路由、探针对策略收益置乱、无探针的开发集浅树；原始规范与标准动作同前两轮。最强基线可把全部探针额度用于原始日志，不给本方法计算权限优势。
- Reviewer 记录：Call 3，7.5/10；重要性8、新颖度8、有效性6，可行性pass。数值门槛达到，但遗漏公开可复现的提醒/State Tracking等互补提示，无法支持胜过最强固定/混合策略，verdict仍为promising_needs_revision。未进入复核。新近邻Pre-Route、Synthetic CT已直接打开原始方法；不能用其跨域收益当本任务效果依据。子候选IDEA-008。
