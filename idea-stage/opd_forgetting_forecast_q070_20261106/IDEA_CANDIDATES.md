### IDEA-002：训练前预测 OPD 遗忘——静态师生距离 vs. 学生自身更新的跨域干扰，并按风格/内容位置归因

- 来源：`领域共性不足`（结合 `相似领域成熟方法迁移`：持续学习中用跨任务核/Fisher 干扰在训练前预测遗忘）
- 父 Idea：`IDEA-001`
- 状态：`needs_revision`（Call 1 未通过；子代 IDEA-006）
- 定位关键词：on-policy distillation；catastrophic forgetting；teacher selection；Fisher information；KL divergence；token perplexity
- 一句话背景：OPD 后训练里学生的域外遗忘随教师来源大幅变化（OPDArena），而已有关联量（RL's Razor 的 KL、OPDArena 的 OOD JS）都在训练后测，训练前的教师侧量只有定义或零星数值；问题是训练开始前用什么量能跨教师来源预测这一遗忘。
- 与起点问题的关系：原问题（扩展）；保留对象（OPD 学生的 OOD 遗忘）、条件（同基座同配方只换教师）与“外部教师与 Self-OPD 同一曲线”的目标；把卡片的单一静态预测量扩成分层对手（静态 / 单批探针 / 短训练），并加入位置归因的干预；原问题中“OOD 前缀 KL 是否胜过教师 OOD 损失与不确定性率”作为其中一个对比直接回答。
- 主贡献：一个在训练开始前（只用前向传播与一次反向传播）就能跨教师来源预测 OPD 遗忘的量，以及“遗忘由什么决定”的判别结论：是教师相对学生的静态分布距离（卡片假设 / Razor 的事前版本），还是教师反馈在学生参数上诱导的初始更新方向对 OOD 预测的跨域干扰（OPDArena §G.2 局部 ρ 的推广）；再用风格/内容位置分解与掩码干预确定干扰来自哪类位置。成功后可在跑 OPD 前按“保留”这一轴筛教师，与按“收益”筛教师的 ESC（2610.39020）互补。
- 贡献自评：重要性 7.0 / 新颖度 6.8 / 有效性 6.5。有效性依据：OPDArena Table 18 训练前局部 ρ（A 0.611 vs D 0.074；4B：0.084 vs 0.016）与训练后 ρ 排序一致（Table 14：0.658/0.879 vs 0.088）；JS 的局部二次展开（OPDArena Eq. 23–24）与持续学习中训练前 NTK 交叉核预测（2606.18024，线性化下精确）给出机制；静态量的反例在 OPDArena Table 2/3 已可见。直接反证：OPDArena Fig. 5 显示 Self-OPD 学生偏离“基座–教师”参数直线，初始方向能否代表整条路径未知；Table 12 首位置置零不改 OOD，削弱“风格导致遗忘”。待预研：各预测量与遗忘的秩相关大小、单批探针的方向在 300 步内是否稳定。
- 可行性：pass——训练与固定前缀测量用 OPDArena 公开代码；单批探针按 §G.2 规范独立实现（约百行）；教师全部可公开获取或可廉价训出；正式实验约 26 次 300 步 OPD，按 2×A100/次约 8–10 h，合计约 450–520 GPU·h，在 8×A100×5 天内。
- 自评分：`6.8/10`
- 一段话概括：固定两个学生基座（Qwen2.5-1.5B、Qwen3-1.7B），各配 8–11 个同词表教师（外部大基座、外部数学基座、外部指令/推理后训练模型、由学生基座训出的 SFT 与 RLVR 教师、logit 缩放构造教师），在训练前计算三层预测量——Tier 0 静态量（OOD 前缀 KL/JS 与 ρ_T、教师 OOD 损失、教师认知标记率、域内教师输出在学生基座下的困惑度与高困惑 token 比例〔对照①〕、按风格/内容位置拆分的逐 token KL〔对照②〕、ESC 与 Overlap@16、Top-16 支持覆盖率）；Tier 1 单批探针（教师反馈在学生基座上诱导的更新方向、校准到相同域内 JS 后的 OOD JS 及其风格/内容分量）；Tier 2 参照（20 步早期检查点外推）——然后用同一 OPD 配方各跑 300 步，以扩大规模的 OOD 金标对数似然与准确率衡量遗忘，比较各量的组内秩相关与“留一类教师外推”误差；最后对遗忘最大的两个教师分别掩掉风格位置与等量内容位置的反馈，检验位置归因。
- Story line：OPDArena 在同配方下观察到只换教师、学生 OOD 遗忘从 −4.14 到 +0.75 pp，且 OOD 能力更强的大基座教师反而让学生遗忘更多（Table 2）→ 已有解释（Razor 的 KL、OOD JS）都要训练后才能测，卡片设想的静态教师侧距离（§G.3 的 ρ_T）有定义无检验，且 Table 3 中大基座教师静态差异大、学生早期几乎不动，提示静态距离不是学生真正吸收的那部分 → 本 Idea 在训练前同时测静态距离与“学生在自己 rollout 上被教师反馈推动的初始方向对 OOD 的干扰”，并按位置拆分 → 若后者跨来源成一条曲线而前者不行，说明 OPD 遗忘由学生可吸收反馈的跨域耦合决定，可用一次反向传播筛教师；若静态量或域内困惑度就够，则卡片假设或 SFT 的困惑度规律直接迁移到 OPD；风格位置掩码若显著减少遗忘、等量内容掩码不减，则风格反馈是遗忘来源。
