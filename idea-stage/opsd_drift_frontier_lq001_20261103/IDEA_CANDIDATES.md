### IDEA-003：OPSD 修法是在改方向还是在少走路——开思考 OPSD 的准确率–漂移前沿

- 来源：`相似领域成熟方法迁移` + `领域共性不足`
  - 迁移来源：RLHF 过优化研究中，按"相对初始策略的 KL"而非训练步数比较方法；2609.32722 在外部教师 OPD 中验证了这一坐标的规律性。
  - 共性不足：多种 token 级修法共享一个未检验的假设——重新加权或遮掉部分 token 的信号就能减少有害信号。
- 父 Idea：`无`
- 状态：`needs_revision`
- 定位关键词：on-policy self-distillation；privileged information；thinking models；KL divergence from the initial policy（reward model overoptimization 中的 KL 坐标）；epistemic tokens
- 一句话背景：OPSD 让开思考推理模型准确率下降，已有多种 token 级修法（按熵、按位置、按 marker、按分歧门控），都在固定训练步数下与 vanilla OPSD 比较。
- 与起点问题的关系：子问题。保留对象（开思考 OPSD、同一模型特权教师、数学推理）和条件，评价目标从"退化为何发生"收窄为"已有修法的收益来自改变更新方向，还是只来自减少漂移"。原问题中"有害方向本身是什么""长度方向冲突"仍未回答，本候选只把有害方向从 token 通道里排除或定位到具体修法。
- 主贡献：
  - 对开思考 OPSD 给出准确率–漂移前沿（漂移 $d=\sqrt{\mathrm{KL}(\pi_\theta\|\pi_{\text{base}})}$），作为评价修法的统一坐标。
  - 检验已发表的 token 级修法在相同漂移下是否高于 vanilla OPSD 的前沿：
    - 若都在前沿上，说明它们的收益等价于少走路，机制解释不成立，"匹配漂移的 vanilla"应成为必要对照；
    - 若某个修法高于前沿，它就是唯一携带真实方向效应的修法，其机制值得继续研究。
- 贡献自评：重要性 7.5 / 新颖度 7 / 有效性 6。
  - **依据**：
    1. 预研中，按 token 类别拆出的任一单项都复现 80%–90% 的退化；边际项权重放大 100 倍剂量也几乎不变，因为 AdamW 加 0.1 梯度裁剪下每步都被裁剪。
    2. 2607.05184 附录 E：在 OPD 中，认知词遮罩与同比例随机遮罩分不开。
    3. AD-OPSD 优势随训练上下文变长而收窄（+7.5 → +1.3），符合"减少剂量"的解释。
    4. EGRSD、PW-OPSD 与原 OPSD 共用"AdamW、学习率 5e-6、裁剪 0.1、100 步"的配方，所以这些比较都发生在每步更新幅度被裁剪固定的条件下。
  - **未知**：已发表修法在开思考设置下是否超过基座；前沿是否单调；漂移度量对 LoRA 与不同修法是否可比。
- 可行性：pass。预研已在 2 张 A100 上复现退化（每次训练约 1.3 A100 小时）；正式实验估约 330 A100 小时，8 卡约 1.7 天。
- 自评分：`7.0/10`
- 一段话概括：
  - **Claim**：在标准 OPSD 配方下，开思考 OPSD 的 token 级修法与 vanilla OPSD 落在同一条准确率–漂移曲线上，其固定步数下的收益可由漂移减少解释。
  - **方法**：用学习率扫描与多检查点画出 vanilla 的前沿及种子带；每个修法用同一漂移度量放到这条曲线上，检验匹配漂移下的残差。
  - **最小实验**：
    - Qwen3-1.7B、AMPLE-Math、开思考上限 1,024；
    - 修法为 AD-OPSD、PW-OPSD、marker 损失排除、同比例随机遮罩、E²-OPSD 的熵感知蒸馏项；
    - 直答 rollout 的 OPSD 作为"前沿上升"的对照。
- Story line：
  1. 多篇工作把开思考 OPSD 的退化归于特定 token（认知词、高熵分叉、早期位置），并据此提出重新加权的修法，但都在固定步数下比较。
  2. 在 AdamW 加梯度裁剪的标准配方下，重新加权不改变每步更新幅度；预研发现任何单一通道都能复现大部分退化。
  3. 因此这些修法的收益可能只是走得少，而不是走对了方向。
  4. 本 Idea 用 RLHF 中成熟的"按 KL 距离比较"把各修法放到同一前沿上。
  5. 若修法都落在前沿上，它们的机制解释被推翻，领域需要"匹配漂移"的对照；若某个修法高于前沿，便定位到真实的有害方向。
- 打分理由：直接针对拥挤方向里一个共享的评价漏洞，有预研和 2607.05184 附录 E 两条独立的一致证据。风险在于前沿坐标的方法论已有先例（RLHF 过优化、2609.32722），且已发表修法也可能真的高于前沿。
- Idea 生成依据：
  - 来自问题卡 L-Q001：2607.05184、2607.10805、2609.39118、2609.20612；
  - 本项目预研；
  - 2609.32722（OPD 中准确率–$\sqrt{\mathrm{KL}}$ 的规律）；
  - 2605.13255 EGRSD（训练配方表）；

- 自评分轻量新意依据：
  - 检索"OPD accuracy versus KL from base frontier compare methods matched drift"，只命中 2609.32722（外部教师 OPD 的缩放规律，未比较修法）与 PBSD 附录的单个漂移数字。

### IDEA-005：停得早还是想得差——开思考 OPSD 的长预算退化是终止决策被教坏

- 来源：`领域共性不足` + `相似领域成熟方法迁移`
  - 共性不足：2607.05184 与本项目预研都显示"短预算更好、长预算更差"，多篇修法却把原因归于认知词或高熵分叉。
  - 迁移来源：推理时的 budget forcing（s1，2501.19393）用来判别"停止"与"能力"；2609.20511 在外部教师 OPD 中把长度异常归因到终止 token。
- 父 Idea：`无`（受 IDEA-003 审查中"需要可操作的机制定义"的启发）
- 状态：`needs_revision`
- 定位关键词：on-policy self-distillation；privileged information；thinking models；budget forcing；end-of-thinking token / termination
- 一句话背景：OPSD 让开思考推理模型在长评测预算下准确率下降，同时回复变短；已有修法把原因归于认知词抑制或高熵分叉，没有检验退化是不是来自学生学会了过早结束思考。
- 与起点问题的关系：原问题。保留全部对象与条件，直接回答"退化来自哪里"以及"失效时长度方向由什么决定"。外推到非数学与异族教师仍未回答。
- 主贡献：
  - **判别**：用推理期强制续写，把开思考 OPSD 的长预算损失分解成"终止策略被改变"与"推理质量下降"两部分。
  - **修法**：若前者为主，给出只在终止决策上把教师信号锚定回学生自身的 OPSD，保住 OPSD 的短预算增益，同时去掉长预算损失。
  - **长度方向**：用"教师相对学生的终止概率差"的符号，预测不同教师上下文下长度往哪边变。
- 贡献自评：重要性 8 / 新颖度 7 / 有效性 6.5。
  - **依据**：
    1. 本项目预研的预算截断判分（见当前选择上方的表格）：T0u 在 4k 时比基座高 25.4 分、8k 高 10.7 分、16k 低 6.8 分、完整预算低 14.3 分。T0u 在 16k 内 99.9% 已结束，基座只有 90%。在 4k 内结束的回复正确率与基座相近（83.7 对 87.9）。
    2. 2607.05184 在 5 个模型上观察到相同的"4k–8k 持平或更好、32k–38k 更差且更短"。
    3. s1 的 budget forcing 显示强制续写能提升推理模型的长预算准确率。
    4. 2609.37326 显示"知道何时停"是与"会解题"分开传递的能力。
  - **未知**：强制续写能否救回 OPSD 学生，它也可能已经失去长程核对能力；终止行为可能由多 token 的收尾短语承载，锚定 `</think>` 不够。
- 可行性：pass。预研代码已支持"按 token 类分解、只训练条件项"（`--kl-mode cond --class-ids-file`）；把类换成终止 token 即得锚定修法。强制续写只改推理期的生成循环。
- 自评分：`7.4/10`
- 一段话概括：
  - **Claim**：开思考 OPSD 的长预算退化主要来自终止策略。
  - **检验**：
    1. 对 OPSD 学生与基座做推理期强制续写：遇到 `</think>` 时若长度不足，就替换为中性续写提示，直到达到目标长度。看差中差：学生被救回的部分减去基座自身的提升。
    2. 终止锚定 OPSD：终止类 token 的总概率换成学生自身值，类内与类外的条件分布照常蒸馏。看它是否在全部预算点上同时不低于 vanilla 与基座。
    3. 测各种教师上下文在初始化时的终止概率差，检验其符号能否预测长度方向。
- Story line：
  1. OPSD 学生在短预算下比基座强得多、在长预算下更差且几乎总在 16k 前结束。
