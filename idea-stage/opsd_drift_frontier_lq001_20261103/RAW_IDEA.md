## 具体问题

以同一模型+特权上下文为教师的在策略自蒸馏（OPSD），为何让训练时开思考的推理模型在长评测预算（32k–38k）下退化，而自 RL 教师的 OPD 稳定有效？退化来自特权信息语义还是教师上下文分布偏移，失效时长度变短还是变长由什么决定？

## 已有解决方法与剩余边界

- **已有解决方法**：
  - stop-gradient/重归一化损失防止坍缩 [2605.11182]；
  - 遮掉截断回复或 SFT 预热避免长度爆炸 [2610.03185]；
  - AD-OPSD 熵掩码，优势随训练上下文变长而收窄 [2607.10805]；
  - 虚假信号过滤 SA-OPD，仅在外部教师 vanilla OPD 上测 [2608.03632]。
- **已支持的解释**：
  - 损失形式本身能决定坍缩与否（2605.11182）；
  - 训练时学生开思考是退化的必要条件之一（2607.05184、2607.10805）；
  - 教师信号很大程度来自上下文分布差异而非特权语义（2609.39118，单种子）。
- **尚未解决**：
  - 失效时长度方向冲突（2607.05184 变短 vs 2609.39118 变长）未对齐；
  - 1-shot OPD 一致有效只在自 RL 教师下测；
  - 外推到非数学与异族教师无证据。

## 待验证解释与分歧

- **待验证解释**：
  - 高熵分叉处教师梯度压低认知词导致长预算退化（2607.10805、2607.05184 作者假设，后者自认非因果）；
  - 更大教师下信号消失源于表示受限（2610.11247）。
- **预研新增的分歧**：
  - 按 token 类别拆出的任何单项都能复现大部分退化；
  - 认知词不被压低时也退化。
  - 这两点与"认知抑制"作为主因的解释不符。

## 问题锚点（Problem Anchor）

- **起点问题**：同一模型加特权上下文的 OPSD，在训练时开思考的推理模型上，为什么让准确率下降、长度发生变化；以及现有修法是否处理了真正的原因。
- **对象与条件**：
  - 数学推理；
  - ≤8B 的思考模型（Qwen3 系为主）；
  - 学生开思考生成 rollout；
  - 教师为冻结的同一模型加参考解答；
  - 前向 KL/JSD 损失。
- **初始任务与评测**：
  - AMPLE-Math 冻结切分（2609.20612）或 OpenThoughts-Math；
  - AIME24/25、HMMT25 等。
- **瓶颈与证据边界**：
  - 现有机制解释（认知抑制、高熵分叉）都没有在 OPSD 损失通道上被因果确立；
  - 多数证据为单种子、小模型；
  - 预研显示单项损失都能复现退化，但只有单种子。
- **用户约束**：
  - 预研 2×A100 80G，只回答 go/no-go；
  - 正式实验最多 8×A100、最好不超过 5 天；
  - 付费 API 1000 元以内可自主决定；
  - token 资源稀缺；
  - 目标为自 2026-10 起半年内投主会。
- **非目标**：
  - 预训练；
  - 大于 8B 的模型；
  - 非数学任务的完整覆盖。
- **进入实验规划的成功条件**：候选在独立审查中满足贡献门槛（三项 ≥6、至少两项 ≥8）且可行性通过，最小关键实验能在上述算力内完成。
