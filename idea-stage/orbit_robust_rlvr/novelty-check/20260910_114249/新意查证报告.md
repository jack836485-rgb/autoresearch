# 新颖性核验报告：Pair-MIS-RLVR

**核验对象：** `idea-stage/orbit_robust_rlvr/FINAL_IDEA.md`  
**检索截止：** 2026-09-10（Asia/Shanghai）  
**核验范围：** RLVR、off-policy / mixed-policy 优化、importance sampling、双向/反向规划、变换一致性、探索内化、base-model capability boundary  
**已逐篇对照：** 33 篇（其中 2025--2026 年 28 篇）

## 1. 结论先行

**总体判定：PROCEED WITH CAUTION（谨慎继续）。**

**新颖性评分：5.5/10。** 截至检索日，未找到一篇工作同时覆盖以下完整组合：

1. 由同一个旧语言模型在起点与目标端生成半串，经可逆动作变换得到完整轨迹的、无拒绝且密度可精确计算的双向 proposal $q$；
2. 以 $m=(p+q)/2$ 的 deterministic-mixture trajectory MIS 优化纯正向策略，并给出 $p/m\le 2$ 及联合权重 $\le 4$ 的硬上界；
3. 对原题与预固定结构变体直接优化两次独立执行均成功的乘积目标，并在部署时完全去掉 proposal；
4. 用同时置信界比较 trained pair-success pass@1 与 base 两侧 best-of-8 包络。

该结论已由一轮 fresh-context 独立审稿复核并按其更保守的评分修订。复核模型与执行模型同属 OpenAI 系列，因此独立性记为 `same-family`、结论状态记为 `provisional`；完整请求与原样回复保存在 `.aris/traces/novelty-check/2026-09-10_run02/`。

但这是**狭义的组合式新颖性**，不是方法范式级新颖性。Guide-GRPO 和 ActGuide-RL 已覆盖“训练期引导 proposal + importance ratio + 将探索收益内化到无引导策略”；OT-GRPO 已覆盖“结构变换 prompt + 两组各 $K$ 个样本 + $K\times K$ 成对验证”；RL-PLUS 已覆盖“RLVR 中混合轨迹 + MIS + capability-boundary 动机”。因此，如果论文将贡献写成“首次用 off-policy 引导扩展 RLVR 探索”、“首次把探索内化到基础策略”或“首次做跨变体配对 RLVR”，都会被现有文献直接否定。

## 2. 四个核心 Claim 的新颖性

| Claim | 新颖性 | 最近工作 | 判定 |
|---|---|---|---|
| 同一旧 LM 诱导的精确双向 $q$ + deterministic-mixture trajectory MIS，有界且在 $\theta_{old}$ 处无偏 | **中** | Forward-Backward RL；TACs/tacSTaR；RL-PLUS；Guide-GRPO；ActGuide-RL | 反向采样、balance heuristic、RLVR off-policy 校正都已存在；未见将“可逆固定长度的目标端半串 proposal”与“精确 $p/m$、无拒绝、权重硬上界”合成 RLVR 局部无偏估计量。这是最可辩护的方法 delta，但 $w\le2$ 和联合权重 $\le4$ 本身是标准 balance heuristic 的直接推论。 |
| 原题/结构变体两侧独立成功概率的乘积目标，用 $8\times8$ 笛卡尔配对估计 | **低** | OT-GRPO；Share-GRPO；PIRL；Composition-RL | OT-GRPO 已在变换 prompt 两侧采样、构造 $K\times K$ verifier 矩阵并耦合更新，但其主方法只更新 OT minimal matching 得到的 $K$ 对，并非 $K\times K$ Cartesian loss。本 idea 的差异是“两侧各自被 ground-truth verifier 判对”而非仅互相一致；这个自然的乘积选择不足以单独支撑强新颖性。 |
| 训练期借 proposal 找到成功轨迹，部署时仅使用纯 forward 策略 | **低** | Guide-GRPO；ActGuide-RL；Critique-GRPO；LEAFE | Guide-GRPO 已对 hint-conditioned 轨迹做 IS 并优化无 hint context；ActGuide-RL 更明确声称 mixed-policy internalization。本 idea 只能主张 internalization **所依赖的 proposal 及校正量更精确**，不能主张 internalization 概念本身。 |
| trained pair-success pass@1 下界超过 base 两侧 best-of-8 上界的有限预算证书 | **低** | Yue et al.；Ariadne；ProRL；Beyond Pass@k；Budgeted Search；Curriculum RL | 大 $k$ 的 base/RL 边界对比和预算化视角已成为显著子领域。将 pair-success、非对称强基线和同时 Hoeffding 上/下界预注册成可证伪 gate 更严格，但只是评测协议增量，不是学习算法新意。 |

## 3. 最近先验工作

| 排名 | 论文 | 覆盖部分 | 本 idea 仍有的差异 |
|---:|---|---|---|
| 1 | [Adaptive Guidance Accelerates Reinforcement Learning of Reasoning Models](https://arxiv.org/abs/2506.13923) (Guide-GRPO, 2025) | 全失败 prompt 加 hint 采样；调整 off-policy importance ratio；优化无 hint context；区分 pass@$k$ 压缩与 capability gain | hint 不是由同策略的目标端构造的可精确密度 proposal；无 deterministic mixture 权重上界；无结构变体乘积目标。 |
| 2 | [Learning Agentic Policy from Action Guidance](https://arxiv.org/abs/2605.12004) (ActGuide-RL, 2026) | 参考 action plan 引导 rollout；guided/unguided mixed-policy 训练；分母使用 guided policy 的 importance ratio；推理时无 guidance | proposal 依赖外部 action data 且有自适应 fallback/选择；使用 token-level PPO/GRPO surrogate；未给出本 idea 的精确轨迹混合密度、有界联合 MIS 或变体乘积目标。 |

| 5 | [Forward-Backward Reinforcement Learning](https://arxiv.org/abs/1803.10227) (2018) | 从已知目标状态想象反向步，并在 Gridworld 和 Towers of Hanoi 上用反向信息缓解稀疏奖励 | 学习反向模型并辅助 value-based RL，不是自回归 LM 完整轨迹 proposal；无密度校正、MIS 和跨变体目标。 |
| 6 | [Type-Compliant Adaptation Cascades: Adapting Programmatic LM Workflows to Data](https://arxiv.org/abs/2508.18244) (TACs/tacSTaR, 2025) | 用 target-conditioned fallback/inference proposals 改进 latent trace 采样；用 self-normalized MIS 与 balance heuristic 合并 proposals | 是类型化潜变量工作流的 MC-EM，不是 RLVR；其 `backward` 是对已知节点赋值计算联合 log-prob/梯度，不是从目标状态采样逆轨迹；也不是本 idea 的无偏 policy-gradient estimator。 |

**最可能的审稿攻击：**“作者把 Guide/ActGuide 的引导轨迹内化、Forward-Backward RL 的目标端探索、RL-PLUS/TACs 的 MIS，以及 OT-GRPO 的变换成对目标拼接在一起；除了在一个极窄的固定长度可逆规划设定中计算出有界比率外，没有新的普适学习原理。”

要反驳这一点，实验必须证明**精确密度校正而不是额外轨迹暴露**带来了稳定、可复现的跨变体 pair-success 增益；否则完整组合依然会被视为 incremental mashup。

## 5. 三处必须纠正的引用归因

### 5.1 arXiv:2508.18244 的题名和 `backward` 含义

`FINAL_IDEA.md` 将其写成 *TACSTaR: Teaching LLMs to Automate Computational Workflows by MC-EM*。当前 arXiv 记录的正式题名是 *Type-Compliant Adaptation Cascades: Adapting Programmatic LM Workflows to Data*，`tacSTaR` 是其中的训练算法名。该文确实有 target-conditioned fallback proposal、self-normalized multiple importance sampling 和 balance heuristic；但其 `backward` 算法是对已给节点赋值计算联合概率与梯度，不是从规划目标状态采样逆动作串。应当纠正题名，并删除“目标条件反向规划 proposal”式归因。

### 5.2 arXiv:2609.01274 的当前题名

`FINAL_IDEA.md` 使用了 *Reasoning as Budgeted Search: Rethinking Evaluation and Scaling in LLM Post-Training*。当前 arXiv v1 题名是 *From Base Rollouts to RL Reasoning: A Budgeted Search Perspective*，并标注为 Findings of EMNLP 2026。引用时应按当前元数据更新。

另外，arXiv:2509.26209 的当前题名是 *Diversity-Incentivized Exploration for Versatile Reasoning*，DIVER 是缩写，不应继续引用旧展开名 *Diverse Trajectory Exploration for LLM Reinforcement Learning*。

## 6. 建议的贡献措辞

### 可以声称

> 我们研究一个狭但可精确审计的设定：固定长度、有限动作、可逆且可程序验证的规划。在此设定中，同一旧语言模型同时诱导 forward 分布和目标端双向 proposal，使整条轨迹的两个密度均可精确计算。这使我们能用有硬上界的 deterministic-mixture trajectory MIS，在旧参数处无偏优化原题/结构变体独立联合成功率，同时保持无 proposal 的纯 forward 部署。

### 不可以声称

- “首次用引导/off-policy 轨迹解决 RLVR 全零 reward。”
- “首次用 importance sampling 将探索轨迹蒸馏进无引导策略。”
- “首次在结构变体之间做成对 RL/GRPO。”
- “首次用 base pass@$k$ 检验 RL 是否获得新能力。”
- “证明了 base model 的理论 support 被扩展。”

## 7. 发稿前的新颖性 Gate

1. **只有组合差异还不够。** 需要用枚举小状态空间和有限差分，展示 proposed estimator 的无偏性与 $w\le2/4$ 确实对应可测的方差/稳定性收益。
2. **必须直接对比 Guide/ActGuide 式的 token-level source-conditioned ratio。** 若无法实现同域公平对照，至少要以统一符号说明它们的 estimator 为何不同、哪些选择/fallback 使密度不再是简单 mixture。
3. **变体目标要与 OT-GRPO/PIRL 对齐。** 必须报告“两侧一致但同时错”的比例，证明 ground-truth joint-success 目标真的排除了 consistency-only 的失败模式。
4. **要证明 MIS correction 是原因。** main 必须超过 unweighted paired replay，并同时报告 $q$ 成功率、ESS、权重分布和最终 forward-only pair success。
5. **capability 措辞保持预算相对。** 即使所有 Hoeffding gate 通过，也只能说“在冻结题集和预注册采样预算下超越 base 搜索包络”。

## 8. 检索过程与局限

- 对四组 claim 分别设计了不少于 3 组的不同查询，覆盖 `bidirectional/backward proposal`、`trajectory/multiple importance sampling`、`paired transformed prompts/product success`、`internalize guided search`、`base-model pass@k/capability boundary` 等组合。
- 检索源包括 arXiv 网页与 API、OpenReview/ICLR 2026 索引和 Semantic Scholar 索引页。Semantic Scholar 无密钥 API 返回 429，因此未将 API 返回数量误当作“检索无结果”，而是改用其公开索引页交叉查找，由此补到 Critique-GRPO 等候选。
- 对最高重合论文查看了方法段或公式，其余论文至少核对了 arXiv 当前题名、版本、摘要与状态。
- “未找到完整覆盖”是以 2026-09-10 前可索引的公开文献为边界，不是数学上的不存在证明。发稿前应重跑最近 3--6 个月检索，特别监视 `exact bidirectional proposal`、`mixed-policy internalization`、`transformation-paired RLVR` 三组词的交叉结果。

## 9. 最终建议

这个 idea **值得做最小机制实验，但不宜直接进入 15 个大模型完整训练 run**。先通过三个廉价 gate：（1）枚举图上验证无偏梯度；（2）冻结模型 probe 上证明 $q$ 提高 pair-signal 且 ESS 可接受；（3）小步数上 main 明显超过 unweighted replay 和 full-forward paired PG。如果第（3）不成立，则不是“还需要更多算力”，而是新颖性最强的 MIS 部分没有实证价值，应停止或转向。
