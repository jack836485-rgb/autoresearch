### IDEA-006：表征对齐是否改变数据受限扩散训练的记忆化时间尺度——对齐目标的"实例可识别性"假说

- 来源：`领域共性不足`（对齐家族都只在 ImageNet 全量上报告收敛速度和 FID）结合 `相似领域成熟方法迁移`（借用记忆化时间尺度理论的 τ_gen 与 τ_mem 测量框架）
- 父 Idea：`无`
- 状态：`needs_revision`
- 定位关键词：representation alignment、REPA、memorization、generalization、diffusion transformer、training set size
- 一句话背景：在数据受限的扩散模型训练中，已知生成质量出现的时间 τ_gen 与数据量基本无关，记忆化出现的时间 τ_mem 正比于训练集大小 n（2505.17638、2505.16959）；但表征对齐（REPA 一类，现已是 DiT 训练的默认组件）会怎样改变这两个时间尺度，未检出研究。
- 与起点问题的关系：邻近新问题。保留研究对象（DiT/SiT 上的表征对齐）和"它到底补了什么"的机制问题，评价目标从全量 ImageNet 的收敛速度和 FID 换成数据受限下的 τ_gen、τ_mem 和泛化窗口。原问题中"层级增量对空间结构"等解释能否解释全量数据下的加速，仍未回答。
- 主贡献：
  - 现象与机制：检验 REPA 是否在加速生成的同时提前了记忆化，以及原因是否在于对齐目标的实例可识别性。DINO 类编码器的实例判别特征在 n 小时几乎是每张训练图的唯一编码；而记忆化的经验最优去噪器，正需要从噪声输入识别出最近的训练样本。
  - 实用后果：如果成立，"对齐加早停对齐"在小数据和领域数据（医学等，已有 REPA 应用）上带有隐藏的复制风险；"保留语义、去掉实例可识别性"的对齐目标则可能保住加速而不提前记忆化。
- 贡献自评：
  - 重要性 6.5：REPA 是默认组件，并已被用在内窥镜等小数据领域（2608.07176），记忆化关系到隐私和版权；但在 ImageNet 全量规模下记忆化基本不出现，影响限于数据受限场景。
  - 新颖度 7.5：多次定向检索未检出 REPA 与记忆化或数据量的研究；ICR（2606.09718）只在相关工作中提到 REPA。
  - 有效性 6：依据是 (a) 经验最优去噪器的闭式形式要求识别训练样本；(b) SSL 特征（SSCD、DINO）是复制检测的首选，说明它们实例可分；(c) 2605.06077 显示加大模型会提前记忆化，说明加速拟合的因素也可能加速记忆。竞争预测来自 HASTE 后期"抹掉学生想学的细节"：它可能反而推迟记忆化。目前没有任何 REPA 记忆化的直接观测。
- 可行性：pass（理由见最小实验）
- 自评分：`6.6/10`
- 一段话概括：在 ImageNet 子集上，n 取 1k、4k、16k，用 SD-VAE 潜变量训练 SiT-S/2 或 B/2，按 Bonnaire 等的协议跟踪 FID 和 f_mem（最近邻与次近邻的 L2 距离比 <1/3），估计 τ_gen 与 τ_mem。对齐目标做 2×2：
  - DINOv2 补丁特征（可识别、有语义）；
  - 每张图固定的随机编码（可识别、无语义）；
  - 类内平均的 DINOv2 补丁特征（有语义、去实例）；
  - 不对齐。

  另设 HASTE 早停一臂。预测：如果可识别性假说成立，随机编码也会提前 τ_mem，类内平均目标保留大部分 τ_gen 加速、但不提前 τ_mem；如果 HASTE 的正则化解释成立，REPA 会推迟 τ_mem，早停会释放记忆化。
- Story line：REPA 成为默认组件、已用于小数据领域 → 记忆化理论给出 τ_gen、τ_mem 框架，但从未测过外部表征对齐 → 对齐目标来自实例判别编码器，n 小时近似实例标识，这正是记忆化所需 → 2×2 目标设计把"可识别性"和"语义"分开，再测两个时间尺度 → 结果可以否定任一方向的预测；如果可识别性假说成立，就得到一个保住加速、不提前记忆化的目标构造。
- 打分理由：贡献横跨两条成熟研究线，判别设计清楚，算力适配；风险在于重要性受"只在数据受限时成立"的限制，类内平均目标会改变空间结构，存在混淆。

### IDEA-007：语义潜空间的几何是否压缩泛化窗口——用经验最优去噪器的"实例后验集中噪声水平"预测记忆化时间
