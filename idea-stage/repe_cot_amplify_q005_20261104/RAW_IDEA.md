## 具体问题

推理模型中，在 steering 下生成的思维链会放大被 steer 的决定（思考模式比不思考更容易被 steer），而 steering 之前已写好的思维链会锁住原决定；放大与锁定各由什么决定？放大是剂量效应、文本正反馈，还是答案在审议前已预先确定？

## 已有解决方法与剩余边界

- 已有解决方法：卡片未列出。
- 已支持的解释：决定可在推理 token 之前从激活解码（2604.01202、2603.01437、2603.05488）。
- 尚未解决：两篇独立工作都出现“在 steering 下审议会放大决定”，但没有工作把它当作现象分离：剂量（被 steer 的 token 数）、文本正反馈、预先确定程度三者未被拆开；放大何时转为锁定也不清楚。本轮检索未检出专门研究。

## 待验证解释与分歧

- 思考模式更易被 steer，是因为 CoT 为被改的决定找理由并自我强化（2604.01202 作者描述，未与剂量对照分离）。
- 已写好的 CoT 文本携带原决定、抵消 steering（2605.26772 的固定 CoT 结果）。
- 推理模型难以 steer（2603.01437）可能由 MoE 路由造成，而非审议本身。
- 地图正文中的跨论文分歧：2604.01202／2605.26772 显示“在 steering 下审议放大决定”，2603.01437 显示“推理模型 steer 不动”，后者唯一推理模型为 MoE。2603.05488 提示放大或锁定程度可能随答案预先确定程度变化。

## 可检验切口与查新状态

- 可检验切口：在稠密推理模型上，对同一决策方向比较：只在生成前位置注入后关闭 vs 全程注入；思考 vs 不思考在相同被 steer 的 token 数下比较；用 steering 前的 CoT 文本强制续写 vs 自由重新生成；按预先确定程度（探针置信度或题目难度）分层。观察翻转率、CoT 长度与合理化比例。
- 查新状态：做了定向网页检索（思考模式更易 steer、CoT 放大／合理化），只找到 2604.01202 报告该现象而未分离；未进行完整查新。
- 已知边界：证据多在 4–9B 稠密模型与工具调用／拒答／二选一任务；多数证据在窗口外且非白名单。

## 问题锚点（Problem Anchor）

- **起点问题：** 推理模型中，激活 steering 下生成的 CoT 放大被 steer 的决定，而 steering 前已写好的 CoT 锁住原决定；放大与锁定各由什么决定（剂量 / 文本正反馈 / 预先确定）。
- **对象与条件：** 稠密开源推理模型（证据集中在 Qwen3-4B、GLM-Z1-9B、DeepSeek-R1-Distill-Llama-8B，4–9B）；从生成前激活提取的决策方向（工具调用、拒答、二选一答案）；变量为 steering 强度、注入／抑制、思考／不思考、CoT 固定／去除／重新生成。
- **初始任务／评测：** When2Call、BFCL 的工具调用决策；拒答；二选一答案任务。指标为决定翻转率，辅以 CoT 长度与合理化比例。
- **瓶颈与证据边界：** 现象由两篇独立工作报告但均未分离；剂量混淆、随机方向对照与被 steer token 数未核实；推理模型“steer 不动”的反例只来自 MoE 模型；多数证据为单次运行、n=100、窗口外且非白名单，其中两篇仅读摘要。
- **用户资源约束：** 预研 2×A100 80G / 4×L40 48G / 8×4090 24G；正式实验可用 8×A100 80G、最好不超过 5 天；付费 API（如 GPT judge）1000 元内可自主决定；token 资源较稀缺。
- **时间与目标：** 自 2026-10 起半年内投出一篇主会论文。
- **非目标：** 不做世界模型、视频生成、机器人方向。
- **进入实验规划的成功条件：** 独立 reviewer 两次（high + xhigh 复核）对同一 brief 判定三项贡献都 ≥6 且至少两项 ≥8、可行性 pass、verdict 为 experiment_ready、无 fatal blocker；产出 `EXPERIMENT_HANDOFF.md`。
