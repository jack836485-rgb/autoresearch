### IDEA-002：递归增益分解——后代改进者的优势有多少来自可迁移技能，多少来自累积历史与选择噪声

- 来源：`领域共性不足`（多个 RSI 系统都只报告最终产物；方差、任务顺序与选择乐观在多篇工作中被观察到）+ `相似领域成熟方法迁移`（进化生物学与元学习中"可进化性/元生产力"的测量：在共同环境下对比后代的适应速度；统计学中赢家诅咒的去偏重评估）
- 父 Idea：`IDEA-001`
- 状态：`needs_revision`
- 定位关键词：recursive self-improvement；self-referential self-improvement；meta-productivity；selection bias；held-out evaluation；self-improving coding agents
- 一句话背景：LLM 自我改进系统（改进者本身可被修改，如 STOP、Promptbreeder、DGM、HGM）声称存在递归；但审计显示，26 篇声称流程变好的研究中只有 4 篇在相同起点、相同预算下比较前后两代。评测方差（σ 约 2–7%）和单次评测带来的选择乐观已有报告，而改进者代际的对照几乎没有。
- 与起点问题的关系：原问题；聚焦卡片的第二个主张（后代改进者更会改进），并顺带测量第一个主张（跨轮累积）。
- 主贡献：
  - 第一个受控的"递归曲线"测量：在 2 个改进者可修改的系统、2 个执行模型规模上，估计各代改进者在新目标上的同预算改进量 Δ_k，以及放大比 r_k = Δ_{k+1}/Δ_k。
  - 一个三分解：把后代优势拆为可迁移改进技能、累积历史（上下文/笔记）、选择噪声（赢家诅咒），分别用"历史匹配的第 0 代"和"独立重评估后的选择"作对照。
  - 主假说：去掉历史与选择噪声后，后代的优势显著缩小，r_k < 1，即递减而非放大；若仍有剩余，主要集中在流程类编辑。
- 贡献自评：重要性 8 / 新颖度 7 / 有效性 6.5。
  - 依据：Harness Evolution Hits a Ceiling 报告单次 rollout σ=0.023 会带来选择乐观；Fragility 论文报告 run 间差 2.4–6.7% 且受任务顺序左右；Promptbreeder 的消融显示最大收益来自初始多样化，而非递归改进；HGM 发现当前分数与产出更好后代的潜力只有弱相关；STOP（按记忆，待核实）在较弱模型下自我改进会退化；B12 理论预测可达编辑集合固定时收益递减。
  - 未知：强开源模型（Qwen3-235B/72B 级）下递归是否比 GPT-4 时代更强；三分解是否近似可加；放大比的方差是否大到无法下结论。
- 可行性：pass。STOP（microsoft/stop）、SICA、DGM、HGM、Promptbreeder 实现均已核验存在；改进者与执行者用本地 vLLM 部署开源模型，API 只做强模型复核。
- 自评分：`7.2/10`
- 一段话概括：在 STOP 式自改进 scaffold 与 Promptbreeder/SePO 式自指 prompt 进化两个系统上，从同一起点各跑 5 条独立谱系、6 代，冻结每代改进者。在 8 个未参与进化的新目标任务上，每代改进者以相同调用预算各做 5 次改进，测留出改进量 Δ_k。再做三类对照：(a) 把第 k 代可见的历史与笔记原样交给第 0 代；(b) 用独立新种子重评估后再选择改进者，与单次评测选择作比较；(c) 不经选择、随机接受编辑的漂移谱系作零假设。在两个执行模型规模上重复。
- Story line：RSI 的核心卖点是"改进者会越改越会改"，但领域只报告最终产物，审计显示几乎没人在同预算下比较前后两代 → 同时，评测方差、任务顺序与单次评测的赢家诅咒都能制造"代际进步"的假象，而后代改进者还携带更多历史 → 本 Idea 把后代优势拆成技能、历史、噪声三部分，并在两个系统、两个规模上估计放大比 → 若递归真实存在，就能给出第一条可复现的递归曲线及其成立条件；若去偏后优势消失（r<1），则当前 harness 级 RSI 的"递归"主要是历史累积与选择噪声，领域应改变评测与选择方式。
- Idea 生成依据：RSI 地图 Q003 证据；HGM 2510.21614；Promptbreeder 2309.16797；SePO 2606.04465；STOP 2310.02304；DGM 2505.22954。
- 自评分轻量新意依据：检索"冻结改进者代际、同预算比较 / 元生产力受控测量"未见；STOP 是最接近的早期工作（GPT-4 时代、少量任务、无历史与噪声分解）；HGM 测的是谱系元生产力，用于引导搜索，而不是受控的代际对照；需要 reviewer 检索。

### IDEA-004：改进者学到的主要是统计纪律吗？——用编辑类别移植检验 hyperagent 元级增益的来源

- 来源：`最高近邻不足`（Hyperagents/DGM-H 报告元级改进可跨域迁移，并自述来自"持久记忆、性能追踪"，但没有做成分归因）+ `领域共性不足`（Winner's Curse、Harness Ceiling 都显示，自改进循环的大部分提案有害，且单次评测的选择偏乐观）
- 父 Idea：`IDEA-002`
- 状态：`rejected`
- 定位关键词：hyperagents；Darwin Gödel Machine；recursive self-improvement；meta agent；selection noise；winner's curse
- 一句话背景：在自指自改进系统 DGM-H 中，演化后的 meta agent 迁移到未见域后，imp@50 达到 0.63，而初始 meta agent 为 0；论文把这归因于 meta agent 自己长出的"持久记忆、性能追踪"等机制，但没有检验是哪类改动带来了迁移增益。
- 与起点问题的关系：原问题的机制化。在已报告正向递归增益的系统上，回答"后代改进者为什么更会改进"；它不回答递归能否无限放大。
- 主贡献：一个机制归因及一个强基线。归因是：DGM-H 可迁移的元级增益，主要来自对抗选择噪声的统计纪律类编辑（追踪各变体表现、记住已评估或已失败的改动、重复评估），而不是领域内容或搜索策略类编辑。强基线是：给初始 meta agent 加一个人工设计的抗噪接受规则加实验日志（按 Winner's Curse 论文的接受规则实现），应收回 imp@k 的大部分差距。若成立，"递归"的主要来源就是一次性可补齐的统计纪律，由此可预测补齐之后收益递减。
- 贡献自评：重要性 8 / 新颖度 7.5 / 有效性 6.5。
  - 依据：Hyperagents p.1 自述"persistent memory, performance tracking"是可迁移的元级机制；Winner's Curse 显示第一代之后的大部分提案有害，贪心循环的选择集分数比留出分数高 13–20 点（16 个选择样本时）；Harness Ceiling 报告单次读数 0.535、复测只有 0.44–0.46。
  - 未知：日志中可迁移的编辑是否真能按类别分开；用开源模型替换原 FM 后 imp@k 能否复现正向效应；人工规则能否在其代码框架内自然实现。
- 可行性：pass（有条件）。Hyperagents 代码已公开（含 analysis/transfer_utils.py），实验日志在 Google Drive 公开；一次 100 迭代的运行约 8360 万 token，因此迁移实验用本地 Qwen3-235B-A22B 级模型，并缩短为 imp@20 或 imp@50。Google Drive 在国内可能需要服务器中转，待核实。
- 自评分：`7.3/10`
- Reviewer 记录：`Call 2（常规，Opus 5.5 high）：4.0/10（重要性 6 / 新颖度 5 / 有效性 4，可行性 fail），needs_rethink；最高近邻 Hyperagents（D.5 已用 hunk 过滤做 meta/task 成分消融）、Winner's Curse、审计论文、AIDE²、Trusting Trust Revisited 2609.17817`

### IDEA-005：RSI 测到的"改进者增益"有多少只是在修复坏起点？——有效率 × 条件质量分解与正常起点迁移测试
