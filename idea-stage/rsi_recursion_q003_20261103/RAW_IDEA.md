## 具体问题
RSI 区别于一次性优化，靠的是两个主张：一是改进可以跨轮累积，二是改进后的系统更擅长继续改进。在相同起点与预算下，这两个主张是否成立？收益在多轮或任务流中是持续累积、到达平台，还是被侵蚀？

## 关键证据
| 作品 | 原文链接 | 具体观察 | 证据边界 |
|---|---|---|---|
| Are Self-Evolving Agents Continual Learners?（Google DeepMind、Mila） | https://arxiv.org/abs/2610.25858 | 自进化提高了多数任务流的总分，但可塑性越高、稳定性越差；自修改方法的全局编辑会干扰未见任务、覆盖旧知识；检索式记忆存在检索碰撞 | 数值未取；未测改进者代际 |
| On the Fragility of Self-Improving Agents（Salesforce） | https://arxiv.org/abs/2608.18066 | 无记忆基线在 GitLab 子集上，最好与最差 run 相差 4.4%，标准差 1.98%；VWA 上 2.4%，SCUBA 上 6.7%；默认任务顺序隐含由易到难的课程 | 方法级数值未取 |
| Harness Evolution Hits a Ceiling（Stanford、Berkeley） | https://arxiv.org/abs/2610.11655 | 留出分 4B 从 0.16 到 0.30，9B 从 0.32 到 0.44；流程类失败可由 harness 修复，内容类失败需要权重训练；单次 rollout 的 σ=0.023 会带来选择乐观 | 单一任务族 |

**本轮补读**
- HGM（2510.21614）：发现"元生产力与表现不匹配"，即 agent 当下的分数与它产出更好后代的长期潜力只有弱相关；据此提出以 CMP（基于后代结果的元生产力估计）指导扩展。
- Promptbreeder（2309.16797）：消融显示，最大的收益来自初始化时对任务提示的多样化重述，而不是递归改进 mutation prompt。SePO（2606.04465）指出，其 hyper-mutation prompt 是手写且固定的。
- STOP（2310.02304）：种子改进者改进自己之后，在少数下游任务上产出更好的程序。全文 HTML 无法获取；按主执行者记忆，较弱模型下自我改进反而退化，此点待审阅者核实。

## 已有解决方法与剩余边界
- 已有方法：持续学习式两阶段评测；以 meta-productivity 作为选择目标（HGM、MetaSkill-Evolve）；可编辑的改进机制（Hyperagents，窗口外）。
- 已支持的解释：全局编辑带来可塑性与稳定性的取舍；评测方差与任务顺序可以左右结论。
- 尚未解决：在相同起点、相同预算下，"后代改进者是否产出更大改进"，窗口内基本没有对照实验；多轮累积只有少数持续学习式评测，结论分歧。这个缺口已被 B1 量化，并非无人注意。

## 待验证解释与分歧
- 可达编辑集合固定时，收益必然递减（B12 理论，白名单外）。
- 只有当递归增益与前沿变难之比大于 1 时，才会自我放大（B15，网页二手）。

## 可检验切口与查新状态
- 可检验切口：从同一个初始 artifact 出发，冻结第 k 代改进者，让每一代在同一组新目标任务上做同预算改进，比较留出改进量。控制执行模型、预算、目标任务，以及改进者可见的历史长度，以区分"改进者变强"和"带着更多历史"。
- 查新状态：做过反证检索（WebSearch 两次 + 30 篇方法论文覆盖扫描），窗口内未检出改进者代际对照研究；HGM、Hyperagents（窗口外）提出过概念或机制，对照实验本轮未读到。

## 问题锚点（Problem Anchor）
- **起点问题**：LLM 驱动的自我改进系统中，"改进后的改进者更会改进"（递归）是否成立；跨轮收益是在累积、到达平台还是被侵蚀。
- **对象与条件**：改进者本身可以被修改的系统（scaffold、mutation prompt、agent 代码等，如 STOP、Promptbreeder、DGM/SICA/HGM）；执行模型冻结；同起点、同预算。
- **证据边界**：现有工作主要报告最终产物，而不是递归本身；评测方差大（σ 约 2–7%）；理论预测相互竞争。
- **用户约束**：正式实验可用 8×A100 80G，单次最好不超过 5 天（可本地 vLLM 部署开源模型充当改进者与执行者）；付费 API 1000 元以内可自主决定；token 资源稀缺；目标是半年内投主会。
- **非目标**：本 skill 内不跑实验；不训练权重级自改进（另见 Q007）。
- **成功条件**：得到经双审通过的 Idea，并交付 `EXPERIMENT_HANDOFF.md`。
