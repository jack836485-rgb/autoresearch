### IDEA-002：改进者 × 前沿的因子分解——RSI 的递归增益是不是只在起点上测出来的

- 来源：`领域共性不足`（跨论文分歧：Hyperagents 在初始目标上测得改进者变强，AIDE² 在后期目标上的点火测试不确定）+ `相似领域成熟方法迁移`（析因设计与交互效应估计；经济学中“研发弹性 / 想法越来越难找”的分解思路，见 2609.15802）
- 父 Idea：`IDEA-001`
- 状态：`needs_revision`
- 定位关键词：recursive self-improvement；imp@k；ignition test；metaproductivity；diminishing returns；Darwin Gödel Machine / hyperagents
- 一句话背景：自指式自我改进系统（DGM-H、AIDE² 类）中，“改进者是否越改越会改进”目前只在单一目标状态上被测过；它在系统已经改进过、更难的前沿目标上是否成立，以及递归增益是放大还是衰减，都未知。
- 与起点问题的关系：原问题。保留对象（自我改进系统的改进者代际）与“相同起点、相同预算”的条件；新增“目标成熟度”这一维度，并估计递归增益比。“收益在任务流中是否被侵蚀”（可塑性与稳定性）不在本候选内。
- 主贡献：
  - 一个析因测量框架：用 Δ(i, j) 表示把冻结的第 i 代改进者用于第 j 代目标时、同预算下的改进量，把每代的观察收益分解为改进者增益、前沿变硬和交互三部分；
  - 首次在现有系统上实测递归增益比（改进者增益相对前沿变硬的速率），判断它处于放大区还是衰减区；
  - 检验一个可推翻的现象：改进者的优势主要体现在不成熟的目标上，即“低垂果实”。
  - 意义：成立时，起点上测得的 imp@k 会高估递归增益，并可以解释 Hyperagents 与 AIDE² 结论的差异；不成立时，imp@k 可以作为递归能力的可靠代理。
- 贡献自评：重要性 7.5 / 新颖度 7.0 / 有效性 6.5
  - 重要性：“RSI 会不会加速”是政策与安全讨论的核心问题（Anthropic Institute、RAND、经济学论文 2609.15802 估计弹性约 0.09），而现有直接测量只有两个单点设计。
  - 新颖度：imp@k 只测了 j=0 这一列，点火测试只测了 j=47 上的两个 i，析因分解和交互估计本轮未检出。
  - 有效性：改进者增益在起点存在（Hyperagents，0.63 vs 0）；前沿变硬有间接证据（AIDE² 搜索在领先策略平台期后递减；harness 演化天花板 2610.11655）；点火测试 3 个种子不确定，说明噪声是关键。未知：交互的方向与大小；开源模型能否驱动有效的自我修改（STOP 显示较弱模型会退化）。
- 可行性：pass（预估）。Hyperagents 代码公开，含 paper_review、imo、polyglot 等领域，通过 litellm 接模型，可接本地 vLLM；STOP 代码公开，作第二个系统。
- 自评分：`7.0/10`
- 一段话概括：在两个自指式系统上实测 Δ(i, j)：Hyperagents/DGM-H（paper_review 领域）和 STOP（改进者程序改进自身）。
  - 先各跑一条谱系，取 5 个等间隔代次；
  - 对每个（改进者 i，目标 j）组合，在相同生成预算 k 下、用配对随机种子重复 3 次测量改进量；
  - 用带交互项的加性模型估计改进者增益、前沿变硬与交互，再算递归增益比；
  - 检验“起点 imp@k 的排序能否预测后期目标上的改进量”。
- Story line：Hyperagents 报告迁移元 agent 在初始任务 agent 上 imp@50=0.63、初始元 agent约为 0，被解读为“改进能力在提升并累积”；AIDE² 在后期目标 AIDE47 上的点火测试（各 3 个种子）却不确定 → 被忽视的是，两者测在不同的目标成熟度上，而前沿变硬与“低垂果实”都会让起点上的改进者优势在后期缩小，现有设计无法分开改进者增益与前沿变硬 → 本 Idea 用改进者代次 × 目标代次的配对析因测量分解二者，并估计递归增益比 → 可推翻的预期：交互显著为负（后期目标上改进者优势缩小），且起点 imp@k 对后期改进量的预测力弱；若交互为零、比值大于 1，则支持“递归在放大”。两种结果都改变对当前 RSI 系统的判断。
- 打分理由：问题分量大、设计简洁、能对齐真实分歧；风险在于测量噪声与开源模型的能力。
- Idea 生成依据：问题卡 Q003（2610.27610、2609.26457、2610.25858、2608.18066、2610.11655）；Hyperagents 2603.19461（imp@k 与迁移结果，网页二手加摘要）；AIDE² §3.6 点火测试（本轮核实）；HGM 2510.21614（元生产力与当前表现不匹配）；STOP 2310.02304；2609.15802（RSI 经济学，弹性约 0.09）；2609.00137（临界性）。

### IDEA-005：自指改进者到底学会了什么——区分通用接口修复、谱系记忆回放与可迁移改进技能
