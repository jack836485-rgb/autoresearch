## 读取方法
- 全文读取：`python -X utf8 .claude/skills/ai-frontier-search/scripts/批量读取论文.py <ID数组json> --output-dir path-stage/AgenticRL研究地图_20261016/资料/正文精读 --max-chars 200000 --delay 1.5`（ID 数组文件请写到 path-stage/AgenticRL研究地图_20261016/资料/正文精读/ 下，用你的编号命名，如 A1_ids.json）。如需最新版，先读 https://arxiv.org/abs/<ID> 确认版本，再用 `<ID>vN` 读取；记录实际阅读版本。
- 读出的 JSON 很长，**不要整篇打印**。用 python 按关键词（Table、Figure、ablation、limitation、collapse、we find、we observe、%、baseline 等）切片打印相关段落。
- HTML 不可用时：`python -X utf8 tools/arxiv_fetch.py download <ID> --dir path-stage/AgenticRL研究地图_20261016/资料/pdf`，再用 PyMuPDF(fitz) 提取文字。
- 非 arXiv 页面：`python -X utf8 .claude/skills/ai-frontier-search/scripts/读取研究页.py <URL> --max-chars 60000`。

## 每篇要提取的内容（只写原文支持的内容，数值逐字抄录并给位置）
作品ID、完整标题、v1 日期、阅读版本、核实机构（及证据位置）、资格类别（厂商白名单/QS前50高校/白名单外背景）、来源类型（方法/诊断/实证研究/综述/技术报告/系统）、
实验设置（模型、规模、任务/基准、评测指标、重复/种子数）、变化变量、对照与保持条件、
具体观察（反常结果、失败条件、关键数值；写清分母与指标口径，如 pass@1/成功率/奖励、全任务还是子集）、
成本口径（步数/rollout 数/GPU 时/token；额外教师/评审/环境成本是否计入）、
作者的解释：已由消融/干预支持的 vs 仅为作者推测、作者写明的局限与未验证范围、位置（章节/表/图）。
不确定就写 null 并说明原因。不得凭记忆补数字或补论文。

## 问题簇小结
在每簇末尾写：原有做法 → 已观察到的失败 → 已有解释/解法 → 最近缓解的条件 → 剩余边界/未知；跨论文的分歧（先对齐任务、模型、预算等条件，能由条件差异解释的写成条件差异）；1–3 张候选问题卡草案（具体问题=对象+条件+失败/未知关系；可检验切口=要区分什么、观察什么、控制什么；不要提出新算法）。
