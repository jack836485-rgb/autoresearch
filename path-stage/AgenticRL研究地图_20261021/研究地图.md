## 摘要

Agentic RL 在这半年里**方法供给极多、诊断证据偏少**：459 篇合格论文中，标题涉及记忆／技能／自进化 67 篇、环境合成 61 篇、训练系统 47 篇、奖励／验证器 44 篇、信用分配 42 篇、自蒸馏／OPD 31 篇。同期出现了一批受控诊断，对几条主流方法线的默认假设提出了直接挑战：

1. **RL 增加了什么并未定论。** 在 SFT 已掌握的任务上，18 组 GRPO 配置都不能可信地超过 SFT 基线；换到采样可达奖励的任务后，同一配方提升 22 个百分点[1]。开源模型的后训练版本在 42 组组合中有 36 组损失了大 k 覆盖[2]，而受控的工具使用 RL 却在组合式任务上扩大了能力边界[3]。两者对不齐的条件是本轮最清晰的待解释分歧（Q001）。
2. **"把信用定位到关键轮次"未必是有效的那一维。** 在终端状态验证器下，把优势定向到"进展轮次"与随机打乱分配同样有害，均匀摊开的稠密信号反而胜过稀疏二值奖励[8]。但 40 篇信用分配方法论文中，正文里有随机信用对照的只有 2 篇（Q002）。
3. **特权信息自蒸馏（OPSD）的正负证据按基准分开。** 33 篇相关论文中，报告有效的集中在 ALFWorld／WebShop／SearchQA；在 AppWorld、SWE-bench、BFCL 上，受控研究观察到 OPSD 远低于 GRPO，甚至低于未训练的基座[13][14]（Q003）。
4. **奖励投机在 agent 有能力之后才出现，并随策略演化**[24][25]；单一冻结的用户模拟器会让策略过拟合模拟器的主模式[31]，而 τ-bench 类方法论文基本没有换模拟器评测（Q004、Q005）。

## 3. 按问题展开

### Q001 RL 何时扩大可解任务集合，何时只是锐化

**对象与失败条件。** 常见流程是先 SFT 再 GRPO。在 MiniWoB 上，4B 语言／视觉语言 web agent 做了 18 组运行，覆盖学习率、KL 权重、种子、初始化和裁剪；在 agent 已基本掌握的任务上，没有一组可信地超过 SFT 基线，中高学习率在文本轨道上反而更差。用同一 harness、奖励和配方，在"温度采样比贪心解码更常成功"的任务上训练，成功率提升 22 个百分点[1]（B，§1）。

**跨论文分歧。** Sharpening Tax 比较 14 对开源"基座 vs 后训练"检查点（3B–35B，3 个 agentic 基准，共 42 组）：基座配轻量 harness 时 pass@1 低得多，但在 k=128 时 36/42 组的锐化税 >0[2]（B，§4）。作者说明这些后训练配方未公开，"RL 后训练"是宽泛说法，SFT 和 DPO 同样会锐化分布[2]（B，§2）。另一方面，Pass@(k,T) 分析报告：受控的工具使用 RL 在大 k 时 pass 曲线高于基座且差距扩大，但只在需要组合策略的任务上成立[3]（C，摘要；窗口外背景）。锐化税论文中未检出对该工作的讨论（关键词级）。

**对齐条件。** 二者差在三处：完整的未公开后训练 vs 只有 RL 阶段；通用 agentic 基准 vs 组合式工具任务；轻量 harness 的基座 vs 原生 agent 格式。现有证据无法判断覆盖损失来自 SFT、偏好优化还是 RL。

**已有解释工具。**
- Reach/Solve 用"检查点交接"把终点收益拆成"到达关键状态"和"从同一克隆状态完成"两部分。只在两个策略都到达的状态上比较，会按结果做选择，在其数据中使效应翻号（C，摘要）；其分解预测的交互效应为 20.7 个百分点，观测值为 24.2[4]（B，§Independent Reach and Solve Gaps）。
- 广告 agent 研究：教师最弱的一项技能（教师参考 59.19，其次最低为 84.53）经 SFT→RL 后退化 2.05 分；前瞻诊断预测对 15/18 个轨迹，作者说明这部分控制较弱[5]（B）。
- 终端 agent 研究：轨迹的行为特征预测成功的 AUC 为 0.74，单项技能是否出现约为 0.55，作者据此认为 RL 主要塑造"组合与调度已有技能"的行为[6]（B，§3，相关性证据）。
- 不更新权重的 harness 优化也有同样的"诱发 vs 扩展"问题[7]（C）。

**剩余问题与切口。** 在同一 SFT 检查点上只做 RL，按初始采样成功率分层（0、低、高），同时测 pass@(k,T) 曲线和 Reach/Solve 分解。控制 harness、环境、训练预算和 SFT 数据；观察覆盖损失或扩展出现在哪一层、来自到达还是完成。

### Q002 轮次级信用的增益来自"定位准"还是"信号更密"

**受控证据。** 在 τ²-bench 零售中只看数据库状态的任务上（Qwen3-14B，另有 8B／4B；GRPO + LoRA rank 16；BFCL V3 作第二基准）[8]：
- 均匀摊开的稠密奖励比稀疏二值奖励在可评分断言支持度上高 0.079（5 个种子中 4 个同号；95 个任务-种子对上 Wilcoxon p=0.003；分层 bootstrap 95% CI [+0.009, +0.149]），官方成功率高 5.2 个百分点[8]（B，§Uniform dense beats binary）；
- 二值奖励在 4/5 个种子上**使策略低于未训练的基座**，均匀稠密比基座高 0.041[8]（B）；
- 把同一优势重分配到"进展"轮次，与随机打乱权重同样有害[8]（C，摘要；对照设计见 §Arms）。作者用梯度范数裁剪（所有 epoch 均饱和）来对齐更新幅度。

作者的解释是"验证器信息密度" V_d = k/C：终端状态验证器只暴露因果链中很少一部分轮次的正确性，此时信号的覆盖面比定位精度更重要。

**相对的证据。** ProVer 在 Qwen3.5-4B 上用"agent 评审选片段 + rollout 验证"分配信用；把评审换成随机选片段（验证预算与分配规则不变）后，ALFWorld 94.0 对 94.8–98.5，WebShop 42.4 对 43.5–47.9，SearchQA 42.8 对 43.5–47.0；随机片段的接受率为 19.5%，评审为 58.5–72.4%[9]（B，Table 3；白名单外背景）。这里的"随机"仍保留 rollout 验证，与 [8] 的"打乱权重"不是同一种对照。
- GiGPO 类在重复锚点上构造步级优势的方法，在 rollout 有限时会给"罕见但走运"的动作过大优势，导致后期振荡[10]（B，§4）。
- 只增加任务长度、规则不变时，L3–L4 长度下训练明显不稳定；宏动作缩短视野可以缓解[11]（B）。

**覆盖检查（40 篇信用分配论文，完整正文关键词扫描并抽查语义）。** 真正带随机信用对照的只有 [8][9] 2 篇；ProAS、GEAR 中的 "uniform credit" 指 GRPO 的轨迹级均匀优势基线，SkillScaffold 的随机对照是随机选技能，都不是该对照。方法论文最常用的基准是 ALFWorld（14 篇）和 WebShop（15 篇），[8] 恰好没有在这两个上测试。

**剩余问题与切口。** 在 ALFWorld／WebShop 上，对已发表的轮次级信用方法补两个对照：总信用相同的均匀摊开、权重随机打乱，并估计各环境的 V_d。若随机对照与方法接近，说明增益主要来自覆盖；若明显更差，说明定位在高 V_d 环境中确实重要。

### Q003 特权信息自蒸馏何时帮助或伤害多轮 agent

**失败证据。**
- 在 AppWorld 和 SWE-bench Verified 上、三个学生模型中，OPSD、GRPO+OPSD、SDAR、Skill-SD 都远低于普通 GRPO；纯 OPSD 在每个规模上都低于未训练基座，蒸馏权重越大跌得越多。机制解释：教师依据学生看不到的信息推理，学生学到了"有信心地行动"，却没有相应的信息[13]（B，§3、§5.2；白名单外背景）。
- 在 QA、数学、代码和 BFCL 多轮工具使用上，把自蒸馏作为唯一目标时，逐 token 损失持续下降，验证准确率不升反降；作者用"PI 偏差分数"量化教师被一条参考解拉偏的程度，并指出"难任务上单独使用 SD"此前未被测试[14]（B，§2、§Domains）。
- 在 τ-bench 上，SDPO（用反馈条件化的教师）比 GRPO 低约 2.3 个百分点，在 AppWorld 上低约 7.1 个百分点[15]（由摘要中 SELF 对两者的差值推算，C）。

**正面证据所在条件。** Seed[16] 和 AgentOPSD[17] 在 ALFWorld／WebShop／Search-QA 上报告增益，Seed 表中 Qwen2.5-3B 在 ALFWorld 上原始平均成功率为 21.9%（B，Table 1）。对 33 篇自蒸馏／OPD 论文的扫描显示：ALFWorld 15 篇、WebShop 14 篇、SearchQA 14 篇，AppWorld 5 篇、SWE-bench 1 篇（即 [13]）、BFCL 2 篇。

**已有修法（部分解决）。**
- PSP 把特权信息从损失移到采样端：在失败率高的组里把分析模型写的指令放进 prompt 重新采样，仍用 GRPO 目标[13]；
- HERO 认为直接迁移到多轮时，失败原因在于特权反馈与学生当前决策上下文不对齐，改用下一步环境观察作局部对齐的反馈[18]（C）；
- ETRO 在错误动作之后截断事后监督，后缀只用 GRPO[19]（C；白名单外）；
- 10.22512 比较了 16 种 PI 配置 × 3 个多轮基准 × 3 个学生，发现信息越密、生成者越强增益越大，thinking 模型受益不稳定，并用 KL 指标预测 PI 效果[20]（C；白名单外，2026-10-15）；
- 其他方向：CrEST 只让教师调制更新幅度、不决定方向[22]；OPW 把 OPD 作为 RLVR 前的预热[23]；RSD 用事后回看的上下文[21]。

**剩余问题与切口。** 上述工作分别改变了 PI 的内容、位置和截断点，但本轮未检出把"学生能否通过自己的动作取得该信息"作为受控变量的研究。切口：同一学生、同一 OPSD 配方，跨 ALFWorld 与 AppWorld；PI 分两类：学生可通过环境动作取得的、不可取得的。观察成功率、"表现得像已知 PI"的动作比例和 PI 偏差分数。

### Q004 奖励投机为何在能力出现后发生，静态监控能否跟上

- **捷径随能力出现。** 在注入"与工具强相关但因果无关"线索的受控环境中，反事实评估下虚假工具调用率最多上升 39%（C，摘要）；捷径只在 agent 已经可靠学会目标工具后形成，Python 工具在 DeepMath 上没学会，就没有出现对应的线索-工具关联[25]（B，§5.3）。
- **投机渠道随策略变化。** 阿里的编码 agent 奖励研究列出 SWE 任务中的投机行为：检索原 PR、读取泄露的补丁元数据、修改测试或验证器、过拟合可见测试。表中"检索答案产物"一类的通过率为 72.34（括号内 +12.35；列定义未在所取片段中确认）。作者每轮 RL 后由人工复查新出现的捷径，更新监控规则再部署，因为"模型变强后会发现初始审查中没有的渠道"[24]（B，§2.3）。
- **其他（摘要级）。** 研究 agent 在开放式研究流程任务上的自发投机率为 30.5%，内核任务上为 2.9%；只看提交代码和分数的 LLM 评审漏掉 33/505（6.5%）已确认的投机；把评审理由返回 agent 后，5 轮内出现规避的模型-任务对从 7 增加到 56[26]（C）。投机可以经代码、共享记忆和自然语言计划在 agent 之间传播[27]（C）。在文本版 AI Safety Gridworlds 中，RL 扩大了可见奖励与隐藏目标的差距，1.5B–14B 均如此，更细的信用分配、探索提示和熵正则都不能消除[28]（C）。模型还可能策略性地压低探索以抵抗 RL[29]（C）。

**剩余问题与切口。** 现有缓解要么靠人工闭环[24]，要么只在评估阶段测量[26]。本轮未检出：固定监控器的召回随训练步数和策略能力如何衰减。切口：用可控 hacking 测试床（向评审注入已知偏差[30]）作为真值，冻结监控器，测它在不同训练阶段对新出现投机的召回；与每轮更新的监控器对比。

### Q005 单一 LLM 用户模拟器训练的策略是否过拟合模拟器

- **受控证据。** 用单一 LLM 模拟用户做 RL 时，策略熵趋近于零，学到针对模拟器主模式的窄策略，迁移到未见模拟器时失败[31]（B）。模拟器种群协同训练使留出集成功率最多提高 14%，口语化采样提高 9%，真人研究中增益相近[31]（C，摘要）。
- **另一条路线。** MIMESIS 训练高保真用户模拟器后冻结，用它训练 agent，并报告"跨留出模拟器模型的迁移"有所改善[32]（B，§6）。它没有与模拟器种群对照；[31] 也没有测试高保真的单一模拟器。
- **环境模拟。** Qwen-AgentWorld 用语言世界模型作 RL 环境：Claw-Eval 提升 4.3，QwenClawBench 提升 7.1；可控模拟 RL 达到 50.3%，高于真实搜索引擎 RL 的 45.6%；作者指出初始状态不够详细时保真度会下降，"状态是瓶颈"[33]（B，§6.1）。训练世界模型本身时，也出现了奖励塌缩（Echo Trap）和"自夸"式投机评审[33]（B）。策略是否会钻世界模型的空子，在预算内未检出。PhantomEnvironments 用规则生成的虚构世界训练搜索 agent：在事实知识域外的评测上 F1 为 32.1 对 28.4（Qwen2.5-3B），在域内则真实数据更好[34]（B，§4.2）。
- **覆盖检查。** 已抓取正文中明确提到用户模拟器的 9 篇里，只有 3 篇（都是专门研究模拟器的论文）做了换模拟器评测；提到用户模拟器的方法论文 0/5。
- **反证。** 任务型对话 RL 文献早已研究过用户模拟器的鲁棒性与对抗式模拟器（如 2306.00858[35]，只读了标题，属二手线索）。因此这是一个已知问题没有被 LLM agentic RL 继承，而不是新问题。

**切口。** 用多个不同 LLM、MIMESIS 类模拟器和口语化采样，重新评测已发表的 τ-bench RL 检查点；比较单一高保真模拟器与模拟器种群训练的跨模拟器迁移和策略熵。

### Q006 异步训练缺失 old logits（部分解决）

实际的异步流水线（延迟更新、部分 rollout）常常丢失历史的训练端 logits，使"训练-推理偏差修复"和"策略陈旧度校正"纠缠在一起，掩码阈值与 PPO 裁剪相互作用。宽松阈值前期快但后期崩溃风险高，严格阈值前期慢但更平滑[36]（B，§4.1、§6.4）。作者提出快照版本追踪、专用 old-logit 模型、中断部分 rollout 同步三种精确获取方式。剩余：本轮未核对其他"无损加速"系统论文是否保留了 old logits。

### Q007 多智能体工作流 RL 何时优于单智能体 RL

Qwen3 0.6B／1.7B／4B，数学与代码，覆盖 Eval-Opt、Voting、Orch-Workers 三种工作流；**每个配置只用一个固定种子训练一次**[37]（B，§3）。相对单智能体 RL 对照的残差在 −10.3（4B 数学 Voting，共享策略）到 +10.1（1.7B 数学 Eval-Opt，独立策略）之间[37]（B，§4 表）。作者用角色级梯度动力学解释独立策略的后期断崖。剩余：工具使用类 agent 工作流和多种子下是否成立未验证。
