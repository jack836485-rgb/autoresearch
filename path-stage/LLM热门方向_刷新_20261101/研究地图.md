## 2. 本轮新判的卡

### L-Q002 循环深度：已拥挤
2026-09/10 至少有三项工作直接研究"FLOPs 匹配下循环带来多少增益"：
- SMELT [R1]：在 MoE 上同时匹配每 token FLOPs、参数量与 KV cache；
- Looping Beyond Twice [R2]：FLOPs 匹配下，两轮以上的收益迅速递减甚至退化；
- Truncate or Not? [R3]：约 600 次训练的截断 BPTT 缩放研究。

本卡另有算力约束：需要从头预训练，适配为低–中。

### L-Q007 自动研究循环：已拥挤
Beneath the Diff [R7] 直接诊断代码级自动研究循环：在循环内按指标保留编辑，这样得到的改进能否泛化到循环外；同时诊断算法模式坍缩。这覆盖了本卡"编辑多样性坍缩"与"不迁移"两项。AIRA_2 [R8] 报告，按验证集选择会随搜索变长而过拟合。

### A-Q003 OPSD 用于多轮 agent：已拥挤
When Privileged Guidance Misaligns [R12]（2026-08，10 月修订）研究的是：学生走到参考轨迹没有覆盖的状态时，以参考为条件的教师会惩罚正确动作（状态—参考失配），并给出状态匹配路由与情境化自蒸馏两种修法。这正对应本卡的关键条件"特权信息能否由学生通过自己的动作取得"。

### L-Q009 监控器长转录 × 奖励设定错误：中
单因素"长上下文使监控器退化"已有两项工作：本卡证据 Classifier Context Rot，以及 Paranoid Monitors [R9]。两因素交叉，以及 OOD 失败类型在长转录下的召回，本轮没有检出直接工作。

2026-11-03实际打磨：3次独立首审为6.5→6.8→7.5；最后候选研究“当前日志内用局部/跨步已知事件比较读取干预，再用于原日志选择”，是允许保留的邻近子问题。末轮重要性/新颖度/有效性为8/8/6、可行性pass，但漏掉公开强提示/混合对照，尚未正式通过或复核。已补齐为IDEA-008，仍未复审；原始奖励训练×长度交互未回答。详见`review-stage/monitor_observability_lq009_20261103/实际打磨与技能修改报告.md`，不把本轮结束标为原问题放弃或解决。

### A-Q007 多智能体工作流 RL：低–中，出现竞争解释
本卡来源 2605.24202 是单种子研究，作者用角色级梯度动态来解释独立策略的后期断崖。Dr. MAS [R14] 则给出另一种可检验的解释：多智能体 GRPO 的全局归一化基线偏离各角色自己的奖励分布，导致梯度范数不稳定；改为按角色归一化后，非共享策略设置的提升更明显（例如 57.5 / 74.4 → 61.1 / 77.7）。Dr. MAS 没有讨论"后期断崖"，也未见在 2605.24202 的三种工作流上复现。

除本卡证据 2605.12070 外，没有检出直接新作。但它需要异步 RL 基础设施，算力适配为低–中，卡片也已标为"部分解决"。

## 3. 推荐顺序（交给 idea-improvement-loop）

按问题分量排序：失败是否重要、机制是否未定、已有修法是否只治症状。拥挤度只作为风险标注。

1. **A-Q007 多智能体工作流 RL 中独立策略的后期断崖**
   - 为什么值得做：多智能体 LLM 工作流做端到端 RL 越来越常见。独立策略的后期断崖是一个具体、可复现的失败；现有两种解释（角色级梯度动态 vs 全局归一化失配）都没有在同一设置下被对照。原证据只有单种子。
   - 风险：要先核对 Dr. MAS 是否已在相同工作流上覆盖。
   - 算力：≤4B，双卡即可起步。
2. **L-Q009 监控器在长转录与奖励设定错误同时出现时的召回**
   - 为什么值得做：监控器是 RL 训练与部署中的主要监督手段。两种已知退化因素同时出现时是否超加性，目前没有受控证据。如果超加性成立，现有"分段监控"一类修法可能只治了一半症状。
   - 风险：单因素已有两项工作，交互新意要靠设计撑起。
   - 算力：被监控策略可自训（≤8B），监控器需要 API 或 70B 级推理。
3. **A-Q006 异步 RL 缺 old logits**：问题清楚且冷清。但需要异步 RL 基础设施，算力适配低–中，作为备选。
