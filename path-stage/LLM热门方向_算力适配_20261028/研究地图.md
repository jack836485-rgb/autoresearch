**现在火的方向**：按旧图的 arXiv 关键词份额倍数（当前窗口占 LLM 论文的比例 ÷ 去年同期），增长最快的是：

|---|---|
| 在策略蒸馏 / 自蒸馏（OPD/OPSD） | 10.0× |
| 循环深度 LM | 9.4× |
| 技能库 / 自进化 Agent | 5.3× |
| 代码智能体 | 3.8× |
| Rubric 奖励 | 3.2× |
| 自动研究 / AI 科学家 | 3.2× |
| Agent 记忆 | 3.2× |

测试时扩展（0.52×）、过度思考（0.44×）、RL 熵 / 探索（0.56×）的份额在下降。本周 Hugging Face 热门页上新集中出现两个标签：

- **递归自我改进（RSI）**：约 10 个标题，包括本周最高赞的 Trinity；
- **Agent harness**：约 8 个标题。

二者都是"自进化 Agent / 自动研究"的延伸。另外，Agent 记忆、扩散 LM、自蒸馏各有 4–7 个标题。

**算力判断**：17 张问题卡中，10 张适配高，最小可证伪实验落在 ≤8B 全参训练或 ≤35B 推理，8×A100 能做。其中 L-Q003、L-Q004、L-Q006、A-Q007 在预研卡上就能起步。另有 3 张中–高，GPU 够用，主要受多种子耗时或 token 约束。只有两类明显超出：

- 循环深度 LM（L-Q002）需要从头预训练；
- 异步 agentic RL（A-Q006）需要大规模异步 RL 基础设施。

**本周带来的变化**：

- **Agent 记忆（L-Q006）**：两篇系统评测显示，多数专用记忆系统不如朴素 RAG。LongMemEval-s 上，一个记忆系统 31.8%，两轮朴素 RAG 72.2% [N1][N2]。作者把损耗归为记忆处理隐藏或丢弃了证据。原卡"条目级损失归因"的空间收窄。

### L-Q006 整合式记忆随更新变坏：本周的系统评测改变了什么

- **新增证据**：
  - Memory Tax [N1] 跨会话、经验、世界模型三类记忆基准，在 Qwen3.5-4B、Qwen3.6-27B 和一个闭源模型上比较记忆系统与朴素 RAG。最强一例：LongMemEval-s + Qwen3.5-4B 上，OpenViking 31.8%，两轮朴素 RAG 72.2%。两组共享 Qwen3-Embedding-0.6B 嵌入器，用 Qwen3.6-27B 判分。
  - 作者把记忆的净值拆成"设计收益"和"税"，税指记忆处理把证据隐藏或丢掉。
  - [N2] 在 LoCoMo、LongMemEval、MEME、MemoryAgentBench 上得出同方向结论：Raw-RAG 在 7 个设定中 6 个排第一。该篇机构待核实，只作背景。
- **与原卡的关系**：
  - 旧卡的观察是：流式逐步整合比一次性整批整合低 17–38 个点，原卡缺的是条目级的损失归因。
  - [N1] 的"税"在概念上就是这类归因，但本轮只抽取到摘要级结论，没读到分解方法是否细到条目、是否随更新次数变化。
  - 所以状态写成"可能已被部分覆盖，待读分解方法确认"，不写成已解决。
- **剩余切口**：
  - 损耗随更新次数的时间动态：第几次改写开始丢证据，丢的是条件还是实体；
  - 只追加记忆是否同样随规模出现"税"。
  - 两者都只需推理，预研卡就能做。
  - 风险是本周已有两篇系统评测，主会审稿会要求明显超出它们的分解粒度。

### L-Q001 自蒸馏：本周新证据不回答原问题

- [N3] 用外部教师（Qwen3-32B 等）蒸馏 Qwen3-0.6B 至 4B 学生。Qwen3-4B 配 Qwen3-32B 时，Bridged 63.9，vanilla OPD 60.3，基座 59.2；12 组配对相对基座提升 1.2–4.7 分。
- 原卡的对象是"同一模型 + 特权上下文"作教师在长预算下的退化，[N3] 的教师设置不同，不能拿来支持或反驳原卡。
- 它的价值在成本参照：训练、评测和消融合计约 1450 H100/H200 GPU 小时。按 A100 比 H100 慢约 2–3 倍粗估，在 8×A100 上约需 2–3 周。这只是按 GPU 小时换算的量级，未考虑长序列显存与吞吐差异。
- 你的 opsd_thinking_q001 的实验规模可以以此作上限参照。

### 算力判断的依据

- **8×A100 能做全参 RL / OPD 的规模**：L-Q001 的两篇核心证据分别在 8×H100、8×A800 上训练 1.7–8B 学生 [旧图 1][旧图 3]，与 8×A100 同卡数；A-Q002 的证据在 8×A100 上训练 12 小时 [ARL 旧图 10]。所以 ≤8B 全参训练判为"高"。
- **只需推理的卡**（L-Q004、L-Q006、部分 L-Q005）：7–35B 推理在 8×A100 上可行，≤8B 在预研卡上即可。
- **L-Q002 判为低–中**：核心对照要求循环与非循环模型在等训练 FLOPs 下各训一个，证据规模 0.6–60B，多为从头预训练。8×A100 只能覆盖 1B 以下、较少 token 的设定，结论能否推广到主会审稿认可的规模存疑。
- **A-Q006 判为低–中**：需要异步 agentic RL 框架，证据规模到 30B，以系统工程为主。
- **API 与 token**：L-Q005、L-Q007、L-Q009 依赖较多 agent 轨迹或 LLM 判官，与"token 稀缺"冲突，是这几张卡的主要约束；GPU 不是。

## 8. 术语表（本图新增部分；其余见旧图 §8）

| 术语 | 说明 |
|---|---|
| 递归自我改进（Recursive Self-Improvement, RSI） | 让 agent 改进自身或其他模型的训练流程、代码或 harness，再用改进后的系统继续改进。与"自动研究循环"高度重叠，区别多在叙事上，强调多轮迭代的累积 |
| Agent harness | 包在模型外面的执行框架：工具调用、上下文管理、重试与验证逻辑。harness 进化指自动改写这层框架而不改模型权重 |
| 记忆"税"（memory tax） | [N1] 的说法，指记忆系统在写入、压缩、整合时把原本可检索到的证据隐藏或丢弃造成的损失 |
| 朴素 RAG / Raw-RAG | 直接对原始历史做稠密检索（可加重排），不经过记忆系统改写 |
| GPU 小时换算 | 本图按 A100 比 H100 慢约 2–3 倍做量级换算，只用于判断是否在 8×A100 的周级预算内 |
