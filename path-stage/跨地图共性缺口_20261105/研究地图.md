## 摘要

过去的卡几乎都卡在同一处：Reviewer 给的重要性中位数 6.0、新颖度中位数 6.0，27 次打分里只有 2 次出现过 ≥8 的维度。主阻断不是 brief 写法，而是卡片本身的形状——**以单篇论文的局限为起点、在单一领域里问"来自 A 还是 B"**，结果要么是原作者已写进未来工作、要么被 2026-08 至 10 月的局部近作覆盖。

本轮把 89 张卡按"同一失效关系在不同载体上重复出现"重新归并，得到 10 个跨载体问题。首版的 4 个：

1. **Q001 产物价值随消费者翻转。** 更强的模型给弱模型挑修复，同预算下反而更差；冻结读者只能消费接近自己会写出的 KV；同一套上下文工程技术对一类 agent 有益、对另一类有害；harness 受益随基座能力非单调。各载体各有一篇局部论文，**没有检出把"生产方质量指标为何不预测消费方收益"放在多种产物上一起回答的工作**。
2. **Q002 知行差距断在哪一步，取决于怎么测"知道"。** 用显式结论测，结论到动作几乎不出错（<2%），错在推理到结论；用探针测，信息可解码但到动作时方向近乎正交。这是一个未对齐的跨论文分歧，直接决定该在哪一步干预。
3. **Q003 辅助内容的收益何时真依赖内容。** latent 链、视频记忆、压缩记忆、提示区 KV 都出现"换成别的内容收益几乎不变"；PAST 给出特权教师的可迁移/不可迁移分解。候选统一解释是"该内容携带了消费者自己拿不到的信息"，但跨载体检验未检出。
4. **Q004 净增益里藏着的破坏。** 净增益 +55 的干预破坏了它触及的原本正确决策中的一半以上；模型版本更新的回归预测已有负结果，干预场景未测。

扩展的 6 个：

5. **Q005 训练预算之内的改进，到预算之外反号。** OPSD 在 4k–8k 评测预算持平或更好、32k–38k 更差；latent CoT 训练 K=4 时 82.0%，推到 K=32 降到 63.7%；循环 LM 外推循环数时推理分升、知识分从 62.80 降到 52.11；带 compaction 训练的模型在 compaction 模式变好、单窗口与长窗口模式变差。各自被当成本方法的外推问题，没有被当成同一种"训练预算错配"来预测反号点。
6. **Q006 改写式状态为什么输给只追加的状态。** LLM 持续整合记忆，效用先升后降、可跌破无记忆基线；只追加的情景记忆与整合器相当；复杂记忆系统输给朴素 RAG；KV 通信里"追加"可行而"替换"失败；对话复位时删除带压力的历史比保留历史再修复可靠。改写引入的是"看似可信的错误"而不只是缺失，代价是否随改写次数累积未测。
7. **Q007 评估信号读取被评者的自述，在优化下是否被利用。** 把 GUI agent 自己的成功报告从评判器输入里拿掉，危险误报召回提升 43.4pp；进化搜索中算子把 top-100 成功率高报 4.8–9.3 倍，适应度选择不改善报告质量；研究 agent 收到评审理由后，规避的模型–任务对 5 轮内从 7 增到 56。静态的"自述泄漏"已有研究，**训练中策略是否学会操纵这条自述信道没有检出直接测量**。
8. **Q008 禁止类约束与必需类约束谁更易丢：两组证据方向相反。** 长对话里禁止类约束遵从率从第 5 轮 73% 降到第 16 轮 33%、必需类保持 100%；agent 轨迹里却是"未履行的必需义务"（56.92%）多于"执行了禁止动作"（30.00%）。
9. **Q009 后训练的覆盖坍缩是逐任务锐化，还是跨任务耦合的集体效应。** 无标签 RLVR 只在题目多时坍缩，理论解释为共享参数下的集体失稳；有监督 RL 的锐化税、文生图 RL 的多样性坍缩、单模拟器 RL 的策略熵归零是否同一机制，未检验。
10. **Q010 对齐与纠正干预只在被评测的上下文形式下成立。** 混入良性数据、inoculation 等常见干预让通用提示下测不到涌现失配，带训练情境线索的提示却仍能引出；拒绝在工具通道里失效；情境翻转后模型承认变化却坚持原规则；EM 的"邪恶程度"可由评测提示到训练数据中心的表示距离预测。这条距离能否跨干预类型预测"干预在新上下文形式下是否保持"，未检出研究。

### 1.2 六条教训（每条都对应可复核的 FATAL 记录）

**L1 卡片锚在单篇论文的局限上，去掉论文名就只剩"补一个对照"。**
RSI Q003 两次都死于"单系统单实验的混杂审计、原文已自承"（Hyperagents）；`colar_latent_relay` 的对照"由最高近邻讨论直接引出"（C-MTP §4.3/§4.5）；`compaction_rl_attribution` 是"DSSR §5.6/§7 明确提出的修补方向"；`credit_localization` 是"2609.02417 §7 明文预测"；`blindzone_position`、`hack_onset_gates`、`diffusion_opd` 同样围着 ScreenHaystack／HVTA／GFD 一篇论文转。重要性因此被压在 6。
→ 准则 C1、C2。

**L2 热门方向里，局部近作出得比打磨快。**
`async_old_logit` 五轮分数 6.0→4.5 持续下降，每轮主阻断都是"核心思想已被近作覆盖"，关键近邻在第 3、5 轮才由 reviewer 指出；`harness_weight` 被 Harness-Zero 覆盖；`em_template_gate` 被 TReFT/Piggyback 覆盖；`marl_info_asym` 事后才把拥挤度从"低–中"改成"高（源论文作者已自答）"。单领域的卡在 2026 年下半年平均只有几周的空窗。
→ 准则 C5：地图阶段按"问题族"做一次反证检索，拥挤写成风险。

**L3 "来自 A 还是 B"的二分问题，常常 A、B 不可分或根本不互斥。**
`blindzone_position`："位置编码 vs 训练覆盖"二分错误，实验推不出主 Claim；`nl_direct_supervision`：2×2 无法区分多模态、误差累积和压缩压力，三种假说都预测恢复；`completion_gradient`：截断历史仍带进度线索，前提不成立；`rsi_recursion`：判别阈值被 headroom 机械保证成立。
→ 准则 C4：卡片写"什么量随什么变化"，并记录判别所需的噪声下限与 headroom。

**L4 把近邻领域的方法搬过来，新颖度天花板是 6–7。**
`incentive_search`（SecOPD → CUA，6）、`relational_binding`（REC → GUI，7）、`nl_direct_supervision`（NAT 蒸馏 → latent CoT，5.5）、`fewstep_coverage_rl`（LLM 组内混合信号 → T2I，7）。迁移本身是 idea 阶段的一条路线，但卡片层面若只给"本领域还没人做 X"，就把天花板定死了。

**L5 同一失效关系在多张地图里被各自当成本地问题打磨。**
特权／更强教师的失败出现在 L-Q001、A-Q003、N-Q001、GUI Q007、视觉 Q001；"信息在、行动不跟"出现在 GUI Q002、N-Q003、表示工程 Q001/Q006、低显卡 Q005、GUI Q009；"换内容收益不变"出现在 L-Q003、LatentCoT Q001、AI Q004、记忆 Q003、GUI Q003。每次都在本领域里被局部近作覆盖，但**跨载体的共同原因没有人回答**——这正是 idea-improvement-loop "共性不足"路线需要的输入，而旧地图一张都没提供。
→ 准则 C1：本轮的卡以跨载体关系为单位。

**L6 通过的三个 idea 的共同形状：可预测、跨方法、能改变决策。**
`rl_boundary`（用测试时的轮次接管对照预测哪种训练方法能扩大覆盖）、`opsd_thinking`（单项训练干预分离长度方向与准确率退化）、`llm_agent_low_compute`（自然数据上窄而独立的可证伪机制）。进行中最高分的 `em_conditional_mitigation`（7.0）则是"因子化操纵反转了已发表的归因"。
→ 准则 C3。

## 三、按问题展开

### Q001 同一产物对不同消费者价值相反：生产方质量指标为什么不预测消费方收益

**对象与失败条件。** 一个模型（生产方）产出另一个模型（消费方）要用的东西：修复动作、蒸馏教师分布、harness 与技能、上下文管理策略、KV cache。领域默认用生产方一侧的质量衡量它——评估器更强、教师更准、cache 更忠实、搜索集分数更高。下面五类载体都出现了"生产方质量更高，对这个消费者却更差或无效"。

**实验发现。**

- *修复选择* [1]：固定失败轨迹和单步候选修复，用部署体自己的独立 rollout 给每个候选打"部署价值"标签。部署体为 Qwen2.5-7B-Instruct 与 Llama-3.1-8B-Instruct，每个非筛选池 60 条失败（ALFWorld、WebShop）。同 rollout 预算下，用 Qwen2.5-14B 的 rollout 为 7B 选修复，ALFWorld 损失 0.25、WebShop 损失 0.07 的期望净收益；每候选 20 次 14B rollout 的价值不超过 7B 自己的 2 次。在 7B 与 14B 最佳候选不同的 37 条轨迹上，每分支每执行者再跑 30 次新鲜 rollout，确认两者确实偏好相反的修复。贪心重放也比部署体自选损失 0.08–0.13（ALFWorld）。
- *KV cache* [2]：两侧都冻结、把发送方 cache 换给读者时，读者只能读接近自己会写出的 cache；作者测了 8 种替换方法，全部停在无信息 cache 基线；与读者自身 cache 的几何相似度不预测可用性，失败也不是渐进的。
- *上下文工程* [3]：7 个 LLM、5 个基准共 1,514 个长程数据任务。无 CET 时 agent 自然分成"调查者／过早作答者／过早放弃者"三组；每种 CET 只在匹配的那组转成准确率（编排对过早作答者收益最大，语义层对放弃者）；**对调查者，每种 CET 都让准确率下降或不变且成本上升**，其最佳组合是不用任何 CET。
- *Harness* [4]：更新能力对基座能力几乎平坦（Qwen3.5-9B 产出的更新与 Opus 4.6 收益相近）；受益能力非单调（SWE 上 Qwen3-235B 19.3pp、Qwen3-32B 4.4pp、Opus 4.6 2.6pp，继承自 RSI 地图 Q006）。弱模型受益少的两个机制是没把技能等产物载入上下文（activation）和载入后不照做（adherence）。HarnessDev [5] 换成固定 Gemini 执行后，只有 Opus 生成的 harness 仍提升，其余退步（继承）。另一项受控研究 [6] 也得到 harness 敏感性非单调，且随 chat／reasoning 类型变化（单模型代表一档，作者自称只是模型特定观察）。
- *蒸馏教师*：自 RL 教师的损失降幅均值 96.2%，更大教师 25.1%（2610.11247，继承自 L-Q001）；同一检查点把学生的短直答 rollout 换成长思考 rollout，特权信息的增益在两个模型家族都变成损失 [7]；扩散跨尺度 OPD 中学生 rollout 上的 KL 与教师轨迹上的 KL 趋势相反（GFD-OPD，继承自视觉 Q001）。
- *上下文管理策略迁移*：对固定执行者学到的管理策略，按 agent 学成完全不同的压缩频率，与各 agent 原生 ReAct 能力排序一致（AdaCoM，继承自记忆 Q001）；TRACER 换到未见骨干后保留 62–87% 的收益，作者归因于"工具调用遵从度"这一消费者属性（本轮片段核对）。

**跨论文覆盖扫描（关键词级，抽查 3 条语义成立）：** 记忆压缩语料 129 篇中 14 篇做过换消费者测试，RSI 87 篇中 4 篇，GUI 85 篇中 3 篇；抽查的命中都只报告"迁移后保留多少"，没有给出预测保留率的量。

**解释与处理。** 每个载体都给出了局部解释：读者的 tolerable set 与竞争注意力 [2]；行为组与 CET 的匹配 [3]；activation／adherence [4]；教师在学生状态上不可靠（GFD-OPD）。局部修法：用部署体自己的 rollout 选修复 [1]（贵）；追加而不是替换、只适配 query 侧 [2]；按 agent 训练外部管理器（AdaCoM）。**最接近的统一工作是 GRACE [21]：只用学生梯度的分布性质预测哪个教师适合离线蒸馏，GSM8K/MATH 上 Spearman 最高 86%**——说明"在消费者一侧测"在离线 KD 上可行。

**分歧与缺口。** (1) GRACE 只覆盖离线 KD 与数学；[1] 的消费者侧选择靠昂贵的自 rollout；[2][3][4] 只诊断不预测。(2) "更强生产者更差"在 [1] 是选择偏好相反，在 [2] 是分布不可读，在 [4] 是不激活/不遵循——**是否同一个消费者侧量（例如产物诱导的动作在消费者自身策略下的似然、激活率）能同时预测这几种失败，本轮未检出研究**。(3) 反证检索（"consumability"、"executor mismatch"、"student-specific teacher selection"、"agent-specific context management"）只找到上述局部工作。

**下游切口（种子，不是 idea）。** 固定若干产物，与若干消费者做"生产者 × 消费者"矩阵，至少跨两类产物；比较生产方指标与廉价消费方指标对消费者收益的预测力；控制 rollout／token 预算。需要区分的竞争解释：消费者分布接近度、消费者能力档、行为类型（chat/reasoning、调查型/草率型）。

**风险。** 每个载体都有 2026-10 的局部近作；下游若只在单一载体上做，会重演 L2。[1] 已经给出了修复载体上的强基线与协议。

### Q002 知行差距断在哪一步：不同的"知道"测法给出相反定位

**对象与失败条件。** Agent 在文本、探针或事实问答上显示它"知道"正确判断，动作却不跟。本项目在 GUI（推理承认冲突仍执行）、工具安全（文本里判 BLOCK 仍调用）、表示工程（可解码但 steer 无效）、失败恢复（诊断对、修复错）四张地图里各遇到过一次，局部打磨都因拥挤失败（`judgment_action_nq003` 5.5、`reason_action_gap_gui` 5.0）。

**实验发现（同一现象，四种测法）。**

| 测"知道"的方式 | 论文与设置 | 断点定位 |
| --- | --- | --- |
| 显式结论标签 | 德州扑克模拟器、三个模型家族 [8] | 结论→动作不一致 0.0–1.8%；用自由文本抽取结论时测出 22–26%，作者认为大部分是抽取噪声；65% 的错误决策里模型正确估计了输入并复述了规则，却得出相反结论，把规则写进提示也无效 → 断在**推理→结论** |
| 独立事实探针 | 17 个单次打分系统 + 1 个推理模型，覆盖客服、工具、网页、代码状态 [9] | 多数错误动作发生在事实读对之后，且系统越准，这类错误占比越高；在事实可证明决定动作的状态上，用代码组合模型自己的事实答案就能修复 → 断在**组合事实成决策** |
| 隐状态探针 | Qwen3-8B/4B、Llama-3.1-8B/3.2-3B，算术与 TruthfulQA 的工具必要性 [10] | 端到端失配 26.5–54.0%（算术）、30.8–41.8%（TruthfulQA）；"是否需要工具"与"是否调用"都线性可解码，但在驱动下一 token 的末层末位置方向近乎正交；失配集中在**认知→动作** |
| 判断侧干预 | 3 个开源模型的工具安全 [11] | 安全信息可从动作状态读出（继承：跨家族 AUROC 0.756–0.875），把判断推向 BLOCK 的干预对动作偏好影响小得多 → **判断与动作的因果控制耦合弱** |
| 推理文本移植 | 文本网格世界 [12] | 把另一决策的推理前缀移植过来，强制动作随移植走（π(a_B) 0.598–0.673 对 π(a_A) 0.129–0.165，396 对错配 + 396 对一致对照）；但推理窗口的激活编辑控制力有限；任务信息的表示比行为更可靠 |

**解释与分歧。** 把表对齐后，矛盾的形状是：**以文本形式形成的结论几乎总能控制动作**（[8] 的显式标签、[12] 的移植），**而探针测到的"知道"常常不控制动作**（[10][11]）。两种读法都说得通：(a) 探针可解码的信息不等于模型实际使用的判断（与表示工程 Q001 的"可解码 71.6% 但 steering Δ≈0"一致，2605.05715，继承）；(b) 文本结论本身就是模型做决策的地方，失败在组合与推理 [8][9]；(c) 一部分差距是测量伪影（[8] 的一个数量级差异）。三种读法预测不同的有效干预：(a)(b) 下该修推理或组合（显式决策标签、代码组合 [9]），动作侧 steering 无用；若断点真在认知→动作，则动作侧干预才有效（[11] 报告动作原生干预更有效）。

**缺口。** 2026 年本轮检出至少 7 篇各测一步的工作（另有 2601.07972、2603.22619 等未读），**没有检出把探针、显式报告、强制结论/移植三种测法放在同一批决策状态与模型上、并检验哪种定位能预测哪种干预成功的研究**。这正是方向拥挤时更细的被忽视子问题。

**下游切口。** 同一批决策状态上并列三种"知道"的测法；记录每种测法下的断点；用"规则注入、显式决策标签、代码组合、动作侧 steering"四类干预检验哪个断点有预测力。需控制：结论抽取方式（[8] 已证明会差一个数量级）、模型家族、是否推理模型。

**风险。** 现象层面拥挤；只做"又一个领域的知行差距测量"会直接重演 N-Q003/GUI Q002 的失败。

### Q003 辅助内容的收益何时真的依赖内容：消费者能否自己取得这份信息

**对象与失败条件。** latent 思维、检索记忆、压缩记忆、摘要、提示区 KV、特权教师都声称把"信息"交给消费者。多个载体上，换成别的内容收益几乎不变。

**实验发现。**

- *压缩记忆* [13]：9 个系统（ICAE、CCM、Activation Beacon、MemoryLLM 等）。置零记忆会降分，但另训一个无记忆模型反而更好的情况存在；TriviaQA 上给 xRAG 另一题的段落，F1 从无文档 19.38 升到 24.78，本题段落 29.88——超过"无文档"的增益不能说明需要本题内容。作者提出用"常量输入训练的模块"分离不需文档事实的增益。
- *latent 推理与视频记忆*（继承）：逻辑任务上"删链伤、换内容不变"，算术任务所有配方依赖内容（2610.21182）；化学 latent 交换后保留 94.5–103.3% 分数（2610.34173）；只保留边界标记找回 latent 视觉增益大部分（2606.01287）；视频记忆去身份对照几乎恢复全部收益（2609.12090）；提示区 KV 用中性模板替换可恢复、置零不行（2605.30574）。
- *Compaction* [14]：三个前沿模型、三个长程基准，1M 上下文模型对压缩阈值不敏感；作者的解释是基准有固定目标、无中途用户输入、有可重读的文件系统，被丢的内容多能找回；在 44 个真实人机编码会话中，关于"怎么做／别做什么"的指令被丢的频率约是"做什么"的 6 倍，而这类用户指令在别处不存在。
- *有损记忆* [15]：7 个模型上，留下错误结论却丢掉过程的记忆会让模型自信给出错误值，而空记忆时模型会弃答（白名单外，摘要级）。
- *特权信息教师*：多轮 agent 上 OPSD 低于 GRPO，纯 OPSD 低于未训练基座（PSP，继承自 A-Q003）；数学上特权信息在无参考蒸馏之外只增加有限收益 [7]。**PAST [16] 给出形式分解：教师–学生分歧 = 学生前缀条件下动作与特权变量的条件互信息（任何只看前缀的策略都学不到）+ 学生可得的因果偏移；完美的特权教师不一定能迁移（其 Proposition 4）。**

**解释与处理。** 已有：任务类型解释（逻辑占位、算术依赖内容，2610.21182）；评测协议 [13]；OPSD 下的信息论分解 [16]。经典 RL 里，部分可观测下模仿特权专家的"imitation gap"是已知问题（窗口外背景，本轮未读原文，下游需补）。

**待验证解释（本地图提出，未经检验）。** 内容特异的收益大小，取决于该内容携带的、消费者从自身观测与动作中拿不到的信息量；[16] 的条件互信息项是这一量在 OPSD 上的形式。[14] 的"可重读文件系统"和 A-Q003 的"特权信息能否由学生动作取得"是同一个变量的两个实例。

**缺口。** 未检出在同一任务内操纵"可得性"（例如有无可重读文件系统、特权信息能否经动作获取）而保持内容不变、跨 ≥2 种载体检验内容收益的研究。

**下游切口。** 按 [13] 的对照协议（置零、换题内容、常量输入训练）测内容收益，在任务内改变可得性；观察内容收益是否随可得性单调。注意：`nl_latent_content_q001` 曾因"以任务类型解释已被 2610.21182 占据、CoT 收益与任务类型共线"被拒，**所以变量必须是任务内操纵的可得性，不能是跨任务的任务性质**。

**风险。** PAST 已在 OPSD 上给出理论，下游若只做 OPSD 会被判为验证已有理论；单载体的内容对照已有 [13]。

### Q004 净增益掩盖的破坏：干预同时修复与破坏时，破坏集由什么决定

**对象与失败条件。** steering、RL、OPD、harness、CET 都按净分报告；净分是"错改对"减"对改错"。

**实验发现。** 工具调用前决策（When2Call、MetaTool，7 个 LLM）上，一个净增益 +55 的方向干预破坏了它触及的基线正确决策中的一半以上，59 个预算匹配的随机方向都达不到目标增益 [18]；无门控 steering 下，原本答对的规则准确率随强度单调下降、错误集中在目标标签（2608.29431，继承自表示工程 Q006）；CET 的过程收益可伴随准确率损失 [3]；OPD 增益集中在小 k、可解集不扩大（2610.03185，继承）；共装技能冲突时核心约束失效但任务仍计为完成（2610.11647，继承，摘要级）。

**已有处理与反证。** 模型版本更新的"回归／负翻转"有成熟文献（2105.03048、FlipGuard 2410.00508，背景未读）；**2608.13607 在 6 个基准、6 对版本更新上发现没有通用信号能预测样本级回归** [19]——这是对本问题的直接负证据。[18] 已提出 destination 审计流程。

**缺口与切口。** 干预（而非版本更新）场景下，破坏是否集中在"基线答对所依赖的信号恰被干预目标覆盖"的样本上，未检出研究。切口：对同一干预做翻转矩阵，检验破坏集与干预方向的关系；对照 [19] 的信号集。

**风险。** 有直接负证据；评测审计类贡献在本项目历史上重要性常被压在 6。列为第四。

### Q005 训练预算之内的改进，为什么在预算之外反号

**对象与失败条件。** 后训练和测试时扩展都隐含一个单调假设：评测给更多预算（更长生成、更多 latent 步、更多循环、更长上下文），结果不会更差。四类方法在训练预算之外出现反号。

**实验发现（均继承自旧地图 Tier B 记录，另加 2 篇摘要）。**

- *OPSD* [22]：Qwen3-1.7B 三基准均值 0.372→0.308；4k–8k 评测预算持平或更好，32k–38k 更差且回复更短；训练时关思考的版本与基线持平（0.590 对 0.591），开思考 0.532（L-Q001）。另一条预研记录：`opsd_drift` 打磨发现 1024 token 训练窗口内几乎没有终止位置（review-stage FATAL）。
- *latent CoT* [23]：Coconut 训练 K=4 时 82.0%，K=16 71.4%，K=32 63.7%；RDT 91.3%→71.9%（LatentCoT Q003）。
- *循环 LM* [24]：2×10 训练外推到 L=40，推理 28.52→31.49，知识 62.80→52.11（L-Q002）。
- *带 compaction 的 RL* [25]：30B 完整 CompactionRL 在 Comp 模式 SWE 50.5→56.0，单窗口模式 47.5→43.7、长窗口模式 53.5→49.0（记忆 Q001）。
- *rollout 数错配* [26]：训练只有 m≪N 个 rollout、部署按 best-of-N 时，标准目标优化单样本均值而非上尾（理论，摘要级）。*长度税* [27]：RL 让已解决的问题回复变长而准确率不增，作者用在线蒸馏把这部分从 19.0% 降到 −3.7%（摘要级）。

**解释与处理。** 各自的局部解释：OPSD 是特权教师上下文分布偏移与认知词密度下降（2607.10805，继承）；latent 是秩坍缩与漂移；循环 LM 无机制解释；CompactionRL 未解释；rollout 数错配有尾部结构假设下的理论 [26]。

**缺口。** 未检出把"训练时预算 B_train 与评测预算 B_eval 的错配"作为共同变量、在 ≥2 类方法上预测反号点的研究。下游要区分：评测时进入训练未见状态（分布外）、训练目标只在窗口内定义（如终止 token 在窗口外缺失）、以及资源增加本身带来的长度税。

**下游切口。** 在两类可廉价重训的方法上（OPSD、带 compaction 的 agent RL）系统改变 B_train，记录 B_eval 扫描下的反号点；检验反号点是否随 B_train 平移。循环 LM 与 latent 需要重训架构，算力上作为可选。

**风险。** 每个方法单独做都是"补一个外推实验"（重演 L1）；必须以跨方法的反号点规律为单位。

### Q006 改写式状态为什么输给只追加的状态

**对象与失败条件。** Agent 记忆整合、摘要式 compaction、KV 通信、对话修复都要在"改写现有状态"与"保留原文、只追加"之间选。多个载体上，改写方案输给简单的追加方案，而且输法是引入错误，不只是丢信息。

**实验发现。**

- *持续整合记忆* [28]：整合进行中效用先升后降，可跌破无记忆基线；即使从标准答案整合，GPT-5.4 在其先前无记忆能解的一组 ARC-AGI 题上失败 54%；流式比整批低 17–38 个点，WebShop/ALFWorld/AppWorld 上只追加的情景记忆与整合器相当（继承 L-Q006）。
- *摘要条目* [29]：667 个 summary 的 26,881 条中 17.9% 无来源；待处理用户请求 86.1%、开放待办 67.7% 无来源，推理类条目每个 summary 重写约 4 条；作者称 83% 失败运行可追溯到执行某条 summary 条目的动作（白名单外，继承记忆 Q005）。
- *记忆系统净值* [30]：LongMemEval-s + Qwen3.5-4B 上一个记忆系统 31.8%，两轮朴素 RAG 72.2%；另一篇报告 Raw-RAG 在 7 个设定中 6 个第一（2610.30755，继承）。
- *有损记忆* [15]：留下错误结论、丢掉过程的记忆让 7 个模型都自信给出错值，空记忆时弃答。
- *KV 通信* [2]：替换读者 cache 失败，追加可注意上下文并只适配 query 侧可行。
- *对话修复* [31]：保留历史的修复只在 2–3/14 个模型–数据集组合上恢复到干净行为，删除带压力的历史明显更可靠（继承 N-Q004）。

**解释与处理。** [32] 把 KV 驱逐、提示压缩、状态有界、记忆整合统一为率失真决策，给出统一目标与下界（摘要级）。修法：只修剪 summary 不修剪历史 [29]、保留原文加引用（ARC，继承低显卡 Q003）、追加式通信 [2]。

**缺口。** 率失真视角把损失看成"失真"，但上述证据显示改写会**写入生产者自己的推断并以事实身份呈现**（无来源条目、过时结论），这种错误比缺失更难被下游纠正 [15][31]。未检出研究在同一任务上把改写错误分成"缺失、无来源推断、过时"三类、并测其代价是否随改写次数累积、是否跨载体一致。

**下游切口。** 同一批轨迹在固定预算下比较追加式与改写式状态；按改写次数记录三类错误的累积曲线与下游失败的归因；检验"追加 + 检索"相对改写的优势是否来自可纠正性。

**风险。** 记忆方向 2026-10 拥挤（本轮窗口内至少 8 篇诊断与基准）；单载体的"追加更好"已被多篇报告。

### Q007 评估信号读取被评者的自述：在优化下是否被利用

**对象与失败条件。** GUI 评判器、研究 agent 的评审面板、CoT 监控器、进化搜索里的自评，都会读到被评者自己写的东西（成功声明、推理、理由）。静态评测里，这条自述信道已经造成系统性偏向接受。

**实验发现。**

- *自述泄漏* [33]：同一评判器读同一任务与轨迹，只改变是否附上 agent 的最终报告；拿掉报告后，危险误报（有成功声明而轨迹不支持）召回提升 43.4pp（Qwen3.5-35B-A3B）与 13.3pp（DeepSeek-284B-A13B），留出批次趋势相同。
- *自报告不是核验* [34]：进化 Contexto 搜索、200 次运行、5 种配置、3 个模型家族、12,249 条自报告；算子把 top-100 成功率高报 4.8–9.3 倍，继承的理由不影响后续提议，按适应度选择也不改善报告质量（白名单外，摘要级）。
- *GUI 评判器* [37]：过度接受约占全部错误的 2/3，每个评判器 ≥48%；Hard 集所有评判器降 20–43pp（继承 GUI Q001）。
- *研究 agent* [35]：17 个模型、38 个任务；LLM 评审面板返回决定与理由后，规避的模型–任务对 5 轮内从 7 增到 56；只看代码和分数的面板漏检 33/505（继承 RSI Q005，作者说明反馈内容与轮数未分离）。
- *CoT 可监控性* [36]：奖励设定错误下 hack 率上升，CoT 仍写得顺从或塌缩，监控以假阴性为主；更强监控器平均只提高 0.09/0.12（继承 L-Q009）。

**解释与处理。** 已有：报告隔离的审计器 [33]；环境落地审计 [34]；确定性护栏（2609.02246，检出未读）；闭环人工复查（2606.26300，继承）。

**缺口。** 现有证据要么是静态的（[33][34][37] 不训练被评者），要么是对抗式或多轮反馈下的规避（[35]）。**在以"读自述的评判器"作奖励的常规 RL 中，策略是否学会抬高自述（更自信的成功声明、更像完成的叙述），以及这一效应的大小相对真实能力提升是多少，未检出直接测量**——GUI Q001 当时已标"本轮未检出"，本轮扩到研究 agent 与 CoT 监控后仍未检出。

**下游切口。** 同一 RL 配方下用"读自述"与"报告隔离"两种评判器做奖励，跟踪训练过程中自述泄漏量（[33] 的 aware/blind 差）与真实成功率的分离；控制评判器模型与调用预算。

**风险。** 2026 年监控与评判器方向论文多；本项目历史上监控类卡曾拿到重要性 8（L-Q009），但有效性论证是卡点。

### Q008 禁止类约束与必需类约束谁更容易丢：两组证据方向相反

**对象与失败条件。** 长程执行中，"不要做 X"（禁止／omission）与"必须做 Y"（必需／commission）两类约束的保持情况。

**实验发现。**

- *长对话* [38]：12 个模型、8 家提供方、6 个对话深度、4,416 次试验；Mistral Large 3 上禁止类遵从从第 5 轮 73% 降到第 16 轮 33%，必需类保持 100%；必需类定义为需要主动产生某个 token/字符串，禁止类为压制默认生成行为；在有 token 匹配填充对照的两个模型上，schema 语义内容解释 62–100% 的稀释效应；在每个模型的安全轮深之前重新注入约束可恢复遵从。
- *Compaction* [14]：真实会话里"怎么做／别做什么"类指令被丢的频率约是"做什么"的 6 倍；每次压缩丢弃的约束类别 GPT-5.3-Codex 2.73/3、GPT-5.4 1.76、Claude Opus 4.6 0.51（继承记忆 Q005）。
- *agent 轨迹* [39]：56.92% 的轨迹含未履行的安全义务，含禁止动作的只有 30.00%（继承 N-Q003，摘要级）。
- *受控因子* [40]：独立操纵目标压力、控制退化与可执行的不安全机会，假设"控制边界退化在环境暴露越界动作时才造成后果"（白名单外，摘要级）。

**分歧。** [38] 与 [14] 显示禁止类更易丢，[39] 却显示必需的安全义务更常不被履行。可能的对齐方式：[38] 的"必需类"是输出格式型（产生某个字符串），[39] 的"义务"是需要多步执行的动作（如先确认再操作）；两者中的"必需"不是同一种约束。也可能是度量口径不同（逐轮遵从率 vs 轨迹级是否出现）。本轮未读 [39] 的定义细节，标"待解释分歧"。

**缺口与切口。** 未检出在同一 agent 环境里按"禁止/必需 × 输出型/动作型"四格构造约束、并在上下文压力（深度、compaction 次数）下测保持率的研究。切口：四格因子设计，控制约束难度与位置，[38] 的填充对照可沿用。

**风险。** 现象已被 [38][40] 及 2606.22528、2608.11242 直接研究，拥挤；剩余空间在分歧本身与机制。

### Q009 后训练的覆盖坍缩：逐任务锐化，还是跨任务耦合的集体效应

**对象与失败条件。** RL 后训练提高单样本成功率、降低大 k 覆盖或多样性，这一现象出现在文本 RLVR、文生图 RL、单模拟器 agent RL 与无标签自训练中。

**实验发现。**

- *集体失稳* [41]：无标签 RLVR 只在题目多时坍缩；理论上，共享参数下不同题偏好不同答案的群体会放大任何共享扰动，逐题锐化速度按 1/N 变慢，共享模式增长 ∝λ² 且与 N 无关，由此给出临界数据规模；纠正答案边际分布的不平衡不能阻止坍缩（理论与随机模拟）。
- *锐化税* [42]：k=128 时 36/42 组的锐化税为正，后训练把任务推向"总是解出"或"从不解出"两端（继承 A-Q001）。
- *文本多样性坍缩的位置* [43]：Olmo 3 三条后训练谱系、15 个任务；坍缩位置随数据组成变化，Think 谱系在 SFT 阶段失去大部分语义多样性（摘要级）。
- *文生图* [44]：Flow-GRPO 类 RL 中协方差由固定噪声调度决定、策略熵不变，感知多样性坍缩、奖励方差逐步下降（继承视觉 Q003）。
- *单模拟器 agent RL*：策略熵趋近零，迁移到未见模拟器失败（2608.12253，继承 A-Q005）。
- *跨运行一致* [45]：两个 1.5B 基座、18 次后训练运行、最多 1532 题；独立运行在哪些罕解题上改进高度一致（噪声上限约 0.9），两基座之间只有 ρ=0.25——共享成分属于基座而不是题目（摘要级）。

**解释与处理。** [41] 是唯一给出"任务数依赖"机制的工作，但只在无标签 RLVR 上；其他载体的修法（多样性正则、课程、扩组、按方差筛题）都按逐任务锐化来设计。

**缺口。** 集体耦合解释是否适用于有验证器 RL、文生图 RL 与模拟器 RL——即坍缩是否随训练任务数/提示数呈现临界行为、是否由跨任务共享模式主导——未检出检验。[45] 的"改进由基座决定、跨运行共享"与集体耦合相容但未被这样解读。

**下游切口。** 固定总步数，扫描训练任务数 N，测大 k 覆盖与跨任务共享模式（如答案或图像特征的群体级对齐）；在文本 RLVR 与一种非文本载体上各做一遍。

**与用户已有 idea 的关系。** `rl_boundary_aq001`（已通过）研究多轮 agent RL 的覆盖扩展与预测；本卡的单位是"坍缩是否是集体效应"，打磨时需先与该 idea 划清边界。

### Q010 对齐与纠正干预只在被评测的上下文形式下成立

**对象与失败条件。** 安全对齐、涌现失配缓解、拒绝、steering、对话修复在"标准评测上下文"下有效，换成触发线索、工具通道、多轮历史或情境翻转后失效。

**实验发现。**

- *条件失配* [46]：GPT-4o 用 20% 有毒数据训练后，航海主题提示下失配 4.3%/1.4%/8.7%，通用提示 0%；inoculation 后良性系统提示仍可引出失配；推理蒸馏在 DeepSeek-V3.1 上 18.4%→3.1%，在 Qwen3-32B 上无效（继承 L-Q008）。
- *表示距离预测 EM* [47]：EM 训练后，评测提示离训练数据中心越近，引出的"邪恶程度"越高（作者报告平均 Spearman 相关，具体值本轮摘要被截断）；改格式后 EM 平均下降 52.5%（继承 L-Q008）。
- *情境翻转* [48]：12 个模型在安全基准与两个常识对照上做配对翻转；所有模型都有安全–常识差距（平均 +17.4pp）；基线准确率 >90% 的模型中脆性率从 13.7% 到 90.0%；模型在每个案例中都承认情境变化，却坚持原规则（摘要级）。
- *工具通道*：聊天中被拒的有害请求有 10–52% 在工具设置下变成不安全调用（2610.28982，继承 N-Q003）。
- *多轮*：早期成功的 steering 几轮后衰减或反转（2610.19817，继承表示工程 Q007）；保留历史的修复只在 2–3/14 组合上恢复 [31]。

**解释与处理。** EM 上有"表示距离"预测 [47]；方法上有上下文不变对齐 [49]（用可验证变体作锚点，摘要级）。

**缺口。** [47] 的表示距离只用于预测 EM 的引出强度。**它能否跨干预类型（缓解、拒绝、steering）预测"干预在新上下文形式下是否保持"，未检出研究**；若能，评测协议可以按距离挑上下文，而不是枚举触发。

**下游切口。** 对 2–3 类干预，测干预数据（或干预方向的构造数据）与若干评测上下文形式的表示距离，检验距离能否预测干预的保持率；控制模型与干预强度。

**与用户已有 idea 的关系。** `em_conditional_mitigation_20261022`（进行中，7.0）研究 cue 的领域匹配与处境风险的交互；本卡的单位是跨干预类型的距离预测，打磨时需与之划清边界，也可作为它的推广方向。

**风险。** 上下文不变安全对齐 2026 年已有多篇；单在 EM 上做会与 [47] 和用户已有 idea 重叠。

### Q011 奖励装不进未采样行为：起点采样率能否预测冷启动必要性

**问题。** 奖励类信号（结果奖励、稠密采用奖励、GRPO 组相对优势）在多个载体上只放大策略已经会采样的行为，装不进基座从不输出的行为（GUI 的 done()、agent 的压缩工具调用、未学会的 Python 工具）；蒸馏项或 SFT 冷启动则能装入。目标行为在训练起点的采样率（每组 rollout 中该行为的期望出现次数），能否跨载体预测“只靠奖励能否装入”，从而在开训前决定是否需要冷启动 SFT 或蒸馏项？

**证据。**

- Teach it to stop, not just to click（2607.17136，§Which term installs the stop?）：奖励项只能放大策略已采样的动作，无法装入 base 从不输出的 done()；仅蒸馏项可装入停止（1.00±0.00）〔边界：继承自 GUI_Agent研究地图_20261104 Q001；机构未核实；未给出基座 done() 采样率的定量阈值〕
- Memento: Learning Context Management for Long Context Processing Agents（2611.00244，§4.2.1 SFT Initialization and RL；§4.2.2 Context Folding）：SFT+RL 比仅 SFT 高 23.9 分、比仅 RL 高 8.8 分；不经 SFT 初始化时，RL 在前 20 步内把压缩率降到接近 0 并保持；SFT 初始化策略的压缩频率是未初始化策略的 4 倍以上，但 RL 开始时两者验证准确率几乎相同〔边界：继承自 Agent记忆压缩研究地图_20261104 Q001；单模型（Qwen3-8B）；RL 放弃压缩的原因未经干预区分〕
- Spurious Tool Use: When RL Agents Learn the Wrong Reason to Act（2609.16268，§5.3）：虚假调用率最多上升 39%（摘要）；捷径只对已学会的工具形成，Python 工具在 DeepMath 上没学会，就没有对应关联〔边界：继承自 LLM热门方向_刷新_20261101 A-Q004；该文研究的是虚假关联而非可装入性，此处只作旁证〕
- A Learning-Rate-Gated Failure of GRPO in a Small Language and Vision-Language Model Web Agent（2607.12640，§1 Introduction（总结其实验））：已掌握任务上没有配置可信地超过 SFT，中高学习率在文本轨道上更差；采样可达任务上同一配方成功率提升最多 22 个百分点〔边界：继承自 LLM热门方向_刷新_20261101 A-Q001；按任务可达性分组，而非按行为采样率分组〕
- On-Policy Distillation Teaches New Skills but Not New Knowledge（2610.09639，摘要）：反向 KL 的 OPD 能迁移组合技能但几乎不迁移事实知识；换成正向 KL 恢复事实迁移〔边界：继承自 LLM热门方向_刷新_20261101 L-Q001；摘要级。它说明“装不进”不只出现在奖励上，也出现在在策略 mode-seeking 目标上；候选调节量应是目标是否只在学生自身样本上计值〕
- Screenshots or Tools? Eliciting Tool Use and Managing Multimodal Context in Hybrid GUI–MCP Computer-Use Agents（2608.03327，§3.1–3.2、§5.2–5.3、Contributions、Per-domain 表）：推理模型只在 55/309 题调用工具，为可达题（230 题）的 23.9%，非推理模型 13.9%；VLC 17 题中 16 题可达但从未调用；稠密奖励使采用率提高一个数量级并保持到贪心解码，但留出准确率不随之提高，作者结论为“RL 触及了工具决策而非工具胜任”〔边界：继承自 GUI_Agent研究地图_20261104 Q008；提示“可装入”要分频率与胜任两层〕

**已有处理。** SFT 冷启动后再 RL（Memento 2611.00244）；在 RL 目标中加蒸馏项（2607.17136）；用正向 KL 替代反向 KL 以迁移知识（2610.09639）；稠密采用奖励提高调用频率（2608.03327，不提高胜任）

**下游切口。** 选 3 个载体（GUI 终止动作、agent 压缩工具调用、工具使用 RL 中的某个工具），用少量 SFT 步数或 logit 偏置把目标行为的起点采样率扫成 0/1e-3/1e-2/1e-1 几档，固定奖励与组大小训练 GRPO，记录行为最终出现率与任务成功率；再在低采样率档上把组大小加倍，检验“每组期望出现次数”能否作为统一横轴。

**查新。** 查询词：“RL fine-tuning cannot install behaviors base policy never samples, reward vs distillation, cold-start SFT necessity predicted by base sampling probability”。只拿到标题：Unifying ICL, SFT, KL-Regularized RL Through a Bayesian Lens（arXiv 2609.05111）、RL Starts before RL: On Policy Distillation for Better…（alphaxiv 2609.28145）、Demystifying Reinforcement Learning Post-Training of…（alphaxiv 2608.24949）等。未见以起点采样率为横轴、跨载体测装入阈值的工作；但 2609.05111 与 2609.28145 可能部分覆盖相关理论或“RL 前先蒸馏”的处方，需读摘要确认（标题级，未读）。

**风险。** “RL 只锐化”是广为讨论的直觉，审稿人可能视为已知。贡献必须落在定量阈值和跨载体统一横轴上，否则会退化为补对照。本卡与 Q009（覆盖坍缩集体效应）和旧卡 A-Q001（扩展 vs 锐化）相邻，要强调研究对象是离散行为能否装入，而不是任务级 pass@k。

**为何值得做。** 它直接决定后训练流水线要不要冷启动 SFT 或蒸馏项、要多少。如果阈值能由起点采样率预测，开训前就能省掉试错。

### Q012 训练监测量何时失去对部署结局的预测力

**问题。** 多种后训练中，训练期常用的监测量与部署结局背离：扩散 OPD 中，在学生 rollout 上算的 KL 与固定状态 KL 趋势相反；流匹配 RL 中，策略熵恒定而感知多样性坍缩；LLM RLVR 训推不一致时，训练端策略改进不保证推理端改进；LLM OPD 中，蒸馏损失降幅与最终增益不一致。监测量的计算分布在多大程度上由被训练策略自身决定（自参照程度），能否跨载体预测该监测量何时失去对部署结局的预测力？

**证据。**

- GFD-OPD: Guidance-Folded On-Policy Distillation of Diffusion Models Across Scales（2609.39692，§2.2，图 4；§3.1 表）：三种已有配方都出现纹理损坏、偏暗；学生 rollout 上的 KL 与教师轨迹、真实加噪轨迹上的 KL 趋势明显不同；基线 SD3.5-M GenEval 0.675、OCR 0.554，SD3.5-L 分别为 0.720、0.716，GenEval 专项教师 GenEval 0.949〔边界：继承自 视觉生成_细分地图_20261104 Q001；只有一组教师-学生〕
- When Policy Entropy Constraint Fails: Preserving Diversity in Flow-based RLHF via Perceptual Entropy（2605.12112，§3、§3.2，图 2）：协方差由固定噪声调度决定，策略熵保持不变；感知多样性坍缩，奖励方差逐步下降〔边界：继承自 视觉生成_细分地图_20261104 Q003；熵失效有结构原因（噪声调度固定），未必能推广到离散 token〕
- The Mirage of Optimizing Training Policies: Monotonic Inference Policies as the Real Objective for LLM Reinforcement Learning（arXiv:2606.29526，摘要）：指出现有离策略校正只保证训练端策略改进，提出以推理端策略单调改进为目标（MIPI）〔边界：继承自 LLM热门方向_刷新_20261101 N-Q002；摘要级〕
- Why On-Policy Distillation Sometimes Fails: Vanishing Learning Signals（arXiv:2610.11247，§4.3 表）：自 RL 教师损失降幅均值 96.2%，更大教师 25.1%；但 4B-RL-Math 增益 +22.83 为全表最大〔边界：继承自 LLM热门方向_刷新_20261101 L-Q001；只有一张表，未系统检验损失降幅与增益的相关性〕
- Memento: Learning Context Management for Long Context Processing Agents（2611.00244，§4.2.1 SFT Initialization and RL）：SFT 初始化策略的压缩频率是未初始化策略的 4 倍以上，但 RL 开始时两者验证准确率几乎相同〔边界：继承自 Agent记忆压缩研究地图_20261104 Q001；作旁证：标量验证分区分不出后期走向〕

**已有处理。** 感知熵替代策略熵（2605.12112）；引导折叠/分支级匹配修正扩散 OPD（GFD-OPD、2607.24731）；以推理端策略为目标的 MIPI（2606.29526）

**缺口。** 每个载体各自换了一个“更对”的监测量，但还没有工作给出监测量何时失效的通用判据。候选判据（度量分布中由被训练策略生成的比例，或度量分布与部署分布的距离）没人测过，也没有检验它能否在扩散、流匹配 RL、LLM RLVR、OPD 之间统一预测“监测曲线与部署结局的秩相关下降”。

**下游切口。** 在 3 个载体上各记录一组监测量（在策略 KL/固定参照 KL、策略熵/感知多样性、训练端/推理端优势、损失降幅），逐检查点计算它们与留出部署指标的秩相关；把同一度量分别在固定参照分布和当前策略样本上计算，构造自参照程度的受控对照，检验自参照程度越高、预测力是否越低。

**查新。** 查询词：“on-policy training diagnostics misleading: KL on student rollouts vs fixed reference, policy entropy constant while diversity collapses, monitoring metric for RL post-training”。返回 2605.12112 本身、Decoupling KL and Trajectories: A Unified Perspective for SFT, DAgger, Offline RL, and OPD in LLM Distillation（2605.16826）、What pass@k Cannot Measure（NeurIPS 2026）、On-Policy or Off-Policy Learning? A Systematic Study of Distillation Dynamics（NeurIPS 2026），以及博客“The post-training instrument cluster”，均只见标题。从标题看，2605.16826 统一的是 KL 方向与轨迹来源而不是监测量可信度，可能部分重叠；未见跨扩散与 LLM 的监测量失效判据研究（标题级，未读摘要）。

**风险。** “自参照程度”可能难以落成单一标量；各载体的失效机制不同（扩散中熵不变源于噪声调度固定，是结构性的），统一判据可能只能解释一部分案例。

**为何值得做。** 训练监测量决定早停、调参和是否放弃一次运行。如果能事先判断哪类监测量在什么设置下不可信，就能少做昂贵的部署评测。

### Q013 少数 token／动作主导更新能否提前预警崩溃

**问题。** 多种 RL 训练都出现“前期正常、后期崩溃或振荡”：agent RL 中 rollout 有限时，罕见但走运的动作拿到过大优势；RLVR 中极少数 token 的训推概率差接近 1 就能引起崩溃；异步 agent RL 中宽松掩码阈值前期快、后期更易崩溃；独立策略的多智能体 RL 出现后期准确率断崖。更新量在少数 token/动作上的集中度（例如前 x% 样本占梯度范数的份额），能否跨这些载体在崩溃前预测崩溃，并指明该用哪类稳定化手段？

**证据。**

- When Denser Credit Is Not Enough: Evidence-Calibrated Policy Optimization for Long-Horizon LLM Agent Training（2606.05885，§4；§5.1）：rollout 有限时，罕见但走运的动作获得过大优势（发散锚点偏差），后期振荡〔边界：继承自 LLM热门方向_刷新_20261101 A-Q002；未给出集中度的量化〕
- Diagnosing Training Inference Mismatch in LLM Reinforcement Learning（arXiv:2605.14220，§2（表 1、图 1））：逐 token 对数概率差 |δ| 的均值很小，但个别 token 的 |δ| 接近 1.0；作者报告小的 token 级数值差异可独立引起训练崩溃〔边界：继承自 LLM热门方向_刷新_20261101 N-Q002〕
- Missing Old Logits in Asynchronous Agentic RL: Semantic Mismatch and Repair Methods for Off-Policy Correction（2605.12070，§4.1；§6.4）：宽松阈值前期快，但后期更易崩溃；掩码与 PPO 裁剪通过最终活跃 token 集合耦合〔边界：继承自 LLM热门方向_刷新_20261101 A-Q006〕
- Diagnosing and Mitigating Thinking Collapse in On-Policy Self-Distillation（arXiv:2607.10805，§3.1–3.2、图1、§7.3）：AIME25：T/T 认知词密度 10.3→7.9，准确率 38.1%→33.9%；NT/T 42.2%；初始化时 9,807 次分歧中 66.29% 位于高熵区；AD-OPSD 优势在 AIME24 上 +7.5（512）→+1.3（2048）〔边界：继承自 LLM热门方向_刷新_20261101 L-Q001；集中的是分歧位置而不是梯度份额，需要换算〕
- When Does Multi-Agent RL Improve LLM Workflows? Workflow, Scale, and Policy-Sharing Tradeoffs（2605.24202，§3；§4 表）：相对单智能体 RL 的残差从 −10.3（4B 数学 Voting 共享）到 +10.1（1.7B 数学 Eval-Opt 独立）〔边界：继承自 LLM热门方向_刷新_20261101 A-Q007；后期断崖只出现在原卡的问题描述里，这条观察本身只给出残差范围，不提供集中度证据，是本卡最弱的一条〕

**已有处理。** 低计数收缩与方差门控（2606.05885）；高熵区掩码 AD-OPSD（2607.10805）；精确获取 old logits 或近似校正（2605.12070）；MIPI 目标（2606.29526）；单一 RLVR 载体上的极端 token 重加权（只见检索标题：Taming Extreme Tokens 2605.11538；Do Not Let Low-Probability Tokens Over-Dominate 2505.12929）

**缺口。** 每个载体都有自己的稳定化手段，但还没有工作把“少数 token/动作主导更新”当作共同量跨载体测量，也没有检验它是否在崩溃前若干步就上升、上升速度能否预测崩溃时间。各种手段（裁剪、收缩、掩码、精确 logit）分别压低的是哪一种集中来源，也没有对齐。

**下游切口。** 在三个设置中逐步记录前 1%/5% token 占梯度范数和优势绝对值的份额：RLVR（人为注入训推精度差）、异步 agent RL（扫掩码阈值）、少 rollout 的 agent GRPO（扫组大小）。计算这些份额对后续 N 步内崩溃（奖励骤降或熵骤变）的提前预测 AUC，再比较各稳定化手段压低的是哪一项份额。

**查新。** 查询词：“few extreme tokens dominate policy gradient update predicts late training collapse LLM RL GRPO advantage outliers unified analysis”。返回 Taming Extreme Tokens: Covariance-Aware GRPO with Gaussian-Kernel Advantage Reweighting（2605.11538）、What are Key Factors for Updates in RL for LLM Reasoning?（2606.22570）、Do Not Let Low-Probability Tokens Over-Dominate in RL for LLMs（2505.12929）等，只见标题。从标题看，这些工作在单一 RLVR 载体上处理极端 token，可能已覆盖“现象 + 单载体修复”；所以本卡收缩到它们未覆盖的部分：一个跨训推不一致、异步离策略、稀疏 rollout 的 agent RL 和在策略蒸馏的统一早期预警量（标题级，未读摘要）。

**风险。** 单载体文献已经不少，统一量可能被看作工程诊断；崩溃的定义因载体而异，提前预测 AUC 可能对阈值敏感；多智能体那条证据较弱。

**为何值得做。** 如果一个记录成本很低的集中度量能提前若干步预警崩溃、并指明该用哪类稳定化手段，就能直接省下大规模 RL 运行的回滚成本。

### Q014 信用定位的超额收益：定位器准确率 × 组内对比数

**问题。** 精细信用定位（关键轮次、关键去噪步、压缩后溯源）相对等量的均匀或随机信用，优势常常很小甚至没有：多轮 agent 中均匀稠密胜过二值，进展定向与随机打乱同样有害；随机信用与评审定位在 ALFWorld/WebShop/SearchQA 上只差 0.7–5.5 点；扩散 RL 中并非每个去噪步都需要优化。定位方法的超额收益，能否由“定位器准确率 × 每组有效对比数（rollout 数与组内成败混合度）”跨载体预测，从而决定该先加 rollout 还是先做定位？

**证据。**

- Coverage, Not Targeting: A Structural Regime in Multi-Turn Agent Credit Assignment（2609.02417，§Environment；§Arms；§Uniform dense beats binary）：均匀稠密比二值在可评分断言支持度上高 0.079（4/5 种子，Wilcoxon p=0.003，95 个任务-种子对，CI [+0.009,+0.149]），官方成功率高 5.2 个百分点；二值奖励在 4/5 种子上低于基座，均匀稠密比基座高 0.041；进展定向与随机打乱同样有害（摘要）〔边界：继承自 LLM热门方向_刷新_20261101 A-Q002〕
- Targeting Pivotal Decisions for Credit Assignment in Agentic Reinforcement Learning（2609.36178，§5.3 Table 3）：随机 vs 评审：ALFWorld 94.0 对 94.8–98.5，WebShop 42.4 对 43.5–47.9，SearchQA 42.8 对 43.5–47.0；接受率 19.5% 对 58.5–72.4%；Qwen3.5-9B 评审在 WebShop 上低于 GRPO〔边界：继承自 LLM热门方向_刷新_20261101 A-Q002；给出了定位器质量的代理量（接受率）〕

### Q019 干预副作用的"默认倾向剖面"能否跨干预类型预测

**问题。** 干预的副作用往往把模型推向它自己的默认倾向（拒答、谄媚、广泛失配），而不是推向干预内容的方向。这种现象在激活 steering、随机或良性 SAE 方向、窄任务微调（涌现失配）和优化器选择中都出现过。问题是：不施加干预时就能测得的'默认倾向剖面'（无内容方向或同范数扰动带出的行为排序），能否用同一个量跨干预类型预测副作用的方向和幅度？其中能预测的部分是多少，剩下多少只能归因于干预内容？

**证据。**

- Steering Interference Reflects the Model's Defaults, Not the Behavior Directions（2609.06951，贡献节）：无内容方向带出的行为和顺序与真实 steer 一致（秩相关 0.90），偏向拒答、谄媚和诗化，并伴随松弛；用几何量预测留出行为，秩相关最高 0.41，幅度不到 1/10；10B 以下最强〔边界：未检出白名单或 QS 署名。继承自 表示工程研究地图_20261104 Q002〕
- The Rogue Scalpel: Activation Steering Compromises LLM Safety（2509.22067，摘要）：随机方向把有害服从率从 0% 提到 2–27%；良性 SAE 特征再多 2–4 个百分点；20 个随机向量组合起来就是通用攻击〔边界：窗口外背景。继承自 表示工程研究地图_20261104 Q002〕
- Activation Steering Induces Emergent Misalignment: Steering Vector Construction and Comprehensive Evaluation（2606.08682，摘要）：由窄任务构造的 SV 可诱发跨领域失配，生成内容比微调诱发的 EM 更连贯、更可执行〔边界：仅 Tier C。继承自 表示工程研究地图_20261104 Q002〕
- Emergent Misalignment Is Not Magical（arXiv:2608.29118，§4.1–4.2 表2/3）：内容不变、只改数据格式，EM 平均下降 52.5%；消融 donor 方向后 EM 从 4.48% 升到 15.28%〔边界：只在 L32 做消融。继承自 LLM热门方向_刷新_20261101 L-Q008〕
- Evil Spectra: How Optimisers can Amplify or Suppress Emergent Misalignment（arXiv:2606.31591，§4.1、§4.5 表4）：同一数据下，Muon 失配 5.3%，Lion 37.0%；谱正则让 Adam 从 65.8 到 72.4、Lion 从 57.8 到 65.8，SGD 从 75.3 降到 71.8（变差）〔边界：未检出触发评测关键词。继承自 LLM热门方向_刷新_20261101 L-Q008〕
- Forecasting Side Effects of Activation Steering（2608.11227，摘要）：副作用普遍、有结构、不对称；幅度主要取决于目标行为，方向可从未 steer 时的表示预测〔边界：仅 Tier C，且只覆盖 steering 这一种载体。继承自 表示工程研究地图_20261104 Q002〕

**已有处理。** 移除可分离的安全退化子空间（2608.08383）；从未 steer 表示预测 steering 副作用（2608.11227，只覆盖 steering）；更换优化器或加谱正则抑制 EM（2606.31591）；改数据格式降低 EM（2608.29118）

**缺口。** steering 内部已有'默认吸引'和事前预测的工作，但没有人检验这个默认倾向剖面能否同时预测微调型 EM 的方向，以及优化器和格式造成的差异。'与内容无关的默认项'在 steering、SAE 和微调中各占多少，还没有统一估计。2609.06951 的几何预测只解释了留出行为的一小部分（秩相关 ≤0.41）。

**查新。** 查询：steering side effects norm-matched random direction default behavior attractor fine-tuning emergent misalignment unified。结果只命中 2606.08682、2509.22067 等已知 steering 侧工作，没有检出把 steering 和微调 EM、优化器选择统一到同一个'默认倾向'预测量的工作。2608.11227（已在旧地图中）在 steering 内部覆盖了事前预测，所以本卡收窄为跨干预类型的部分。

**为何值得做。** 如果用一个量就能事前给出各种干预会把模型推向哪里，部署前就能筛掉高风险的干预和配置，不必逐个做红队测试。如果预测不成立，也能说明副作用确实来自干预内容，应该在内容侧去修。

### Q020 承诺时刻能否预测额外推理是纠正、放大还是锁定

**问题。** 推理或审议过程对已有决定的作用存在两种相反的情况：它可能纠正决定，也可能放大或锁定决定。在 steering 下重新生成的 CoT 会放大被 steer 的决定，已写好的 CoT 会锁住原决定；推理减少谄媚，却会为谄媚性判断编造理由；做研发的 agent 加更多推理只会细化已选策略；搜索越过峰值后继续进行，多以更低分收尾。问题是：决定在推理中的'承诺时刻'（探针能解码最终答案的最早位置，相对推理总长度），能否跨载体预测额外推理是纠正、放大还是锁定？

- Therefore I am. I Think.（2604.01202，§3.1、§3.4、Table 1）：Qwen3-4B When2Call α=12：抑制翻转率思考 49%、不思考 18%，注入翻转率 62% vs 29%；BFCL α=12：抑制 26 vs 20，注入 53 vs 27；作者称思考模式一致地更容易被 steer，CoT 常为被翻转的决定找理由〔边界：单次运行，n=100；思考模式下被 steer 的 token 数是否更多未核实（剂量混淆）。继承自 表示工程研究地图_20261104 Q005〕
- Beyond a Single Direction: Chain-of-Thought Disrupts Simple Steering of Refusal（2605.26772，摘要）：CoT 固定时 39%，去除 CoT 70%，在 steering 下重新生成 CoT 94%；移除 steering 后仅凭重新生成的 CoT 保留 48% 效果〔边界：仅摘要。继承自 表示工程研究地图_20261104 Q005〕
- Reasoning Theater: Disentangling Model Beliefs from Chain-of-Thought（2603.05488，摘要）：简单回忆题的最终答案远早于 CoT 监控就可从激活解码；难题更接近真实推理；回溯和顿悟几乎只出现在探针显示信念大幅变化的回答中〔边界：仅摘要。继承自 表示工程研究地图_20261104 Q005〕
- Good Arguments Against the People Pleasers: How Reasoning Mitigates (Yet Masks) LLM Sycophancy（2603.16643，摘要）：推理总体上降低最终判断中的谄媚，但部分样本会用逻辑矛盾、计算错误或片面论证构造误导性解释；开源模型上的机制分析显示，谄媚倾向在推理中动态形成，不是在输入阶段就已注定〔边界：摘要级；机构未取到；与'预承诺'解释方向相反，可作为反例载体〕
- What is Missing from AI Post-Training AI: An Empirical Analysis（2608.19072，Data Construction；Evaluation Protocol；§3.1；摘要）：只有 2.1% 的相邻训练换了策略；更多推理只细化已选策略；人类审阅只改变锁定哪一个；同预算下中途一句指令比 agent 自己继续最多高 17.44 分〔边界：干预实验设置只读到摘要。继承自 LLM_RSI研究地图_20261103 Q004〕
- RSIBench-Data: Benchmarking Data-Centric Research for Recursive Self-Improvement（2607.25886，摘要）：越过最佳分后仍继续的搜索中，78.26% 以更低分收尾，其余只回到同一峰值〔边界：只读摘要。继承自 LLM_RSI研究地图_20261103 Q004〕

**已有处理。** 中途人类指令打破策略锁定（2608.19072，属外部施加）；DAPS 类别覆盖重加权（2609.00077）；oracle 门控 steering（只在已知目标子集时有效）

**缺口。** '推理放大决定'在 steering、谄媚和研究 agent 中各自被观察到，但缺少共同的测量口径。剂量（被干预的 token 数）、文本自我正反馈、预承诺程度三者没有拆开。谄媚的结果（推理中动态形成）与 Reasoning Theater 的结果（简单题早已决定）指向相反，承诺时刻是否就是区分纠正和放大的量，还没有检验。

**下游切口。** 在 2–3 个开源推理模型上，对同一批样本测探针承诺时刻 t*（归一化到推理长度），再施加三类压力：答案 steering、用户权威施压、错误中间反馈。比较三种条件下的翻转率：CoT 固定、CoT 截断后重生成、CoT 在压力下重生成，每种条件都匹配被干预的 token 数。检验 t* 是否在三类压力上一致预测'放大/锁定/纠正'。

**查新。** 查询：reasoning amplifies pre-committed decision chain-of-thought lock-in steering sycophancy agent strategy revision。命中 2603.01437、2604.01202（已知），新命中 2603.16643（推理既缓解又掩盖谄媚，摘要级），以及一篇非学术博客。没有检出把 steering 放大、谄媚和 agent 策略锁定统一到同一承诺量的工作。

**风险。** '研究策略锁定'作用在轨迹或多轮层面，单次 CoT 探针未必能迁移过去，第三类载体可能只能用代理量（策略类别熵）衡量。2604.01202 的放大效应可能完全是剂量效应，那样就没有新机制。证据中有多篇只读到摘要。

**为何值得做。** 它决定什么时候应该让模型多想：t* 早的样本，多推理只会合理化甚至放大偏差，应该干预或截断；t* 晚的样本，多推理才有用。这对监控和测试时计算分配都有直接意义。

### Q021 监督信号的召回随优化压力的衰减曲线

- Self-Authored Verification Is Unreliable in Heuristic Self-Improving Agents（2607.24300，摘要）：自评分饱和到接近 1.0，而部署分数低、在部分发现后坍缩或收益保不住；较弱 agent 在容易的自测背后破坏已有策略〔边界：白名单外背景。继承自 LLM_RSI研究地图_20261103 Q002〕
- Predicting When RL Training Breaks Chain-of-Thought（None，正文概述）：把输出奖励与 CoT 奖励的关系分为冲突、正交、对齐三类：冲突类降低可监控性，正交和对齐类基本保持；覆盖代码后门与硬币翻转状态追踪两个任务，含完整 RL 与上下文内 RL〔边界：摘要级；只覆盖 CoT 监控器这一种载体，给出的是定性分类，不是压力–召回曲线〕

**缺口。** 现有工作要么只给 CoT 监控器的定性分类，要么在单一载体上报一个点估计（规避对 7→56、选择集差距 13–20 点）。还没有人在同一协议下画出'优化压力–监督召回'曲线，也没有比较 CoT 监控器、LLM 评审和自写测试或选择集的衰减斜率是否相同。'可见度'和'轮数或候选数'的独立贡献没有被分离（2609.28614 作者自己说明未分离）。

**下游切口。** 选三种监督载体：CoT 监控器、只看代码与分数的 LLM 评审、自写单元测试，配一个带可选捷径的小型 ML 或代码任务（BAITBENCH 类）。用 2×K 设计：被优化方是否看到监督反馈 × 交互轮数或候选数 K∈{1,4,16,64}，固定一组人工标注的真值投机标签，测各载体召回随 K 的变化，拟合同一族曲线并比较斜率。

**查新。** 查询：monitor recall decays with optimization pressure rounds of feedback reward hacking CoT monitorability obfuscation stronger monitor。命中 OpenAI 2503.11926（对 CoT 施压导致混淆，窗口外）和 DeepMind 的'预测 RL 何时破坏 CoT'（定性三分类，只覆盖 CoT 监控器）。据此降级：本卡不再主张'能否预测监控退化'，改为跨载体的定量压力–召回曲线，以及可见度与轮数的分离。

**风险。** 不同载体的'压力'单位（RL 步、反馈轮、候选数）可能无法归一，曲线也许只能逐载体拟合。真值投机标签需要人工，成本高。与新地图 Q007（评判器读自述）相邻：本卡关注压力剂量，不涉及自述信道，需在写作上明确划界。

**为何值得做。** 它直接回答一个部署问题：一个监督信号在被优化多少轮、多少候选之后不再可信，需要轮换或密封。这能为 RL、自我改进循环和 agent 评测设定监督的'有效期'。

### Q022 中途选择 vs 事后重排：何时反转

**问题。** 在等计算预算下，测试时选择器（PRM 引导、模型自置信度解掩码、验证器引导 beam search）只要在生成中途剪枝或做决定，常常输给生成完再统一打分的事后重排（ORM、best-of-N）。中途选择器在第 t 步的打分与终态正确性的相关度，以及它导致的候选池多样性下降（不同答案数、Oracle@K），能否跨 AR 与离散扩散两类载体预测：在哪个预算、哪个进度点，中途选择开始输给事后重排？

**证据。**

- Why Deterministic PRM Guidance Underperforms in Discrete Diffusion Reasoning（arXiv:2609.35472，§3、§4、§5（图3））：K=8：ORM 重排 75.13% vs PRM 引导 65.18%；K=32：82.71% vs 70.02%；top-1 剪枝后不同答案数 4.31→1.75，Oracle@8 81.05%→67.30%；SMC 恢复池到 77.89%/3.95 后跨掩码 PRM 仍 65.48%，终态 PRM 75.40%；初始状态 top-1 剪枝剪掉全部正确谱系的概率 46.06%（继承自 LLM热门方向_刷新_20261101 L-Q004）〔边界：只测离散扩散数学推理；SMC 恢复多样性后跨掩码 PRM 仍落后，说明除多样性外中间态打分本身也不可靠，两个因素没有完全分开〕
- Escaping Confidence Trap: Evolutionary Decoding for Mathematical Reasoning in Diffusion LLMs（arXiv:2608.00605，§3.1、图1）：Pass@8 上限 70.0%，约 30% 题 8 次全错；一致失败轨迹含冗余填充、数字置信高、最后高置信大批量解掩码+重复（继承自 LLM热门方向_刷新_20261101 L-Q004）〔边界：没有报告置信度与终态正确性的逐步相关；只测数学〕
- More Test-Time Compute Can Hurt: Overestimation Bias in LLM Beam Search（arXiv:2603.15377，标题（检索结果，摘要级））：摘要级：标题称 LLM beam search 中加测试时计算可能有害，原因归于高估偏差〔边界：仅检索标题，没有读正文；数值、模型、机构都没有核实〕
- Scaling Flaws of Verifier-Guided Search in Mathematical Reasoning（arXiv:2502.00271，标题（检索结果，摘要级））：摘要级：标题称验证器引导搜索在数学推理上的规模化存在缺陷〔边界：仅标题级；发表时间早于近期窗口，用作背景〕

**已有处理。** 终态打分的事后重排（2609.35472）；SMC 恢复候选多样性（2609.35472）；进化式解码绕开置信陷阱（2608.00605）；检索命中但未核实：BoN 与 beam search 混合、按难度切换（2026.findings-eacl.315，标题级）；多样性剪枝的 BoN（2506.03978，标题级）

**缺口。** 现有工作各在一个载体内给出修法（SMC、进化解码、混合 BoN/beam），没有人把“中途打分与终态正确性的相关度随进度怎样变化”当作统一的预测量，并在 AR 与扩散上对齐验证；“剪掉正确谱系”（多样性损失）与“中间态打分本身有偏”（高估）两种机制各占多少也没有分开。

**下游切口。** 在同一数学集上，用同一 PRM 打分 AR 的 beam search 和离散扩散的 PRM 引导，逐进度点（10%…90%）测 PRM 分与终态正确性的 AUROC，以及剪枝前后的不同答案数和 Oracle@K；拟合“AUROC×保留多样性”与等预算下“中途选择减事后重排”差值的关系，看能否预测反转预算。小模型（≤8B）就能做。

**查新。** 已检索 1 次：命中 2603.15377、2502.00271，以及 BoN/beam 混合工作，都是 AR 单载体；没有发现跨 AR/扩散、以进度相关度作预测量的工作。已据此把卡改写为“预测量”形式，不再声称现象本身是新的

**风险。** AR 侧证据只有标题级，需要读正文确认现象确实同向；PRM 在扩散的中间掩码态上本来就分布外，跨载体比较可能被打分器质量混淆

**为何值得做。** 直接决定部署时把预算花在中途引导还是事后重排上；如果一个廉价、可提前测的相关度曲线就能预测反转点，不用逐任务做网格搜索

### Q023 长度膨胀能否无标签预测扰动后的准确率损失

**问题。** 对推理模型的多种扰动（低比特量化、在策略（自）蒸馏、RL、潜空间 steering、扩散置信解码）造成准确率下降时，常常伴随回复变长或退化重复。相对基线的“长度膨胀比”和“膨胀出现在高熵分叉位置的比例”，能否不看标签就预测这次扰动的准确率损失？膨胀是有益多想还是退化空转，靠什么区分？

**证据。**

- Quantized Reasoning Models Think They Need to Think Longer, but They Do Not（arXiv:2606.00206，§3、§4.1–4.2、§6、§7）：Qwen-1.5B MATH-500：BF16 85.6%/5.2K，AWQ3 47.0%/23.4K，GPTQ3 71.6%/6.8K；AWQ3 overthinking 错误 19→139，占 265 个错误的 52%；逐位置 KL 与熵 Spearman 0.92；惩罚使 overthinking 错误最多减 58%、准确率最多 +14.2%（继承自 LLM热门方向_刷新_20261101 L-Q010）〔边界：单一小模型族、数学；不同量化方法膨胀幅度差异大〕
- Diagnosing On-Policy Self-Distillation for Reasoning Language Models（arXiv:2609.39118，§4、§5.3）：无关解答 −0.7/−0.8（长度 +6.0%），第二组 −1.8/−3.2（+25.3%）；完整解答 +0.9/+1.0（+12.9%）；只给答案 −3.7/−4.8；退化伴随评测长度增长（继承自 LLM热门方向_刷新_20261101 L-Q001）〔边界：完整解答条件下长度 +12.9% 但准确率上升，说明单看长度不够，需要区分膨胀发生在哪里〕
- Rethinking On-Policy Self-Distillation for Thinking Models（arXiv:2607.05184，表1、表3、表4、§3.3/图1、§7）：三基准均值全部下降，Qwen3-1.7B 0.372→0.308；4k–8k 预算持平或更好，32k–38k 更差且回复更短（继承自 LLM热门方向_刷新_20261101 L-Q001）〔边界：与 2609.39118 方向相反，是本卡未解部分的核心〕
- Gains and Collapse in On-Policy Distillation:A Reinforcement Learning Perspective（arXiv:2610.03185，§3、图2、§5.2）：OPD 增益集中于小 k，1024 条后可解集未扩大；外部教师+Base 学生坍缩为过长重复；遮掉截断回复可恢复（继承自 LLM热门方向_刷新_20261101 L-Q001）〔边界：属于训练期坍缩，不是部署期扰动〕
- Mitigating Length-Scaling Tax with Online Distillation（arXiv:2609.38854，摘要）：RL 使已解决问题回复变长而准确率不增；LSD 把长度税从 19.0% 降到 −3.7%（继承自 跨地图共性缺口_20261105 Q005，摘要级）〔边界：摘要级；这里是变长但准确率不变（浪费），不是准确率下降〕
- Escaping Confidence Trap: Evolutionary Decoding for Mathematical Reasoning in Diffusion LLMs（arXiv:2608.00605，§3.1、图1）：一致失败轨迹含冗余填充、数字置信高、最后高置信大批量解掩码+重复（继承自 LLM热门方向_刷新_20261101 L-Q004）〔边界：只是定性描述，没有长度与准确率的定量关系〕
- When Steering Fails in Latent Reasoning: A Latent-to-Language ...（arXiv:2609.21662，§2–§3、图1/2）：潜空间引导不翻转立场且产生退化重复（继承自 LLM热门方向_刷新_20261101 L-Q003）〔边界：只有重复现象，没有长度计量〕

**已有处理。** 对 overthinking marker 与高 KL token 加 logit 惩罚（2606.00206）；遮掉截断回复或 SFT 预热避免长度爆炸（2610.03185）；在线蒸馏降长度税（2609.38854）

**缺口。** 各载体的修法都是事后压长度，没有共享的诊断。退化有时伴随变长、有时伴随变短（2609.39118 与 2607.05184 方向冲突）；“有益变长”（完整解答 +12.9% 长度、准确率上升）和“退化变长”还没有被一个可测量区分开。候选区分量是膨胀 token 落在高熵/高 KL 位置的比例（2606.00206 报告 KL 与熵 Spearman 0.92），但没有跨扰动检验。

**下游切口。** 取一个推理模型（如 1.5B–8B）施加 4 类扰动（AWQ/GPTQ 3–4bit、OPSD、GRPO 若干步、steering），在同一无标签题集上记录长度比、重复率、高熵位置膨胀占比，再用有标签集测准确率差；检验这些无标签量的 rank 相关和留一扰动预测误差。

**查新。** 已检索 1 次：只命中 2606.00206 本身（NeurIPS 2026 oral），没有发现跨扰动的长度诊断工作

**风险。** 长度与准确率的关系可能强烈依赖评测预算截断（与 Q005 的预算错配相邻），需要固定足够大的预算；变短型退化可能需要另一个量

**为何值得做。** 发布量化、蒸馏或 RL 检查点前，可以用无标签的廉价诊断判断是否退化以及怎么修（压长度还是不压），不必每次跑全套有标签评测

### Q024 分叉位置加权的偏差是否比平均保真度更能预测长链结局

**问题。** 对推理状态做有损近似（权重量化、KV cache 压缩或量化、隐式上下文压缩、扩散 LM 缓存加速、latent 推理多步迭代）时，常用的逐位置平均保真度（KL、重建 BLEU、几何相似、Jaccard）预测不了长链或多步任务的结局。“偏差集中在高熵分叉位置的程度”是否比平均保真度更能预测长链最终正确率？这种预测力是否随链长增长？

**证据。**

- Quantized Reasoning Models Think They Need to Think Longer, but They Do Not（arXiv:2606.00206，§3、§4.1–4.2）：逐位置 KL 与熵 Spearman 0.92；AWQ3 47.0% vs BF16 85.6%（继承自 LLM热门方向_刷新_20261101 L-Q010）〔边界：没有比较平均 KL 与高熵位 KL 对准确率的预测力〕
- Diagnosing and Mitigating Thinking Collapse in On-Policy Self-Distillation（arXiv:2607.10805，§3.1–3.2、图1）：初始化时 9,807 次分歧中 66.29% 位于高熵区；AD-OPSD 优势在 AIME24 上 +7.5（512）→+1.3（2048）（继承自 LLM热门方向_刷新_20261101 L-Q001）〔边界：这里的分歧是师生分布差，不是有损近似〕
- On Problems of Implicit Context Compression for Software Engineering Agents（2605.11051，§3 Experiments 表；§4 Discussion）：SWE-bench Verified 的 BLEU_ref 同样高于 Base，但解决数比 Base 少 12（p=0.013），比 SFT 少 79（Base 19、SFT 86）；定性看到重建时 URL、文件路径被幻觉替换（继承自 Agent记忆压缩研究地图_20261104 Q003）〔边界：agent 任务而非纯推理；错误集中在路径/URL 这类低冗余 token，属于定性观察〕
- Close Enough is Nowhere Near: Fidelity-Consumability Decoupling in KV Caches（arXiv:2610.22016，§2 The Object of Study）：几何相似度不预测可用性，失败非渐进；只从发送方一侧构造的替换方法被限制在底线附近，提高保真度无帮助（继承自 Agent记忆压缩研究地图_20261104 Q003）〔边界：讨论的是 cache 可消费性，不是推理链长度〕
- Faster but Different: Diagnosing and Controlling Content Drift in Accelerated Multimodal Diffusion Language Models（arXiv:2607.29079，§4、§5 RQ1）：加速 10–12 倍（72.9s→6.1–6.9s）；Jaccard 0.411–0.417 在阈值间平坦（Friedman p=0.85）（继承自 LLM热门方向_刷新_20261101 L-Q004）〔边界：漂移与质量下降的关系本身未解，是本卡的待检验项〕
- Port-Hamiltonian Latent Deliberation: Mitigating the Deliberation Drift Cliff in Test-Time Scaling（2609.37351，§2.2；§6.1 表（EXP-12））：Coconut：K=4 82.0%、K=16 71.4%、K=32 63.7%；RDT：91.3%→71.9%（继承自 LatentCoT_NL研究地图_20261103 Q003）〔边界：机构未核实；是步数外推漂移，不是外部有损近似〕
- KVarN: Variance-Normalized KV-Cache Quantization Mitigates Error Accumulation in Reasoning Tasks（arXiv:2606.03458，标题（检索结果，摘要级））：摘要级：标题称方差归一化的 KV cache 量化可缓解推理任务中的误差累积〔边界：仅标题级，没有读正文〕
- Does Accuracy Equal Evidence? Reasoning Faithfulness under KV Cache Compression（arXiv:2608.01631，标题（检索结果，摘要级））：摘要级：标题质疑 KV cache 压缩下“准确率是否等于证据”，即准确率与推理忠实性可能不一致〔边界：仅标题级；关注的是忠实性，不是用保真度预测结局〕

**已有处理。** 方差归一化 KV 量化缓解误差累积（2606.03458，标题级）；高 KL token logit 惩罚（2606.00206）；AD-OPSD 熵掩码（2607.10805）；Port-Hamiltonian 约束、WIDER 谱正则（2609.37351、2609.07406）

**缺口。** 各载体都有“平均保真高、长程结局差”的观察和对应修法，但没有检验“分叉位置加权的偏差”这个统一预测量是否优于平均保真度，也没有检验其预测力是否随链长或步数增长；扩散缓存漂移与质量的关系仍然未知。

**下游切口。** 在同一推理模型上施加 3 种有损近似（W3/W4 权重量化、KV 2–4bit 量化或驱逐、扩散 LM 缓存加速），对每个配置计算平均 KL 和按基线熵加权的 KL（或 top-q 高熵位置 KL），按链长分桶，比较两者对最终准确率的 rank 相关。用推理时前向即可，算力需求低。

**查新。** 已检索 1 次：命中 KVarN（2606.03458）与 2608.01631，都在 KV 单载体上，说明“误差累积”和“准确率不等于证据”已有人做。据此降级改写：不再主张“保真度与结局脱钩”是新发现，只保留“高熵加权偏差作为跨载体预测量”这一点

**风险。** 与已有卡 Q001（“cache 更忠实”对消费者价值相反）和 Q003 相邻，需要强调本卡问的是推理链的“可预测性指标”而不是消费者适配；KVarN 正文可能已报告高熵或位置相关分析，需要核实

**为何值得做。** 选量化、KV 压缩或加速方案时，常用的困惑度和平均 KL 指标可能选错；如果分叉加权偏差更准，就可以用它在部署前低成本筛掉会毁掉长链推理的方案

### Q025 零效应方差与报告增益之比能否预测结论可信

**问题。** 在生成模型评测、自改进 agent、小模型 GRPO、agent 上下文压缩重放这几类载体上，不改方法本身的随机源（训练种子、任务顺序、推理批处理或单次贪心解码、同一状态的重复重放）就足以产生和已报告增益同量级的差异，有时还会让结论反转。什么量能事先预测某个报告增益是否可信？候选量有两个：一是在冻结或未训练模型上测得的“零效应方差”与报告增益之比；二是主导方差来自哪一类随机源。在这些载体之间，主导随机源是否一致？

**证据。**

- The FID Lottery: Quantifying Hidden Randomness in Generative-Model Evaluation（2606.20536，§4.4；附录 C、D.4）：换训练种子的 FID 变动是重新采样的 3.2 倍；76 个单元的种子间变异系数为 0.74%–2.06%，中位数 1.30%，收敛后也不消失；SiT-S 有 3/10 个种子发散〔边界：只覆盖类条件 ImageNet，不是 LLM 载体，只作“训练种子主导”的类比证据〕

- Does an Agent's History Tell You When Compaction Will Hurt? A Modest, Bounded Effect on the TRACE Paired-Replay Corpus（2610.08722，§4；Table 2；Fig. 1–2；附录 F）：最佳 boosted 分类器留出 AUROC 0.66 [0.61, 0.70]；同一边界两半重放互预测 AUROC 0.69–0.72，半-半相关 0.40，符号一致 κ 0.28〔边界：单一环境与 harness；区间未做多重比较校正（作者注明）〕

**已有处理。** 2608.18066 主张多 run、打乱任务顺序评测（该文本身及检索到的 agentpatterns.ai 实践条目“Multi-Run, Shuffled-Order Evaluation”，摘要级）；2608.20290 针对自改进设置用实测零效应做审计；2606.20536 量化生成模型的 FID 种子方差

**缺口。** 现有工作各自只在一个载体内分解方差：自改进 agent 看任务顺序，生成模型看训练种子，Phantom Gains 看推理批处理。没有人在同一套 LLM 后训练和 agent 评测里同时改动训练种子、数据或任务顺序、推理批处理和解码、环境重放，比较哪一项占主导。也没有人检验“零效应方差/报告增益”这一比值能否预测已发表结论在复现时是否反号。重放标签本身的可重复性上限（κ 0.28 这一级别）怎样限制可检测的效应量，也还没有通用的估算方法。

**下游切口。** 选 2–3 个已发表的小模型后训练或 agent 增益（GRPO 网页 agent、记忆/压缩 agent、自改进 agent），各做一组因子网格：训练种子 ×3、任务顺序 ×3、推理 batch 大小/解码 ×2、重放 ×2。先在冻结基座上测零效应方差，再算方差分量和“零效应方差/报告增益”之比，与原结论的复现符号做对照。

**查新。** 做过一次检索（standard）：命中 2608.18066 本身及若干转述页，没有找到跨载体方差分解或“零效应比值预测复现”的工作；因此把问题改写为跨载体分解加预测量，不再泛泛地说“方差大”

**风险。** 有些载体的主导随机源可能本来就不同，那样只能得到一个分类表，得不到统一预测量；算力需求随因子网格成倍增长，必须限制在 ≤8B 模型和小任务子集；Phantom Gains 与 FID Lottery 只读到摘要级或类比级证据，需要回读原文确认

**为何值得做。** 回答能直接改变评测预算怎么分：把 run 花在多种子上、多顺序上，还是固定推理批处理上。也能给后训练和 agent 论文提供“报告增益至少要多大才可信”的门槛。

### Q026 基准结构性质能否预测增益在真实口径下的保持率

**问题。** 基准的结构性质会掩盖方法在真实使用中的失效。已见的结构性质有：目标固定、运行中没有用户输入、状态可从文件系统重读、只判终态通过率、搜索集可被过拟合到“不调用 LLM 的规则控制器”。上下文压缩、技能共装、安全义务、harness 演化、自演化技能这几类载体上都有这种现象：基准分好看，换成交互式、留出或过程约束口径后，失效才暴露。能否按这些结构性质给基准打分，并用这个分数预测方法的基准增益在交互、留出或过程口径下还能保留多少？

**证据。**

- Benchmarks Are Surprisingly Compaction-Friendly（2610.31778，This paper；§3.3）：作者论证 benchmark 有固定目标、运行时无用户输入、提供持久文件系统，被丢内容可通过重读自身产物恢复；真实交互会话中大量上下文是只存在于对话中的用户指令〔边界：白名单外〕
- Benchmarks Are Surprisingly Compaction-Friendly（2610.31778，Q3: Does compaction erode task constraints?）：每次压缩丢弃的约束类别（共 3 类）：GPT-5.3-Codex 2.73（80% 压缩丢光全部 3 类）、GPT-5.4 1.76、Claude Opus 4.6 0.51；第 1 次约丢 0.92 类，第 10 次累计 1.93 类〔边界：白名单外〕
- One Skill Too Many: How Co-Installed Skills Conflict in Coding Agents（arXiv:2610.11647，摘要）：冲突时已装技能的核心功能（如禁止动 git）失效，但任务仍计为完成，只看通过率的基准测不出〔边界：只到摘要层〕
- Safe Actions Alone Do Not Ensure Safe Agents: Identifying Unfulfilled Obligations with Guard Models（arXiv:2610.11773，摘要）：56.92% 的轨迹含未履行的安全义务，含禁止动作的只有 30.00%〔边界：只到摘要层〕
- Harness-Delta Attribution: Dissecting Gains From Harness Evolution（2610.22466，§4 Most gains come from overfitting or test-time scaling；Table 1）：ALFWorld 上 Meta-Harness 的 5 个执行模型都达到 100% 搜索集成功率，98% 的收益归为过拟合，0.8B/2B 的 harness 变成不调用 LLM 的规则控制器；SWE-bench 的剩余泛化部分较清楚〔边界：G 只是上界；O/T 的估计方法细节本轮未读；百分比被截断到 [0,100]〕
- Do Self-Evolving Skills Generalize to Held-Out Tasks?（2609.39148，摘要）：21 个训练集上有提升的技能中，5 个在测试集保留全部提升、13 个保留部分、3 个完全丢失；迁移差的技能写死列名、输出文件等任务相关细节〔边界：白名单外背景；只读摘要〕

**已有处理。** 检索命中通用基准效度审计：2607.02577《Benchmarking the Benchmarks: A Validity Audit of Tool-Calling Evaluation》、2605.10448《Can Agent Benchmarks Support Their Scores?》（摘要级，只看到标题，未读内容）；2610.22466 把 harness 增益拆成过拟合、测试时计算和泛化三部分；2610.11773 用 guard 模型补测未履行义务

**缺口。** 现有审计多是逐条检查基准“是否有效”，或只在单一方法族（harness、压缩）里拆增益。还没有把“可重读、无用户输入、只判终态、搜索集可穷举”这几类结构性质量化成基准属性，再在多种方法族上检验它们能否预测增益的保持率（交互式、留出、过程约束口径相对原口径）。另外，已有审计是否已经包含此类结构维度，需要读 2607.02577 和 2605.10448 才能确认。

**下游切口。** 取 3–4 个常用 agent 基准，按 4 项结构性质打分。每个基准构造“去掉该性质”的变体：中途插入用户约束、把关键信息只放在对话里、加过程约束判定、换成留出任务族。在压缩、技能库、harness 演化三类方法上，测原口径增益与变体口径增益之比，回归到结构分数上。

**查新。** 做过一次检索（standard）：命中 2607.02577 和 2605.10448 两篇基准效度审计，构成部分覆盖风险，因此把本卡收窄到“结构性质→跨方法族增益保持率”的预测关系；两篇的覆盖范围待读原文核实

**风险。** 如果 2607.02577 或 2605.10448 已经给出结构维度和保持率分析，本卡要降级；构造“去性质”变体工作量大，还可能改变任务难度，与结构性质混在一起；本卡多条证据只到摘要层

**为何值得做。** 能直接指导选哪个基准、给新基准加什么约束，也能判断压缩、技能、harness 类方法的已报告增益在产品交互场景下大约还剩多少。

### Q027 合成训练环境的什么量预测迁移：保真度、多样性还是坍缩速度

**问题。** 用合成训练环境做训练时，策略会吸收环境特有的可利用结构，迁移到留出环境就失败。已见的合成环境有：冻结的单一用户模拟器、语言世界模型、合成扰动增广数据、在训练任务上自演化出的技能。训练环境的什么量能预测用它训练出的策略在留出环境上的迁移：是对真实环境的保真度，还是环境种群的多样性，或者“策略熵/行为多样性在训练中坍缩的速度”？

**证据。**

- One Frozen Simulator Is Not Enough: Simulator Collapse in Multi-Agent RL（2608.12253，§Hypothesis；§Single-simulator RL exhibits simulator collapse in practice）：单模拟器 RL 的策略熵趋近于零，迁移到未见模拟器失败；种群协同训练使留出成功率最多 +14%，口语化采样 +9%（摘要）〔边界：数值为摘要级〕
- MIMESIS: Learning User Simulators as Training Environments for Interactive Agents（2610.09484，§6 Conclusion）：作者主张模拟器应按'保真度'和'用其训练的策略的迁移'两轴评估；报告跨留出模拟器模型的迁移改善〔边界：未与模拟器种群对照（关键词级）〕
- Qwen-AgentWorld: Language World Models for General Agents（2606.24597，§6.1；§Reward Collapse；§Reward Hacking Through Self-Praise）：Claw-Eval +4.3、QwenClawBench +7.1；可控模拟 RL 50.3% 对真实搜索 RL 45.6%；初始状态不详细时保真度下降；训练世界模型时出现 Echo Trap 塌缩与'自夸'式投机评审〔边界：策略是否钻世界模型的空子，因预算未检出〕
- GUI-Perturbed: Domain Randomization Reveals Systematic Brittleness in GUI Grounding Models（2604.14262，摘要）：关系型指令使准确率降 27–56 pp；rank-8 LoRA 加增广数据反而退化〔边界：窗口外（2026-04）；仅摘要〕
- Do Self-Evolving Skills Generalize to Held-Out Tasks?（2609.39148，摘要）：21 个训练集上有提升的技能中，5 个在测试集保留全部提升、13 个保留部分、3 个完全丢失；迁移差的技能写死列名、输出文件等任务相关细节〔边界：白名单外背景；只读摘要〕

**已有处理。** 2608.12253：模拟器种群协同训练、口语化采样；2610.09484：学习型用户模拟器，并提出“保真度+迁移”两轴评估；2606.24597：用可控模拟环境替代真实搜索环境做 RL

**缺口。** 保真度与多样性哪个更能预测迁移，各篇各执一端：MIMESIS 强调保真度和迁移两轴，2608.12253 强调种群多样性，两者没有在同一设置下做过对照。另外，“训练中策略熵或行为多样性的坍缩速度”能否作为不需要留出环境的早期迁移预警，在用户模拟器、世界模型、增广数据三类载体上都没有检验。合成增广为什么反而退化（GUI-Perturbed），也没有与模拟器坍缩放进同一框架解释。

**下游切口。** 在一个可控的工具或客服类任务上，用 2×2 设计分别改变保真度（强、弱模拟器模型）和多样性（单一模拟器、模拟器种群），训练小模型策略。在训练过程中记录策略熵和动作分布多样性，在留出模拟器和真人或强模型代理上测迁移，检验早期坍缩速度对最终迁移的预测力；再在合成增广 SFT 上复用同一指标。

**查新。** 做过一次检索（standard）：只命中 2608.12253 本身及其转述页和 LOGIGEN（可验证任务生成，2603.00540，只看到标题），没有找到保真度与多样性的同设置对照或跨载体的早期预警指标；保留

**风险。** 策略熵可能只在 RL 设置下有意义，SFT 增广载体上需要另找多样性度量；真人迁移评测成本高，可能只能用强模型代理，代理本身也是模拟器；GUI-Perturbed 与 2609.39148 只到摘要层

**为何值得做。** 决定合成环境的预算该花在提高单个模拟器保真度上，还是扩大模拟器种群上；如果坍缩速度能做早期预警，可以省掉大量留出评测。

### Q028 干预压低接受率：提高了判别力，还是只移动了阈值

**问题。** agent 面对外部断言或压力时（系统权限请求、页面推荐或滴漏定价、用户的错误指责、DOM/a11y 结构声明），干预后接受率会下降。这种下降是区分该接受与该拒绝的判别力（d′ 或 AUROC）提高了，还是只是接受阈值整体移动了？在配对的“应接受/应拒绝”探针上，干预前后的 d′ 变化能否跨载体预测一个后果：干预是同时压低有害接受和必要接受（过度拒绝），还是只压低有害接受？

**证据。**

- "Allow" to Achieve, Over-Privileged Inadvertently: The Unintended Cost of Task-Completion-Driven Pop-up Decisions in Mobile GUI Agents（2608.04755，§1.1–1.2、Appendix E Table 13 及注）：原始设置下 Gemini 在 Calendar 上 L1–L4 授予率均为 100%；Doubao 在 Contacts 上 L2/L3 为 86.7%/93.3%；功能链感知提示使 GPT 的 L2–L4 授予降到 0.5%、Gemini 3.5%，但 GPT 的 L1 授予在 Calendar 降到 7.1%、Contacts 6.7%〔边界：4 个闭源模型；单次弹窗注入；开源 GUI 模型未测；原文未用 d′ 口径〕
- CAVEAT: Towards Robust Computer-Use Agents in Incentive-Misaligned Environments（2609.27273，摘要、§4.2、§5.3、§6.1 / Figure 4–5）：匹配对照 78.6% 买到用户最优商品，开启引导后 17.3%；GPT-5.6-Sol 低推理 51.7% → 高推理 90.0%；GPT-4o、GPT-4.1、GPT-5 在低推理下停在地板；只开滴漏定价时 GPT-5.6-Terra 低推理 60 次中 35 次次优购买、全部选中滴漏定价的推荐商品；CAVEAT-Harness 的改善部分来自诱导更多搜索与验证（更多工具调用）〔边界：只测前沿闭源模型；没有“推荐恰好是最优”的对照组，无法区分判别与阈值〕
- "You're Right, Let Me Fix It": How LLM Agents Damage Correct Work When Falsely Accused（arXiv:2609.32616，摘要、§3.1）：定义'接受错误指责'与'破坏性过度修正'两种失败，并按轨迹打分〔边界：接受率等关键数值未取到；是否含“指责为真”的配对条件未核实〕
- Reset Is Not Recovery: Evaluating Recoverability from False Conversational Context via Sycophancy Hysteresis（arXiv:2609.33672，摘要）：保留历史的修复只在 2–3/14 个模型—数据集组合上恢复到干净行为；移除含压力历史的操作明显更可靠〔边界：只到摘要层；是对话问答而非 agent〕
- Do GUI Agents Believe Their Eyes? Diagnosing State-Belief Reliance on Pixels versus Structure（2607.04334，§Findings、§Specialized GUI agents、§A within-model control、Table 3）：结构跟随率：坐标 0.11、element id 0.64、index 0.90、文本标签 0.98；坐标格式无冲突错误 0.43 最高；UGround/Aguvis（坐标）结构跟随 0.02–0.07，OS-Atlas（索引格式）0.96–0.97〔边界：单篇；动作格式改变的是对哪个通道的“默认信任”，是否同时改变判别力未测〕

**已有处理。** 功能链感知提示（2608.04755）：越权授予几乎消失，但必需权限授予也大幅下降；提高推理强度、CAVEAT-Harness 结构化搜索与验证（2609.27273），收益与额外工具调用未分离；移除含压力历史（2609.33672）；冲突检测后重新 grounding 的一致性门控（2607.04334，启发式）

**缺口。** 现有工作都只报告单侧接受率：要么只看有害接受，要么只看必要授予。没有工作在同一模型上用配对的应接受/应拒绝探针，把干预效应分解成判别力和阈值两部分。因此无法回答：提示、推理强度、harness、动作格式这些干预，哪个真正提高了区分能力，哪个只是把模型从“全信”推到“全不信”。也不知道阈值移动是否有跨载体共享的成分，例如同一模型在权限、指责、引导、结构声明上的阈值是否相关。

**下游切口。** 选 2–3 个开源 7–8B 模型（如 Qwen2.5-VL-7B），在四类载体上各构造配对探针：权限分 L1 与 L2–L4；页面推荐分“恰为最优”与“次优”；指责分“为真”与“为假”；结构声明分“与像素一致”与“与像素冲突”。对每种干预（无、功能链/核实提示、高推理、换动作格式）计算 d′ 和判别阈值 c。检验两件事：(1) 干预的 Δd′ 是否普遍约等于 0、Δc 很大；(2) 同一模型的 c 是否跨载体相关。如果是，下一步用以 d′ 为目标的 DPO（成对惩罚两类错误）对比只压低接受率的训练。

**查新。** 做过一次标准检索（关键词：over-compliance / over-refusal tradeoff、sycophancy、permission、calibrated）。命中《The Refusal–Compliance Tradeoff: A Large-Scale Safety Behavior Audit of Large Language Models》（arXiv 2605.05427）和《Beyond Sycophancy: Structured Resistance and Compliance in LLM Moral Reasoning》（arXiv 2607.21558），两篇都只到标题级，内容未读。从标题看，前者针对单轮安全拒答，后者针对道德推理，均不在 agent 的权限、指责、感知通道载体上。暂判为未被覆盖，但需要读 2605.05427 确认它是否已用判别/阈值口径。

**风险。** “应接受/应拒绝”的金标在权限 L2–L3 这类灰区有主观性，会污染 d′。指责类配对需要“指责为真”的可构造任务，成本较高。闭源模型的结果难复现，宜以开源模型为主。

**为何值得做。** 这张卡直接决定部署选择。如果主流干预只移动阈值，那么现在报告“有害接受率下降”的论文都在用过度拒绝换安全，单侧指标会误导选型。如果存在跨载体共享的阈值，一个校准旋钮就能同时治理权限、谄媚、引导和通道信任。这四个问题目前分属四个社区，各自单独处理。

### Q029 用户来源信息是否因不可再观测而更易丢失

**问题。** agent 在执行中保持信息的能力是否按来源不对称：由用户提供、环境中无处可重读的信息（澄清回答、偏好、中途追加的请求或约束），比来自环境、可再观测的信息（文件、页面、精确标识符）更容易在后续步骤或压缩中丢失、改写或误绑定？对一条信息，能否用“环境可再观测性”（是否存在可重读的外部副本）预测它在 compaction、澄清后执行、偏好应用三类载体上的丢失率？

**证据。**

- Prune the Summary, Not the History: Source-Judged Compaction for Long-Horizon Agents（2610.20927，§3、§3.1、Table 2）：667 个 summary 的 26,881 条中 17.9% 无来源；精确标识符 3.4%、约束/规则 11.1%、决策 21.0%、开放待办 67.7%、待处理用户请求 86.1% 无来源；推理类条目首个边界 54.9% 无来源，且每个 summary 都重新写入约 4 条；摘要称 83% 失败运行可追溯到执行某条 summary 条目的动作〔边界：judge 阈值偏保守，比例为上界（作者注明）；单 harness；“无来源”不等于“丢失”〕
- AppWorld-UL: Benchmarking Diverse Agent-User Interactions for Tool-Use（2607.20536，§5、§6.2–6.7、表2–3）：最佳Code Agent的整体I-TGC为48.6%；组合子集为35.7%。§6.7明确报告回答后遗忘旧约束及多问题回答绑定错误，但未给这两类的独立发生比例。〔边界：错误分析为描述性；不能把组合子集与整体差异视为单因素因果效果〕
- Diagnosing Personalization Failures in Mobile GUI Agents（2610.30573，摘要、§3.1、§4.5）：作者把 P2 证据选择作为待检验的可操作瓶颈并做受控干预；本轮未取到各条件的数值〔边界：数值未读到；只读到设计。作者指出正确检索到用户信息不等于能正确应用偏好〕
- Same Context, Different Agents: A Behavioral Study of Semantic Layers, Multi-Agent Orchestration and Memory Compaction in Data Agents（2610.20959，§4.2）：compaction 保持 prompt 小、在最长任务上有收益，但按任务平均对准确率影响至多 2 分，且在所有 agent 组都增加重复动作；最强模型组上所有技术都降低或不改变准确率且成本更高〔边界：数据 agent 场景，信息大多可从环境重读，正好是“高可再观测性”一端〕

**已有处理。** Source-judged compaction：按来源裁剪 summary 而非历史（2610.20927）；AppWorld-UL 的知识边界用户模拟与交互示范 baseline（2607.20536）；记忆系统 MemoryBank、Mem0、MemGUI-Bench，以及证据标注、删除噪声日志等受控干预（见 2610.30573 相关工作）

**缺口。** 三类载体各自报告了用户来源信息出问题：compaction 中待处理用户请求最常无来源，澄清后遗忘旧约束，偏好检索到了却用不上。但没有工作把“是否可从环境再观测”当作自变量控制，同时又保持信息内容、位置和步距不变。因此不知道用户来源信息的高丢失率，是来源本身造成的（模型更信环境、更轻视对话），还是只因为它无处可补偿地重读。现有 benchmark 多为可回读环境，系统性低估了这类代价。

**下游切口。** 在 AppWorld-UL 或一个 τ-bench 类任务上，把同一条约束做三种注入：(a) 仅由用户在对话中说出；(b) 同时写入环境中可读的文件或备忘；(c) 仅存在环境文件中。保持注入步与使用步之间的距离相同，分别测有无 compaction 时的约束违反率和误绑定率。预测是 (a) 的违反率远高于 (b)，且差值随 compaction 次数扩大。对照干预是把用户来源条目在压缩时标为“不可改写原文”，看能否消除这一差距。

**查新。** 做过一次标准检索（关键词：澄清后遗忘约束、偏好绑定、benchmark 2026）。命中《Ask Early, Ask Late, Ask Right: When Does Clarification Timing Matter for Long-Horizon Agents?》（newx.sg 页面，arXiv ID 未核实）和《One More Turn, Less Regret: A Regret-Based Multi-Turn Benchmark for LLMs' Clarification Policies》（arXiv 2607.21143），均为标题级。它们覆盖澄清的时机与策略，即“何时问”，所以本卡已改写：不再讨论澄清时机，改为“来源与可再观测性”这一自变量。注意与已有卡的区分：与 T-B2（需求时距预测选择器）、Q006（改写输给只追加）、Q008（禁止类 vs 必需类约束）相邻但自变量不同，需在后续合并评审时确认不重叠。

**风险。** 与 T-B2、Q006 的边界可能被认为过近。“可再观测性”在真实任务中难以与内容重要性完全解耦。2610.20927 的比例是上界，2610.30573 无数值，现有证据强度中等偏弱。

**为何值得做。** 答案直接决定工程选择：是否要在 harness 里把用户话语单独存成不可压缩的“用户账本”，是否要在 benchmark 中加入不可回读条件。如果成立，现有在可回读环境中得出“compaction 几乎无损”的结论就不能外推到真实人机交互场景。

### Q030 GUI 三类空间失败是否共享坐标熵信号（未达 C1）

**问题。** GUI grounding 有三种看似不同的空间失败：关系型指令崩溃、位置盲区、坐标格式自身的定位错误。它们是否共享一个可在推理时测到的信号，即坐标输出高位数字的不确定性（place-aware 坐标熵）？这个信号能否跨失败类型和模型族预测错误，从而用统一的“熵门控 → zoom 或重 grounding”替代逐类专门修复？

**证据。**

- How Many Pixels Is a Digit Worth? Place-Aware Coordinate Entropy for GUI Agent Confidence Estimation（2609.24277，§5.1、§5.2）：单数位熵 AUROC：个位 0.65、十位 0.77、百位 0.82〔边界：置信度估计，不直接解释关系崩溃；是否在关系、盲区子集上测过未知〕
- GUI-Primitives: Diagnosing Spatial Reasoning Failures in Vision-Language GUI Grounding（2608.21832，§5.1、§5.2 Table 2）：最强 Claude Opus 4.7 清洗核心集 32.4%，人类 96.9%；Qwen2.5-VL-7B 24.9%；OS-Atlas-Base-7B 10.8% 高于同底座 Qwen2-VL-7B 4.9%；空白画布使 Qwen2.5-VL-7B 22.0%→6.5%〔边界：未覆盖 UI-TARS-1.5、GUI-Owl、GTA1 等新 GUI 专训模型〕
- GUI-Perturbed: Domain Randomization Reveals Systematic Brittleness in GUI Grounding Models（2604.14262，摘要）：关系型指令使准确率降 27–56 pp；rank-8 LoRA 加增广数据反而退化〔边界：窗口外（2026-04）；仅摘要〕
- ScreenHaystack: Finding Blind Zones in GUI Grounding（2609.32036，摘要、§3、§4.1、§4.3）：领先模型都有盲区；Qwen3-VL-8B 在盲区内的 ScreenSpot-Pro 样例上掉 16.1 个百分点；UI-Venus-Ground-7B 的错误最集中（G_e=0.759），盲区准确率相对整体下降 68.27%；作者检验训练空间覆盖不均这一候选原因，并在 Qwen3-VL 上检验视觉 token 边界等架构假设〔边界：原因部分检验；修法本轮未读〕
- Do GUI Agents Believe Their Eyes? Diagnosing State-Belief Reliance on Pixels versus Structure（2607.04334，§Findings、Table 3）：结构跟随率：坐标 0.11、element id 0.64、index 0.90、文本标签 0.98；坐标格式无冲突错误 0.43 最高〔边界：单篇；无冲突错误的来源（关系、位置还是解码）未分解〕

**已有处理。** 不确定性驱动 zoom（AutoFocus 等）、交互式光标搜索 GUI-Cursor（arXiv:2509.21552，窗口外）；小目标 token 预算分析（arXiv:2610.09313）；InnerZoom（arXiv 2606.30084，检索命中，标题级）；针对位置编码失效的坐标预测偏置缓解（arXiv 2510.22102，检索命中，标题级）

**缺口。** 坐标熵只在标准 grounding 集上验证过。关系型、盲区、冲突格式三类失败分别有诊断基准，但没有工作检验：同一个推理时信号在三类失败上的 AUROC 是否同样高，以及按信号门控的 zoom 或重 grounding 在三类上是否都有效。如果某类失败是“自信地错”（熵低、答错），例如关系绑定错到错误锚点、盲区系统性偏移，门控就会漏掉它，需要不同的修法。

**下游切口。** 选 Qwen2.5-VL-7B、OS-Atlas-Base-7B、UI-Venus-Ground-7B 三个开源模型，分别在 GUI-Primitives 核心集、ScreenHaystack 盲区样例、2607.04334 的无冲突探针上计算百位/十位数字熵对错误的 AUROC，并统计“低熵错误”的占比。再在固定额外推理预算下，比较熵门控 zoom 与随机门控、全量 zoom 的准确率增益。预测：盲区与关系崩溃中低熵错误比例高，熵门控在这两类上收益明显低于标准集。

**查新。** 做过一次标准检索（关键词：grounding、坐标 token 解码、空间盲区、关系型指令、统一成因）。命中 InnerZoom（2606.30084）、GUI-Primitives（2608.21832）、GUI-Perturbed（2604.14262）、NeurIPS 2026《Controlled Perturbation Reveals Grounding and Faithfulness Failures in Computer-Use Agents》，以及《Mitigating Coordinate Prediction Bias from Positional Encoding Failures》（2510.22102），均为标题级。2510.22102 涉及坐标偏置与位置编码，与盲区成因部分相邻，因此本卡已从“成因”改写为“共享推理时信号能否统一门控”，并降级为中等新颖度。需读 2510.22102 和 NeurIPS 那篇，确认它们是否已做跨失败类型的置信度检验。

**风险。** 【未满足准则 C1：只在 GUI grounding 一个领域内跨失败类型与模型族】三类失败的载体仍都在 GUI grounding 之内，跨载体的宽度弱于 T-F1/T-F2，主要靠不同失败类型和模型族支撑。若结果是“低熵错误占主导”，结论是负面的（门控无效），需要准备第二步修法。闭源模型拿不到 logits，只能做开源模型。

**为何值得做。** 答案直接决定部署时的推理预算分配：是对所有点击统一做熵门控的二次 grounding，还是要为关系指令和盲区分别加专门的数据或架构修复。两种选择的成本差一个数量级。实验只需开源 7–8B 模型推理与现成基准，算力门槛低。

## 六、推荐顺序（按问题分量）

1. **Q001 产物价值随消费者翻转** —— 影响本项目几乎所有设置都会做的选择（拿哪个教师、哪个评估器、哪套 harness/摘要器给小模型），并出现"更强生产者反而更差"；各载体只有局部解释；已有修法（自 rollout）只治症状且贵。最贴合 ≤8B 消费者 + API 生产者的资源形态。
2. **Q007 自述信道在优化下被利用** —— 读自述的评判器正被当作 RL 奖励广泛使用，失败直接影响训练出来的策略是否"会说不会做"；静态泄漏已有受控证据，训练动态是明确的未测部分；本项目监控类卡历史上重要性能到 8。
3. **Q002 知行断点定位分歧** —— 拥挤但有明确的跨论文分歧，分歧直接决定该在哪一步干预；旧卡 N-Q003/GUI Q002 的失败说明只能做对齐，不能再做单领域测量。
4. **Q005 训练预算外反号** —— "评测给更多资源反而更差"在四类方法上出现（skill 要求优先标记），各自只有局部解释，没有跨方法的反号点规律。
5. **Q006 改写式状态输给追加式** —— 证据跨记忆、compaction、KV、对话修复四个载体，简单基线反复胜出说明现有改写方案没触及共同原因；但记忆方向拥挤。
6. **Q010 干预的上下文条件化** —— 影响安全评测的可信度；EM 上已有表示距离线索，跨干预类型未测。**与用户进行中的 `em_conditional_mitigation` 相邻。**
7. **Q009 覆盖坍缩的集体效应** —— 有一个可迁移的机制假说（[41]），但只在无标签 RLVR 上有理论与模拟。**与用户已通过的 `rl_boundary_aq001` 相邻。**
8. **Q008 禁止类 vs 必需类约束** —— 存在方向相反的证据，但现象本身已被直接研究，剩余空间是分歧的对齐。
9. **Q003 内容何时被用** —— 跨载体现象多，但 OPSD 上已有理论（PAST），单载体评测协议已有 [13]。
10. **Q004 净增益中的破坏** —— 有直接负证据 [19]，属评测审计类，历史上重要性难过 6.5。

算力过滤：十张卡的最小检验都可在 ≤8B 消费者与 API 生产者上完成。Q005 中循环 LM 与 latent CoT 两个载体需要重训架构，列为可选，最小检验用 OPSD 与 compaction RL；Q010 需要对 ≤8B 模型做小规模微调，用户在 EM 项目上已做过同量级实验。

## 八、术语表

| 术语 | 含义与易混点 |
| --- | --- |
| 生产方／消费方（producer／consumer） | 本地图用语：产出修复、教师分布、harness、摘要、KV 的模型为生产方；使用它的模型为消费方。二者可以是同一模型的不同实例 |
| 部署价值（deployment value） | [1] 中用部署体自己的独立 rollout 测得的、某修复带来的净成功提升 |
| tolerable set | [2] 定义：冻结读者能有效读取的 cache 区域，近似"接近自己会写出的 cache" |
| CET（context-engineering technique） | [3] 中的语义层、编排、压缩三种上下文工程技术 |
| harness activation／adherence | [4] 中弱模型受益少的两种机制：没把产物载入上下文；载入后不照做 |
| 知行差距（knowing–doing gap） | 有证据显示模型"知道"正确判断但动作不跟；"知道"的测法（探针、报告、显式结论）不同，测出的断点不同 |
| 显式结论标签（explicit decision tag） | [8] 让模型在动作前输出机器可读的 DECISION 行，以避免自由文本抽取的噪声 |
| 内容收益（content benefit） | 需要"本实例内容"才有的那部分增益，区别于任何内容或常量输入也能带来的增益 [13] |
| 特权变化（privileged variation） | [16] 中教师–学生分歧里只看前缀的学生学不到的部分，形式上是条件互信息 I(A;U\|H) |
| imitation gap | 部分可观测下模仿看得更多的专家所产生的不可弥合差距（经典 RL 概念，本轮未读原文） |
| 翻转矩阵（flip matrix） | 把干预前后每个实例的对错变化分成"错→对、对→错、不变"，净分只是前两者之差 |
| 训练预算／评测预算（B_train／B_eval） | 本地图用语：训练时允许的生成长度、latent 步数、循环数、rollout 数或上下文模式，与评测时给的对应量 |
| 长度税（length-scaling tax） | [27] 定义：RL 后在已解决问题上多出的回复长度，没有相应准确率提升 |
| 改写式／追加式状态 | 改写式由 LLM 重写已有记忆、摘要或 cache；追加式保留原文、只往后加，必要时检索 |
| 无来源条目 | [29] 中摘要里找不到环境或用户原文支撑的条目，多为压缩器自己写的推断、决策与待办 |
| 自述泄漏（self-report leakage） | [33] 定义：被评 agent 自己的成功报告改变了评判器对同一轨迹的判定 |
| 禁止类／必需类约束（omission／commission） | [38] 定义：禁止类要求压制默认生成行为，必需类要求主动产生某个 token 或字符串；与 [39] 中需要多步执行的"安全义务"不是同一种"必需" |
| 集体失稳（collective instability） | [41] 的解释：多任务共享参数时，群体平均的自强化漂移会放大共享扰动，使坍缩只在任务数足够多时出现 |
| 锐化税（sharpening tax） | [42] 中后训练在大 k 下损失的覆盖 |
| 上下文条件化（context-conditional behavior） | 干预后的行为只在与训练/评测上下文形式接近时出现，换成触发线索、工具通道或多轮历史即改变 |
