## 一、这一轮学到的东西

- **原卡命中率低，改写卡命中率高。** 22 张原卡只有 2 张不拥挤（Q004、Q045）；12 张改写卡有 4 张不拥挤（Q060、Q067、Q068、Q070）。查新子代理读过近邻后给出的"剩余空间"，比找卡时的一次快速检索更能定位没人回答的那一小块。
- **"前提不成立"是原卡的主要死因（原卡 8/22，改写卡 0/12）。** 典型情形：两篇"相反"的论文其实测的不是同一个量（Q026：有害请求拒绝 vs 流程省略；Q040：编辑成合法状态 vs 改坏一步），或者结论方向一致、只是作者解读不同（Q047：两篇的斜率与截距符号一致，"敏感"与"不校准"可同时成立）。第三轮找卡说明里加了"先核对两组证据是否测的是同一个量"，但两张第三轮卡仍死于此，说明这一步需要片段级核对，摘要不够。
- **偏拥挤最常见的形态是"把两三篇近邻的变量放进同一设置比较"（16/34）。** 这类卡的子变量各自已有专门论文；能改写成不拥挤卡的，都是在剩余空间里找到了一个**新的可测量的量**（ρ̄ 的轨迹、训练前教师偏移、优化器这一未被扫描的轴），而不是再加一个对照。
- **第三轮找卡只看最近 5 周论文，3 个子任务只写出 2 张卡（Q026、Q047），都判前提不成立。** 新论文多，但够格的分歧少；继续加找卡人力的边际收益已经很低，剩余空间改写更划算。

## 四、可送打磨卡详述

### Q004

**问题。** 随机/虚假奖励 RLVR 的收益由什么决定：既有解释（Chen et al. 2025）把它归于当前模型表现与 rollout 质量（更强模型受错配损害更小），2512.16912 归于裁剪与熵；2610.01066 用完全相同的缓存 rollout 与随机奖励训练 OLMo-2-7B 的预训练末（P1）与仅多 5B mid-training token（P2）两个检查点，P2 平均增益 13.7 点、P1 仅 2.9 点（P2 rollout），P1 rollout 可把 P2 从 13.5% 带到 80.0% 而 P1 自身至多 9.5%——同输入同奖励下学习者不同即结果相反，直接反驳 rollout 质量解释。学习者一侧哪一属性（mid-training 数据、参数状态）决定随机奖励能否放大正确行为，尚未定位。

**证据。**

### Q045

**问题。** CoT 可控性（推理模型能否按要求改写自己的 CoT）对监控是风险还是不相关，两篇 2026-10 论文结论不一致：2610.40939 把低可控性归因于思考标签后头几个 token 的熵塌缩，预填/禁用常见开头 token 可把合规率提高 34–41 个百分点，但主要恢复的是‘添加/风格’可控性，‘抑制’可控性（避免/删去信息）响应不一，且在 12 个模型上抑制可控性与 CoT 监控性常呈负相关；2610.23257 则用 CoT 内自我指令显著提高可控性，并在 CoT Red-Handed 上让监控器捕获率从 52.5% 降到约 46.5–47.8%，而用户指令攻击不降反升（stealth 78.6%）。监控规避需要的恰是抑制类控制：自我指令是否真正提高了抑制可控性、开头 token 瓶颈是否解释了用户指令与自我指令的差距，以及哪类可控性能预测规避，尚未对齐。

**证据。**

- [2610.40939](https://arxiv.org/abs/2610.40939) The First Few Tokens Matter: Understanding Chain-of-Thought Controllability：证据角色：原始实验；实验设置：12 个模型（含 Qwen、OLMo、GLM-5.2）；8 类 CoT 控制任务（添加/风格/抑制）；推理时干预：合规前缀预填、禁用高频开头 token + 上下文示例；监控性评测含干预 g-mean、结局 g-mean、过程敏感性（sandbagging、Memory Advice、Scruples 等）；具体观察：禁用高频开头 token + ICL 使平均合规提高 34–41pp；干预主要恢复添加与风格可控性，抑制类对合规预填响应较弱（词省略变化小，第一人称回避对更长前缀受益更多），与 ICL 下抑制类受影响最大的情况相反；组内正相关、跨组多为负相关；添加/风格可控性多与监控性正相关，抑制可控性常为负相关。；对照与保持条件：同一模型与任务；跨模型 Spearman 相关；证据边界：监控性与可控性的关系是跨 12 个模型的相关，非因果；未测监控规避攻击；位置：摘要；§Exploring the Controllability Bottleneck（p.6, Figure 6）；§3.4 Validating the Controllability Constructs；§Experimental Setup（p.7, Figure 8）
