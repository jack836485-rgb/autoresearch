## 结论
2026-11-03，总体 score 4.6，verdict：needs_rethink。主贡献分两部分：一是把开思考 OPSD 的长预算损失拆成"终止策略被改变"和"推理质量下降"；二是只在终止 token 总概率上锚定回学生的 OPSD。分量不够，原因有三。第一，训练期修法所依赖的通道，在 1,024 token 的训练窗口内几乎没有信号。第二，成功判据"保住 4k 增益且 32k 不低于基座"在逻辑上自相矛盾，因为预研显示 4k 增益几乎全部来自"提前结束"本身。第三，诊断视角与"会解题/会停止"的分解（2609.37326）、"只压缩不修复"（2605.06188）高度相邻。剩下真正新的东西，只有"在 OPSD 学生上做 budget forcing"这一个诊断。

## Claim 判断

|---|---|---|
| 重要性 | 6.5 | 开思考 OPSD 在长预算下退化，是 2026 年被反复报告的失败（2607.05184、2605.06188、2607.02234、2603.24472）。如果能干净地判定"停得早"和"不会推理"哪个是主因，就能决定后续修法应该改终止还是改内容，有明确价值。但这个对象较窄，多篇论文已经指出 OPSD 只是沿准确率-长度权衡移动。即使分解成立，对领域判断的改变也有限。 |
| 新颖度 | 5.5 | "解题能力与停止能力分开传递"的诊断框架，2609.37326 已在外部教师 OPD 上做过（方向相反）。"OPSD 在长思考中只压缩、不修复"已由 2605.06188 提出。2607.05184 已提出"短训练导致遗忘长推理"的假说，并用 OPD 部分排除了它。把 EOS/终止当作单独动作处理，2609.20511 已有先例。我检索到的范围内，没人在 OPSD 学生上用 budget forcing 做差分，这一点可以辨认。终止锚定是把已有的边际/条件分解换到终止类 token 上，属于常规组合。 |
| 有效性 | 4.0 | 当前依据：预研中 4k 内已结束的回复，两者正确率相近（83.7 对 87.9），16k 内结束比例为 99.9% 对 90%。这支持"OPSD 让模型停得更早"，不能证明"停的决定是被终止 token 的概率直接教出来的"。关键的未知步骤有三个。①训练只对前 1,024 个 token 计损失，而基座在 4k 内结束的比例都很低，所以窗口内几乎没有 `</think>`/收尾位置。`L_marg(S)` 的量级很可能接近零。缩短更可能经由非终止内容传递（少写 wait、更快下结论，见 2607.05184 的 fork 与反思 token 符号反转），而这部分仍由 `L_cond` 照常蒸馏。预研已有该分解的代码，却没有报告窗口内 `L_marg(S)` 占总 KL 的比例。②预研自己显示，认知词类的"只训边际项/只训条件项"都复现了同样模式。这本身就是"按 token 类拆信号不改变结果"的反向证据，同样适用于终止类。③s1 的 budget forcing 在基座上有效，但它能否迁移到"被压缩过的学生"未知。2605.06188 显示反思标记被压掉了，续写之后可能只是重复。 |

- **与原问题的关系**：这是对原问题的直接回答，没有转向。原问题中"现有修法是否处理了真正原因"仍主要依赖判断 1 的诊断。
- **实验能否判别主张**：
  - 判断 1 的差中差，基座臂基本是空操作：目标长度取"基座在同题同种子下的长度"，基座自己正好在该长度停下，强制续写几乎不会触发，所以"显著大于基座提升"会自动成立。真正起作用的只有"消掉损失 ≥ 0.5"。
  - 判断 2 要求 4k 增益 ≥ vanilla 的一半，同时 32k 与基座持平。在前缀截断判分下，4k 增益来自 4k 内结束。如果长度恢复到基座水平，4k 增益会随之消失。两者共存需要按难度自适应长度，而该方法并未针对这一点设计。所以这个判据要么同时失败，要么只能被解读成"又落在同一条权衡曲线上的另一点"（2605.06188 的结论），判别力弱。
  - 判断 3 只有 3 种教师上下文，只能检验符号方向，证据量很小；2609.25623 也报告初始 KL 不能给下游性能排序。
  - 结论句"若两者都无效，则首次干净支持推理受损"是过度推断，因为终止行为可能由分布式的内容 token 承载。
- **可行性：pass**。
  - Qwen3-1.7B 与 2609.20612 的仓库已在本项目跑通。
  - 终止锚定只改目标分布，已通过恒等式单测。
  - s1 规则明确，可以在 vLLM 循环中实现。
  - PW-OPSD 有官方代码。AD-OPSD 无代码，但其规范（熵前 20% 沙盒、非对称逐点门控、锚定到冻结基座、表 6 超参）足以独立复现，需注明阈值等缺失选择。
  - 约 120 A100 小时，在 8×A100、5 天之内，不需要付费 API，数据（AMPLE-Math 冻结切分）可得。
  - 缺强对照：E²-OPSD（2610.05048）与 ST-OPSD（2610.34005）是同类型、针对思考模型的近期修法，未列入对照。
