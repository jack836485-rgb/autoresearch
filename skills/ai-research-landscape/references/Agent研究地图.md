# Agent 研究地图的证据粒度

处理 LLM 驱动的软件与知识工作 Agent 时读取，结合实际任务选用；不要求每轮都按这些对象建卡。

## 分清测量对象

工具参数合法，不表示输入信息正确；拿到证据，不表示用对证据；最终答案正确，不表示共享／持久状态正确；找到责任角色，不表示找到最早根因步骤；事后定位成功，不表示在线预警或修复有效。把原作分别测量的能力留在对应问题中。

“从经验学习”需要说明更新的是上下文、外部记忆／skill、检索控制器、记忆编码器，还是执行模型权重。同任务重试、跨任务复用、删除经验后的能力保留与分布外迁移是不同证据。外部记忆收益不会因不改执行模型权重而失去价值，也不能被写成执行模型已经内化知识。

## 受控证据与描述性证据

- 编排比较记录模型、工具、提示、最大预算、实际消耗、任务拓扑和重复次数。更换整个架构的结果不能单独归因于 agent 数量。
- 压缩比较记录 summary、额外位置预算、原档案访问、冻结 actor 和生成长度。下一步动作受评审偏好，不等于该反事实动作实际执行后更好。
- 错误分析记录分母是全任务、失败轨迹、错误片段还是规则 verdict；多标签错误率不必相加为 100%。
- 根因人工标签是有证据的标注参考。若未重放干预验证，不能升级为已证明的因果真值。根因到终点距离与域／任务难度相关时，不把分层下降解释为孤立的长度因果效应。
- 规则遵循的聚合率可能含本来就会遵循的默认行为；子集比较描述条件差异，规则移除与位置互换才提供相应干预证据。观察到的优先次序不等于系统应采用的指令权威层级。
- 学习曲线拟合好，不表示普适缩放规律；总分聚合可以掩盖单任务不连续、平台期和不同反馈条件。保留拟合区间、预算单位及任务筛选。

## 成本和已有解法

Agent 成本至少按原作拆开推理 token、工具／环境调用和运行时间；有额外 teacher、评审、压缩编码／检索或训练时说明是否计入。API 等价价格不能直接推出 GPU 成本或端到端成本下降；吞吐提高也不能推出尾延迟或正确率一起提高。

针对已发现问题补查具体解法和相反条件。文本摘要、图结构经验、权重蒸馏和残差记忆可能作用于不同保留方式，不因共同叫 memory 就作输赢比较；并行可分任务与强依赖顺序任务的多 Agent 结果也不能硬称矛盾。剩余问题写在原作实际验证边界内，明确本轮查找范围。

Survey 的分类和作者判断用于定位，不冒充作者对全部被引作品的受控复现。产品／旗舰报告的采用证据与诊断实验共同使用，但只有独立机构和作品明确采用时才写共同采用。研究地图必须保留具体发现，不能退回“记忆、规划、多 Agent、训练、评测”五个泛方向。
