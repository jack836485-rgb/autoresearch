# 基线复现依据

候选送审前，核实对主贡献有判别力的同任务强基线及其所需数据、模型和接口。公开代码是优先路线，不是唯一准入条件。

- **已核验实现**：打开官方或可归属的公开代码，确认确实实现被引用方法，记录入口、关键配置和所需资源；只看到仓库名或README提到论文不够。
- **依据公开规范独立复现**：没有可用代码时，直接读原论文中定义算法、提示、工具和调度的充分规范，说明如何实现、哪些选择原文没有指定、如何固定这些选择。缺失影响主结论的关键步骤、私有数据或权重时，不能声称充分可复现。标明“计划按公开规范独立复现”，不能写成“已复现”或“官方实现”。
- **明确的标准对照**：普通检索、随机选择等可直接给完整规则和预算；不需要为简单算法寻找仓库。

所有路线都须说明任务和评测匹配、保持相同的核心条件、实际会执行的步骤与资源。公开代码存在不等于它能按所提预算直接运行。关键比较若必须改动原方法，明确改动与原因，并保留能检验其真实能力的对照。

若强近邻缺少充分复现规范，仍须保留它对新颖度与主张边界的限制；不能因没有代码就把它当作无效或不存在。若它是验证优越性不可缺少的竞争者，该缺口阻断相应主张；若当前贡献并不依赖击败它，说明可检验的范围，不把“无法比较”误判为整个方案不可实施。跨领域方法可限制机制新颖度，但不能自动充当不同任务的性能基线。
